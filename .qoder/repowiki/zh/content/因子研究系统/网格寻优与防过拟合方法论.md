# 网格寻优与防过拟合方法论

> 来源：Project_16 网格寻优（T-20260909-009）+ 独立审计（T-20260910-007，报告 `projects/Project_16_LightGBM股票大师/results/策略优化审计_20260910.md`）。
> 适用：任何策略层参数寻优（持有期 N / 出场模式 / 持仓数 TOP / 评分红线 / 位置过滤开关）。

## 一、三阶段流程（S1 → S2 → S3）

| 阶段 | 内容 | 目的 |
|---|---|---|
| **S1 粗扫** | N × 出场模式全矩阵（如 N∈{5,10,15,20} × {fixed, live_trail}），其余参数锁默认 | 找持有期主峰，观察长短两端衰减形态 |
| **S2 微调** | 在 S1 峰值附近扫 TOP（持仓数）× 红线（评分阈值）邻域 | 精化组合参数 |
| **S3 防过拟合** | 测试期对半分段（前 2024-07~2025-06 / 后 2025-07~2026-08），要求**两段超额均正** | 拒绝单段靠运气撑起的尖峰 |

**裁决规则**：宁可低一档超额也要稳健。实例：G2-TOP1 整段 +0.245% 表面最高，但前段 -0.016% 转负 → 证伪弃用；融合-TOP1 两段均正但每段仅 28 笔样本不足 → 列观察不主推。

## 二、官方引擎口径（scan_rotate_cost_real.py）

- 可执行 open→open：信号日 T 选股、T+1 open 成交；滑点敏感性默认 0 / 0.1% / 0.2% 每边
- 成本：佣金万2双边（最低 5 元）+ 印花税万5卖出 + 过户费万0.1（沪市）
- T+1 卫生：买入日不把当日 high 并入追盈峰值（用「截至昨日」峰值判今日出场）
- 一字板双侧：涨停买不进（跳过计数）、跌停卖不出（持有待次日）；停牌/退市 DELIST_DAYS 无价按损失清仓
- 超额基准：panel 当日 universe 等权 fwd_ret 均值（注意 fwd_ret 为 close→close 1 日，与策略 open→open 存在窗位差——历史口径沿袭，年化折算需知其虚）
- env 面：`BT_PANEL/BT_MODEL/BT_META`、`BT_MODEL2/BT_META2/BT_ENSEMBLE`（rank 融合）、`BT_THRESHOLD/BT_TOP/BT_POSFILTER/BT_EXIT/BT_STOP/BT_TP/BT_N_LIST/BT_SLIPS/BT_START/BT_END`

## 三、必须声明的批次开关

**网格批次必须显式声明 `BT_POSFILTER`**，否则 V1.4 官方口径失真（实例：TW 第一批 V1.4 网格漏 `lite`，误报 +0.029%，复跑修正 +0.157%）。每个臂的 panel/model/posfilter 全部显式登记（参考 `data/strategy_cfg_lib.json` 格式）。

## 四、根本性局限：测试集双重使用

模型训练窗口若覆盖回测测试期（如 G2 模型 08-25 训练、测试期 2024-07~2026-08-14 100% 在训练窗内），则：

1. 所有配置数字**系统性偏乐观**；
2. **S3 时间分段救不了**——模型两段都见过，分段只是防参数过拟合，不防模型记忆；
3. 唯一干净裁判 = **样本外纸面前向**；裁判标准看「样本外超额是否 >0」而非「是否达到回测数字」；
4. 年化折算（复利放大后如 70%）禁止对外引用。

## 五、审计方法（对 TW/DE 外部报告）

1. **数字逐项独立复算**：不引用其输出，用官方引擎原样重跑关键配置（含 env 对照），三配置+分段应精确命中；
2. **配置声明与实际对照**：strategy_cfg_lib / env 面 / posfilter 开关逐一核对；
3. **训练窗口重叠检查**：查模型文件日期与测试期覆盖；
4. **峰形检查**：独峰（邻点断崖）信度低，宽峰信度高；单侧陡降说明参数恰在格点取峰；
5. **样本量检查**：TOP1 类低频配置看每段交易笔数（<30 笔不判定）。

## 六、结论等级制度

| 等级 | 含义 | 动作 |
|---|---|---|
| 回测口径成立 | 数字可复现 + S3 分段稳健 | 进候选配置库（strategy_cfg_lib.json） |
| 纸面待验证 | 候选配置挂纸面前向 A/B | 攒 30 笔独立观测 |
| 可上线 | 样本外超额 >0 且不劣于现行 | 人工拍板改实盘配置 |

**红线：禁止仅凭回测扫描数字直接改实盘。**

## 七、纸面优先制度（2026-09-13 固化，T-20260913-001 P3）

1. **任何 N/红线/TOP/出场/过滤/融合权重改动，必须先挂纸面前向臂 ≥30 笔**（现行红线，T-20260910-109 越线上线融合属让步个例，不成为常态）。
2. **纸面前向自动降级闸**（`paper_forward_downgrade.py`）：任一策略纸面臂样本外超额均值 <0 且 <-0.0002（n≥30，rank<=2 口径）→ 自动冻结该策略 rebalance「只卖不买」+ 飞书告警；解除必须人工 `--unfreeze`。
3. **配置漂移复查**（`config_drift_recheck.py`）：promote 新模型后对历史最优 N 的 3 个邻域点重扫，漂移**只登记候选不改实盘**（data/config_drift_<策略>_<date>.md）；实盘切换仍须纸面前向 30 笔。
4. **回滚自动化的保守边界**（`rollback_check_g2.py --auto`）：观察期深度劣化（劣于基线 >0.05pp）**且连续 3 个交易日**（`rollback_streak.json` 计数）才自动回退（回已知好版本=低风险）+ 飞书；轻度劣化或连续不足 3 日仍人工 `--apply`；回退失败 fail-loud（exit 2 + 飞书，防"已自动回退 OK"假阳性）。
5. **KPI 纪律**：自我迭代的裁判 = 样本外纸面前向超额 >0 且不劣于现行；回测年化数字（测试集双重使用虚高）不作 KPI、禁止对外引用。
