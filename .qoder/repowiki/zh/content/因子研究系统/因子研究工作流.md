# 因子研究工作流

> 从「一个想法」到「判定通过 / 证伪归档」的标准流程。核心原则：**证伪与证实同等重要，结论必须落盘避免重复调查。**

---

## 一、判定标准（先立标准，再做实验）

| 指标 | 门槛 | 说明 |
| --- | --- | --- |
| IC | ≥ 0.03 | 横截面 Spearman IC 均值 |
| ICIR | ≥ 0.3 | IC 均值 / IC 标准差 |
| 五分位 | 单调 | Q1→Q5 收益必须单调，缺一不可 |
| Calmar | ≥ 0.6 | 年化 / 最大回撤 |

**四项全过**才进入上线候选；任一项不过即判 FAIL。这条线是**预注册**的——实验前先写死，实验后不许改。

已有判例：BP 因子 IC=0.069 / ICIR=1.74 / 胜率 81%，是少数达标的强因子。大市值域则多次失败（Project_12 -60.8%、Project_18、Project_01、2026-08-18 的 T-20260817-004 均 FAIL）——**低波 alpha 主要存在于小微盘域**。

---

## 二、标准流程（七步）

### 1. 提出可证伪假设
写清：因子定义、经济逻辑、预期作用域（大盘/小盘）、预期失效条件。**「预期失效条件」必须写**——没有失效条件的假设不是可证伪假设。

### 2. PIT 数据准备
- 行情：`DataFeed` / `AstockParquetReader`；
- 财务：必须走 `AstockFinanceReader.get_fundamentals_pit`（按 `ann_date` / `f_ann_date` 对齐）；
- 股票池：优先用 `universe_by_date`（PIT 池）而非固定池，否则引入幸存者偏差。

> Project_01 的教训：修复幸存者偏差后，超额从表面收益降到仅 BP 因子 +6.1%/年，且 2024 年后转负。

### 3. 因子实现
继承 `FactorBase`，实现 `compute(panel, fin_ffill, **kwargs)`，元数据填 `name` / `category` / `description`。预处理按惯例：winsorize(1%, 99%) → zscore 或 rank_normalize，横截面做。

### 4. 注册与计算
```python
engine = FactorEngine()
engine.register(MyFactor())
panel = engine.compute_all(df, fin_ffill)
ic    = engine.compute_ic(panel, price_data, forward_days=20)
```
批量跑用 `scripts/batch_ic_test.py`（或 `scripts/run_batch_ic_test.bat`）。

### 5. 分层与回测
五分位分层看单调性，再进 `run_backtest` 做全周期 + 分段（牛/熊）回测。**必须做掩码前置（MASK=1）**，否则约 18% 收益来自涨跌停虚增。

### 6. 鲁棒性检验
`projects/verification/robustness_tests.py` 的 D-1~D-7：子样本、牛熊、压力、成本压力、容量、未来函数、幸存者偏差。至少跑 D-1 / D-2 / D-6。

### 7. 结论归档
**无论 PASS 还是 FAIL 都要写报告落盘**，注明：口径、区间、成本假设、数据集 hash、结论。证伪的结论尤其要写清楚「为什么不成立」，避免半年后重复调查。

## 三、因子健康监控（上线后）

`research_audit/factor_health.py` 按调仓期计算 Spearman IC 序列并告警，产物 `factor_health_报告.md` + `factor_health_ic.csv`。IC 长期衰减或符号翻转即触发复核。

## 五、常见失败模式

| 失败模式 | 症状 | 根因 |
| --- | --- | --- |
| 未来函数 | IC 极高（>0.1）、回测曲线完美 | 用报告期而非披露期对齐；或用了全样本统计量 |
| 幸存者偏差 | 长期超额虚高，2024 后转负 | 固定池而非 PIT 池 |
| 涨跌停虚增 | 收益高但不真实 | 未做掩码前置（虚增约 18%） |
| 容量幻觉 | 小资金年化 30%，大资金腰斩 | 未跑 D-5 容量测试；Project_10 实测容量上限约 1000–2000 万，5000 万时收益减半 |
| 风控频率错觉 | 年化虚高 10pp+ | 「双月才查风控」口径 vs 「每日风控」口径差异巨大（Project_10 实测 18.0% → 7.5%，主因风控频率 -8.3pp） |
| 样本量幻觉 | 「N>30 笔」看似够 | 同日多票高度同向（组内相关 ρ≈0.68），有效样本 `n_eff = n / (1 + (m-1)ρ)`，N=30 在 m=2 时仅约 18 个独立观测 |

## 六、研究纪律

1. **预注册**：阈值、区间、成本在实验前定死；
2. **锚检查**：跑新实验前先复现一个已知基线（通宵批次任务里要求锚检查 5/5 PASS 才算环境可信）；
3. **证伪即归档**：不达标的候选写进 `research_study/` 类归档区，标注「不部署」；
4. **结论立即落盘**：调研结论、选型结论要立刻写进项目 `PROJECT_MEMORY.md` 或知识库，**避免后续重复调查**；
5. **统一口径才可横向比较**：多条候选必须在同一撮合模型（next_open）、同一滑点（10bp）、同一股票池下跑，禁止各跑各的口径再排名。
