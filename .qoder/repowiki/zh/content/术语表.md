# 术语表

> 分五类：因子研究方法论 / 回测与绩效 / 交易与执行 / 数据与数据源 / 本项目专有名词。

---

## 一、因子研究方法论

| 术语 | 含义 |
| --- | --- |
| **PIT（Point-In-Time）** | 时点数据。财务指标按**实际披露日**（`ann_date` / `f_ann_date`）而非报告期对齐，防止前视偏差 |
| **前视偏差 / 未来函数** | 使用了当时不可得的信息。回测收益虚高的头号原因 |
| **幸存者偏差** | 只用"存活至今"的股票回测，忽略已退市标的，系统性高估收益 |
| **IC** | 信息系数，因子值与**未来**收益的横截面 Spearman 相关系数。门槛 ≥ 0.03 |
| **ICIR** | IC 均值 / IC 标准差，衡量 IC 稳定性。门槛 ≥ 0.3 |
| **五分位分层** | 按因子值把股票池分 5 档（Q1→Q5），看收益是否**单调**。不单调即因子不可用 |
| **Winsorize** | 去极值，本项目默认 1% / 99% 缩尾 |
| **Z-score** | 标准化：(x - mean) / std |
| **Rank normalize** | 秩归一化，转秩后归一化，抗 outlier |
| **中性化** | 剔除市值/行业等因素影响（`settings.yaml` 的 `factors.neutralize`） |
| **代理变量** | 用一个可得变量近似替代真实但难获取的变量（如 F3 新闻催化目前只是代理变量） |
| **预注册** | 实验前先写死阈值与口径，实验后不许改 |

## 二、回测与绩效

| 术语 | 含义 |
| --- | --- |
| **next_open** | 撮合模型：信号在 T 日收盘产生，T+1 **开盘**成交。本项目默认模型 |
| **掩码（MASK）** | 涨跌停/停牌状态前置过滤。不做的回测约 18% 收益是虚增 |
| **滑点（slippage）** | 成交价与理论价的偏离，默认 0.002 |
| **手续费 / 印花税** | 默认 commission 0.00025，印花税仅卖出收取 |
| **CAGR** | 年化复合收益率 |
| **最大回撤** | 权益曲线从峰值到谷底的最大跌幅 |
| **Sharpe** | 夏普比率，超额收益 / 波动率 |
| **Calmar** | 年化 / 最大回撤。门槛 ≥ 0.6 |
| **超额收益 / 跟踪误差** | 相对基准（默认沪深300 `000300.SH`） |
| **换手率** | 一定时期内买卖金额 / 平均资产，影响成本敏感度 |
| **容量** | 策略能承载的资金规模上限（超出后收益衰减） |
| **T+1** | A 股当日买入不可当日卖出；组合层用 `available_volume` 冻结买入可用券 |
| **PIT 股票池** | `universe_by_date`：每个时点用当时真实存在的股票池 |

## 三、交易与执行

| 术语 | 含义 |
| --- | --- |
| **miniQMT / xtquant** | 迅投 QMT 的轻量程序化接口（外部 Python 调用），账号 67014907 走此通道 |
| **大 QMT（内置 Python）** | QMT 客户端内嵌 Python 3.6.8 运行策略，账号 70180771 走此通道 |
| **handlebar** | QMT 策略的行情驱动主循环函数，生命周期为 `init(C)` → `handlebar(C)` → `exit(C)` |
| **passorder** | QMT 下单**全局函数**（不是 `C.passorder`）。异步接口，返回 0/None，**不是订单号** |
| **cancel / can_cancel_order** | QMT 官方撤单 API。`passorder` 的 opType **没有撤单值**（24 是卖出） |
| **m_nOrderID / m_strOrderSysID** | 前者是 QMT 平台委托号（优先）；后者是柜台合同号，撤单用它 |
| **m_nVolumeTraded** | 真实成交量字段（不是 `m_nDealVolume`） |
| **孤儿持仓** | 账户有票但账本无记录 → 止损/止盈永不触发。必须纳管 |
| **pending** | 已发委托待确认状态。本项目超时 300 秒、最多重试 3 次 |
| **部成（状态码 55）** | 部分成交，是**活跃态不是终态** |
| **BUILD_TAG** | QMT 构建产物内嵌的版本标记（`YYYYmmdd-HHMMSS`），用于核对本地构建版本 = 实盘运行版本 |
| **prType** | QMT 价格类型：5=最新价，11=指定价（可挂不可成交单用于测撤单） |

## 四、数据与数据源

| 术语 | 含义 |
| --- | --- |
| **astock** | 主数据源，`D:/astock/` 下买断离线 parquet（日线 + 财务 + 基本面） |
| **gpsj** | 备用数据源（DuckDB），用于交叉验证 |
| **duckdb / qmt_self_owned** | 实时补充源，需 QMT 在线 |
| **复权（adjustment）** | 价格复权方式，`raw` 为不复权。回测与实盘口径必须一致 |
| **circ_mv** | 流通市值，单位是**万元**（30 亿 = 300000） |
| **moneyflow** | 资金流数据，`amount` 字段单位是**万元** |
| **面板（feature panel）** | 特征面板 `feature_panel_v3.parquet`，模型的训练输入 |
| **熔断路由** | `scripts/data_source_router.py`：数据源连续失败 3 次即熔断 300 秒 |
| **crosscheck** | 9:25 盘前双源对拍，不一致打 `[交叉验证]` 预警 |

## 五、本项目专有名词

| 术语 | 含义 |
| --- | --- |
| **Project_16 / G2** | LightGBM 股票大师。V1.3 走 miniQMT(67014907)；**G2 是大 QMT 文件桥版本（70180771），与 V1.3 完全隔离** |
| **文件桥（g2_bridge）** | 外部 Python 与 QMT 内置 Python 通过 `D:/QMT_POOL/g2_bridge/{cmd,state}` 文件交换 + seq 幂等 + pending 状态机 |
| **F1–F6** | Project_16 六维度评分因子。已知缺陷：F3 仅为代理变量、F6 估值约 11 天滞后 |
| **双轨选股** | 候选集离线定（combo 全离线）+ 候选内排名由实时复核重排 |
| **combo** | 候选组合（离线确定性生成） |
| **vol_target（VT）** | 波动率目标缩放，按目标波动调整仓位。在 ATR 策略上会退化为永久低仓 |
| **CrashGuard / RegimeGate** | `risk/` 的两个每日守卫：崩盘空仓 / 低波动环境门控 |
| **buffer160** | Project_10 的降低换手机制 |
| **退市排雷** | 剔除潜在退市标的的风控步骤 |
| **6+2 / dual_band** | 主升浪策略的持仓结构（已于 2026-08-05 淘汰） |
| **Updatedata/** | **人工周更**目录，常滞后 7 天以上，是"数据不同源"事故的高发源 |
| **engram** | 跨会话记忆 MCP 工具（项目作用域 `quantlab`），与三层记忆分工并存 |
| **审计模式** | 只输出任务文档，不改动代码/配置/账本 |
| **fail-loud** | 异常必须显式暴露（非零退出码或告警），禁止静默降级为"成功" |
| **n_eff** | 有效独立样本量，`n_eff = n / (1 + (m-1)ρ)`，用于修正同日多票相关性导致的样本量高估 |
