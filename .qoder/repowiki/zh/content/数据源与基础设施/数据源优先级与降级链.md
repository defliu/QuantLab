## 二、F2 主力资金链（最容易出事的一条）

历史事故（T-20260831-003）：TDX 返回 503 后降级到 iFind，用了**前一日**口径，把 8/28 的 +5.26 亿当作当日数据打 F2=10 分；实际东财口径 8/28 为 -2.79 亿、8/31 当日 -1.25 亿，**方向全反**（真实 F2=1，总分 86→68）。

修复后的规则：

1. **模型特征层**：Tushare `moneyflow` 为权威主源（T-1）。快照新鲜则走 Tushare，滞后则回退新浪兜底。
2. **评分卡实时层（9:45）**：坚持**当日口径**，优先级 mcp_tdx → 悟道 capital_flow（东财当日）→ 东财 mx → 东财 curl；iFind 仅作兜底，且必须写入 `main_net_inflow_date`。
3. **时效校验**：`review_full._valid_main_inflow` 校验资金流日期，**非当日即按缺失计（F2 = 5 分）**，绝不拿隔日数据充数。
4. **盘前交叉验证（9:25）**：双源对拍 F2 资金 / 行情 / F5 板块，写 `crosscheck_<date>.json`；`review_full._read_crosscheck` 对不一致候选打 `[交叉验证]` 预警，只预警不阻塞。

> **Tushare `moneyflow` 的 `amount` 字段单位是万元，不是元。** 历史 parquet `D:/astock/moneyflow/moneyflow.parquet` 同样以万元存储，任何刷新脚本**不得 ÷1e4**。量级突变 1e4 倍即为单位 bug 信号。

## 三、扩展指标降级链（v8）

按职责分组，基础行情锚定腾讯（最稳），扩展指标走多级降级：

```
基础行情：腾讯 → ...
扩展指标：mcp_tdx → iFind → 东财 mx → 东财 curl   （TDX 不可达不阻塞）
F3 催化：官方公告 / 研报 / CLS 快讯 → 新浪 stockNewsSearch → 悟道
F5 板块：theme_intraday_capital / sector_analysis → ...
```

**悟道（wudao）**：真实端点 `https://stock.quicktiny.cn/api/mcp`（JSON-RPC POST + Bearer），63 个工具，盘中可用。注意：早先文档里推断的 `/api/openclaw` REST 路径**实测 404，不存在**。

> 教训：**定时任务（Schedule）环境与交互环境的 MCP 配置可能不同**。项目级 `.mcp.json` 若未登记某个 MCP，定时任务加载不到就会「不可达」。远程数据源一律写 Python 直连客户端（如 `scripts/wudao_client.py`、`caihui`），不要依赖客户端插件层。

直连客户端用法：

```bash
python scripts/wudao_client.py <tool> '<json_args>'
# 失败打印 [WUDAO-ERR] 且 exit != 0
```

## 四、熔断路由（`scripts/data_source_router.py`）

避免单个挂掉的源被反复重试拖垮整条链：

- 取数前 `check<源>`：已 OPEN（熔断中）则直接跳过；
- 调用后 `record(ok|fail)`；
- **连续失败 3 次熔断 300 秒**；
- 状态落 `data/cache/datasource_health.json`，多任务共用。

CLI 自测：`fail × 3 → OPEN → 恢复` PASS。

## 六、夜间检修（`scripts/nightly_check.py`，01:00 工作日）

全模块 A–G 自检，确保次日策略可运行：

- **A 数据完整性**：含 moneyflow、财务 PIT 覆盖检查
- **B 面板模型同步**：面板最新日落后于最近交易日 → 自动 `refresh_panel_v3` 重刷
- **C 调度任务健康**：核对次日 6 个任务 Active
- **D 数据源连通性**：含熔断恢复
- **E QMT 进程 / 桥心跳 / 账本戳 / 对账**
- **F 磁盘 / 清理 / 脚本冒烟**
- **G 报告 + 告警**

```bash
python scripts/nightly_check.py --fix      # --fix 自动修复
# 报告落 data/cache/nightly_check_<date>.md
```

首次 dry-run 就抓到真实问题：面板最新日 9/2 ≠ 最近交易日 9/3（当天 16:30 的 refresh 未到位）。

## 七、新鲜度治理：三个必须做硬断言的地方

历史反复踩的坑：**「生成侧与核算侧不同源」的管道，必然出现「能出信号、无法验证」的死局。**

1. **候选 vs 收益源**：`候选日期最大值 > 收益数据源最新日` 即为死局，必须 fail-loud（非零退出码）。
2. **面板 vs 交易日**：面板最新日必须等于最近交易日（夜间检修 B 项已覆盖）。
3. **零产出**：回填 / 统计类任务输出 0 笔，**不得以 exit 0 报 OK**。

> 典型案例（T-20260904-009）：`paper_forward.py --backfill` 只依赖人工周更的 `Updatedata/`（常滞后 7 天以上），而选股侧用自动日更的增量库 → 候选每天照常产生、收益一笔也算不出，连续 4 天「回填 0 笔」仍 exit 0 静默，有效样本实为 N=0 却被记成「9 个交易日」。

## 八、面板双轨设计 + 纸面回填数据链（2026-09-10 核查确立）

**面板双轨**（设计如此，勿混用）：

| 轨道 | 面板 | 刷新 | 用途 |
|---|---|---|---|
| **回测轨（冻结）** | `feature_panel_v3_sc.parquet`（V1.4）/ `feature_panel_v3_enh2_n3_bt.parquet`（G2） | **冻结 2019-01 ~ 2026-08-14 不动** | 回测可复现性——回测结果不能随数据更新漂移 |
| **实盘轨（日更）** | `feature_panel_v3.parquet` + `data_live/g2_latest_features.parquet` / `latest_features.parquet` | 每日 16:30 daily 链路刷新 | 实盘选股推理 |

> 误读警告：「模型权重回退」≠「面板回退停更」——G2 live 指针（`data/g2_live_model.json`）回退只影响模型权重，实盘每日用**最新面板 + 旧权重**推理（数据新、权重稳，两套并存是设计）。

**纸面收益回填唯一合法数据源**：`data_live/merged_daily_full.parquet`（主库 + 增量合并，每日 16:40 落盘）。主库 `stock_daily.parquet` 周更滞后（当前停 08-21，设计如此）**不可用**；`ashare_trade_dates.txt` 曾陈旧 14 交易日（T-20260910-004 修复：`is_trade_day.load_calendar()` 末日距今 >7 自然日自动用主库+增量重建，且 `refresh_panel_v3.py` 末尾固化每日重建）。到期判断用**交易日口径**（非自然日）。

**依赖链全景**（断任何一环 = 纸面统计静默冻结）：

```
xtdata_update 增量(16:30) → merged_daily_full(16:40) → refresh_panel_v3 面板+日历(16:45)
  → deploy_predict 选股 → paper_forward_daily 回填(16:45) → g2_candidates_night 信号(20:05)
```

## 九、转债与 ETF 数据实测结论（2026-09-12 DE 实锤，来源 `data/schedules/de_cb_datacheck_20260912.md`）

本机 `D:/astock` **无 ETF/转债历史库**（仅股票/指数）。转债/ETF 建模一律走 Tushare HTTP API（`TUSHARE_TOKEN` 环境变量），实测要点：

1. **🛑 511990 货币 ETF 数据陷阱**：Tushare `fund_daily` 的 511990（华宝添益）价格序列**丢失全部收益**（2015-2026 复合年化 = -0.00%，价格常年钉 100 元，分红/收益结转未反映在 close）。**任何货币腿回测禁止用 511990**，会压低全部线 0.5-0.6pp/年。正确口径：H11025.CSI 货币基金指数（2.44%/年）或 511880 银华日利（2.25%/年），两者相互印证。
2. **转债接口行为**：`cb_basic` 默认字段**不含评级/条款**（须显式传 fields 才有 issue_rating/newest_rating/maturity_call_price 等）；`cb_call`（强赎）与 `bond_cov`（转股价历史）需额外积分权限（当前 token 40203/40101 无权限）——强赎公告改走东财公开接口（NOTICE_DATE），转股价无历史 → 历史溢价率须双锚点 ablation。
3. **中证转债指数代码是 `000832.CSI`**（非 `.SH`）；2019 起 1868 交易日零缺失。
4. **cb_daily 摘牌后输出 0 量僵尸行**（岭南转债 2024-08 到期违约后仍输出 248 行冻结价 0 量）——转债回测必须三保险：`delist_date` 非空即截止 ∪ 东财 `CEASE_DATE` 补洞 ∪ `vol > 0` 逐日过滤。
5. **幸存者偏差量级**：1164 只转债已摘牌 817（70%），静态池套全期丢六成样本。
6. **评级 PIT**：`issue_rating`（发行时评级，覆盖 94.6%）作历史回测 PIT 代理；`newest_rating` 是跟踪到生命末期的终态快照（洪涛 AA→CCC 等 151 只差分券实证），禁止用于历史回测。模拟盘当下排雷用 newest_rating。
