# 快速开始

> 目标：让一个新接手的开发者（或 AI agent）在 30 分钟内跑通「取数 → 因子 → 回测 → 验证 → 构建 QMT 产物」全链路。
> 本文只讲最短路径与必踩的坑，原理细节按文末指引跳到对应专题。

## 一、先读这三份文件（硬规则）

`AGENTS.md` 是本仓库的最高约束，开工前必读。其中三条是硬性流程要求：

| 文件 | 作用 | 不读的后果 |

### 2. 股票池

`data/universe.py` 提供带 schema 校验的 CSV 加载器：

- 首列必须是 `code`，格式 `^\d{6}\.(SZ|SH)$`，非法行丢弃并告警；
- 可选列 `enabled`（`false`/`0`/`no`/空串视为关闭）；
- 重复 code 保留首次出现；**空池直接抛 `ValueError`**（不做静默降级）。

仓库内置三份池：`universe_all_a.csv`、`universe_liquid_30e.csv`、`universe_sample.csv`。

## 四、最短路径：取数 + 算因子

```python
from data.feed import DataFeed
from factors.engine import FactorEngine

feed = DataFeed(source="astock")
df = feed.get_daily(codes=None, start_date="2024-01-01", end_date="2026-08-31")

engine = FactorEngine()
engine.register(MyFactor())          # 继承 factors/base.py 的 FactorBase
panel = engine.compute(df)           # 内置 winsorize / zscore / rank_normalize
ic = engine.evaluate_ic(panel, forward_return_col="fwd_ret_5d")
```

`get_daily` 返回 **MultiIndex `(date, code)`** 的 DataFrame，字段至少含 `open/high/low/close/vol/amount`。

## 五、最短路径：构建 QMT 产物

```python
from broker.qmt_builder import build_qmt_strategy, save_strategy
code = build_qmt_strategy(...)   # 模块化研究代码 → 单文件
save_strategy(code, path)        # 输出 GBK 编码单文件
```

产物红线（缺一即视为未完成）：

1. 首行必须是 `# coding=gbk`，文件编码 GBK；
2. 必须内嵌 `BUILD_TAG`（格式 `YYYYmmdd-HHMMSS`），每次构建自动替换，并在 `init(C)` 与日终日志输出；
3. 兼容 Python 3.6.8：**禁止** f-string、`dict[str,...]`、`list[str]`、`str | None`、`:=`、`match/case`；
4. `passorder()` 是全局函数，不是 `C.passorder()`；
5. 账号 ID 硬编码且严格对应：`67014907`（miniQMT / Project_16）、`70180771`（QMT 端 / ATR低波·价值小盘V2）。

## 六、上线前必须过的两道关

| 关卡 | 内容 | 门槛 |
| --- | --- | --- |
| 回测验证 | `projects/verification/` | B 模块（B-1~B-8）**全部**通过 + D 模块（D-1~D-7）至少 D-1/D-2/D-6 |

因子/策略的量化判定阈值（审计框架）：**IC ≥ 0.03、ICIR ≥ 0.3、五分位单调、Calmar ≥ 0.6**。

## 七、五个新手最容易踩的坑

1. **财务数据前视偏差**：必须用 `data/astock_finance_reader.py`（按 `ann_date`/`f_ann_date` 对齐），直接 `merge` 报告期会引入未来函数。
2. **`Updatedata/` 目录是人工周更的**，常滞后 7 天以上。任何依赖它的管道都要做「数据新鲜度」硬断言，否则会出现「信号照常产出、收益一笔算不出」的死局。
3. **零产出必须 fail-loud**：回填/统计类任务输出 0 笔不得以 exit 0 报 OK。
4. **`circ_mv` 单位是万元**（30 亿 = 300000）；`moneyflow` 的 `amount` 字段单位也是万元，不要额外 ÷1e4。
5. **策略时间要用 QMT 行情时间** `C.get_current_time()`，不能用 `datetime.now()`（设备 CMOS 时钟可能错乱）。
