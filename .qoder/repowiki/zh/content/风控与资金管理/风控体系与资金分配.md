# 风控体系与资金管理

> 风控分三层，容易混淆：**组合层（调仓日）**、**每日守卫层（每天）**、**实盘执行层（秒级）**。
> 三者互补而非替代；漏任何一层都会出事故。

---

## 一、三层风控对照

| 层 | 代码位置 | 触发频率 | 典型手段 |
| --- | --- | --- | --- |
| 组合层 | `backtest/rebalance.py` | 仅调仓日 | target_weights → 买卖决策；equal / vol_parity / custom / absolute sizing、行业 cap、max_positions、min_position_value、vol_target + leverage |
| 每日守卫层 | `risk/` | **每个交易日** | CrashGuard 崩盘空仓、RegimeGate 低波门控；可跨调仓期强制转现 |
| 实盘执行层 | QMT 内置策略（如 `strategy_p16_g2_bridge_src.py`） | 秒级 | 止损 / 止盈 / 追盈三规则；孤儿持仓纳管；pending 超时重报与撤单 |

---

## 二、每日守卫层详解（`risk/`）

### CrashGuard（崩盘空仓）

```
r_t = 全市场等权日收益（截面均值）
if sum(hist[-crash_lookback:]) <= crash_threshold and cooldown == 0:
    cooldown = crash_cooldown
if cooldown > 0: cooldown -= 1; return True   # 强制空仓
```

- 参数：`crash_lookback=5`、`crash_threshold=-0.07`、`crash_cooldown=5`
- **只治尾部，不做稳态波动率缩放**。这是刻意设计：稳态缩放会踩 vol_target 在 ATR_FIX_v4 上的坑（ATR 波动 ~18.5% > 目标 15% → 永久低仓，削掉复利主力年）。
- 预期效果：压低最大回撤而不显著伤年化。

### RegimeGate（低波动环境门控）

```
rv  = std(hist[-lookback:])
pct = fraction(hist_window < rv)
pct > vol_percentile_threshold  -> 低波动环境，允许持仓
else                            -> 转现
```

- 参数：`regime_lookback=60`、`regime_vol_percentile_threshold=0.50`
- **fail-open**：历史不足 lookback 时返回 False（允许持仓），避免数据缺口误杀
- 与框架既有的 `market_gate`（价格 vs MA）同属 regime 过滤，**二者同开易重复，建议二选一**

### 接入与启用

```python
from risk.daily_overlay import build_daily_risk_overlay
overlay = build_daily_risk_overlay(cfg)
decision = overlay.apply(decision, today, pf, window, strategy_config, industry_map)
```

接入点在 engine 主循环「decision 生成后、成为 pending 前」。要求空仓时复用既有 `target_weights_to_decision({})` 路径产出 full-exit，**不重复实现卖出簿记**。开关默认关闭，未启用时逐笔零影响。

单测：`python risk/test_overlay.py`。

## 三、实盘执行层风控

### 止损 / 止盈 / 追盈三规则（Project_16 已迁入 QMT 内置）

- 触发即 `passorder` 卖出并走 pending；
- fills 的 `reason` 字段透传 `SELL_STOP` / `SELL_TAKE_PROFIT` / `SELL_TRAILING` 供外部对账；
- 成本锚：外部每日写 `cmd/positions_cfg_<date>.json`；
- 追盈峰值 `state/peak.json` **跨日持久化**；
- `risk_sold` 防重复卖出 + 心跳快照恢复；
- 孤儿持仓**只纳管不误杀**（账户有票但账本无记录，不纳管则止损/止盈永不触发）。

### 大盘门控（回测侧）

Project_10 实测：大盘 MA200 门控使最大回撤从 -29.7% 改善到 -15.8%，代价是年化 -4.4pp。是否启用取决于收益/回撤偏好。

### 已知被证伪的风控/权重方案

- **ATR 反权**：负优化
- **持有期软化**：负优化
- **EP 混入**：负优化
- **行业 cap**：无显著影响
- **稳态 vol_target（在 ATR 策略上）**：因 ATR 自身波动已高于目标，退化为永久低仓

| 账号 | 用途 | 通道 |

- G2 与 V1.3 完全隔离：独立配置 `g2_config.py`（绝不 import V1.3 的 `qmt_config`）、独立资金池 `D:/QMT_POOL/g2_bridge/g2_strategy_capital.json`、独立候选 `g2_top2`（不是 `D_model_top10`）、持仓只认 G2 账本，G2 绝不调 `qmt_trader`。
