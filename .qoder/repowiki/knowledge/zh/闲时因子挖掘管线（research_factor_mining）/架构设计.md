# 闲时因子挖掘管线 — 架构设计

## 阶段流水线（S0→S4）
```
S0 候选登记（DE+人工）     candidates/batch_<id>.yaml（表达式/逻辑/数据源/direction_hint）
S1 截面IC初筛（脚本）      run_screen.py：月频 Spearman IC，只淘汰不入选
S2 训练集验证（脚本）      2021-23，ICIR≥0.5 + 正值占比≥60% + 逐年同号
S3 样本外回测（脚本）      backtest/engine.py 真实约束（试点 0 幸存者未触发）
S4 上线门槛（监控+裁决）   factor_health 扩容 + gpsj 交叉验证 + DE 裁决 + 人工拍板
```

## 文件结构
```
research_factor_mining/
  survey_data.py             数据普查（方向A三源+财务8表）
  run_screen.py              S1+S2 批量 IC（口径对齐 factor_health）
  factor_defs_pilot.py       候选因子实现（40 个）
  candidates/batch_*.yaml    S0 登记台账
  ic_screen/batch_*_report.md + _ic.csv
  survey_report.md / 试点报告_*.md
```

## 数据源与 ctx 面板
- `fin_wide`：财务 PIT 宽表 {field: 调仓期×code}（ann_date 锚后 ffill，27 个字段含同比/单季）
- `north_ratio/north_vol`：北向持股日频面板（2016-06 起）
- `lhb_net/lhb_rate/lhb_flag`：龙虎榜事件面板（2005 起，稀疏）
- `res_cnt/res_rate`：研报事件面板（2006 起，稀疏；MultiIndex 顺序 (ts_code, report_date)）
- 事件型因子用 `_fill0`（未上榜/未覆盖填 0）保持横截面完整

## Universe 与收益口径
- 小盘域：circ_mv 0~30亿 + pe_ttm>0 + pb>0 + 非ST + 非停牌
- 月频调仓（月末最后交易日）；前向=期i T+1开 → 期i+1 T+1开（Spearman IC，与 factor_health 对齐）
- direction_hint 翻转后判定（正值=方向正确）

## 调度窗口（设计）
- 周六 09:00-周日 22:00：S1+S2 重计算（正式批次 500-1000 表达式/双周）
- 交易日 20:30-23:30：S3 样本外回测（≤10 个/夜）
- 禁用：01:00-01:30 检修、交易链路/日终/夜间数据窗口
- 输出独立目录，不碰 D:/QMT_POOL；调度复用 de_guard_runner 模式（fail-loud + 飞书卡）
