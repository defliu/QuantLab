# 闲时因子挖掘管线 — 概述

## 定位
利用周末/晚间闲时算力，系统性批量挖掘横截面候选因子，通过科学筛选纪律寻找 BP 之外的排序 alpha。
背景与可行性论证：`data/schedules/de_factor_mining_20260916.md`（DE 评估）→ 试点报告 `research_factor_mining/试点报告_20260916.md`。

## 为什么需要
- 全库健康排序因子只有 BP 一个（factor_health），因子库扩展是研究路线图 P2 项；
- 历史证伪率极高（462 因子→训练集 11 有效→样本外 0 转正），必须纪律化、批量化为成本可控的重复劳动。

## 核心纪律（防过拟合，硬编码进脚本）
- 三段切分固定：训练段 2021-2023 / 样本外 2024-2026 / 全期只作淘汰参考；
- S0 先登记后运行（YAML 预登记表达式+经济逻辑），禁止跑完补假设；
- S1 只淘汰不入选（|全期IC|<0.02 或训练段与全期反号 → 弃）；
- S2 训练段 ICIR≥0.5 且正值占比≥60% 且逐年同号才晋级；
- 0 通过如实记录，不为产出放宽门槛。

## 试点结论（2026-09-16）
- 管线全流程跑通，40 因子×103 期=127s（远超 DE 估算，单周末可跑 3000-5000 表达式）；
- 存活漏斗 40→11→0；
- 关键发现：北向持股水平、龙虎榜上榜频率、研报覆盖在小盘域是**稳定负向因子**（2021-23 逐年全负），具备排雷/门控潜力（ATR MAX5 减法先例），待 ablation 验证。

- DE 第 2 轮（`data/schedules/de_factor_mining_r2_20260916.md`）上网检索 6 主题（Crossref/Semantic Scholar）：龙虎榜=注意力反转、研报覆盖=忽视溢价、北向负超额=自有实证、Sloan 应计、MAX 彩票、LSY 壳价值。

## AMT_RATIO 域内排除验证收尾（2026-09-17，DE 执行 + opencode 独立复核）

- 背景：R2 漏斗越过 PX_AMT_RATIO_20D，简化版 ablation 报 +2.65pp 最强。为判定是否落地 ATR 实盘参数，委派 DE 做真实约束回测（`run_amt_exclude_engine.py`，backtest/engine 同口径）。
- **结论：+0.00pp，不落地。** base 与 excl（生产池 eligible 内部再剔 top20%）逐位一致（cagr 0.1691/sharpe 0.898/trades 666）。
- 证据链：①excl 诊断 excluded_avg=2.90/eligible_left_avg=11.57（排除真跑）；②diag_amt_overlap 31 季被选 ATR%最低8只与高活跃剔除集 overlap≈0（生产池全季=0）；③被选股 amt_ratio 分位中位普遍<0.2。
- **根因**：ATR 按 ATR% 升序取前8 + 换手≤8% 硬过滤，amt_ratio≈换手率与低波偏好天然正交 → 域内再排除冗余。
- **+2.65pp 证伪**：简化版为 19期vs基线20期、CAGR 用 nav^(4/len) 折算的期数伪差（剔除后真实增量约+0.4pp），且用非生产小盘池。
- **判定纪律**：增益未达 >+0.5pp → 不落地。ATR 本体不受影响，继续实盘。
- 结题报告 `amt_exclude_engine_结题.md`；验证版 `strategy/atr_lowvol_amt_exclude.py`（研究用，amt_exclude_pct=0 时与生产一致）。
