# 闲时因子挖掘管线 — 概述

## 定位
利用周末/晚间闲时算力，系统性批量挖掘横截面候选因子，通过科学筛选纪律寻找 BP 之外的排序 alpha。
背景与可行性论证：`data/schedules/de_factor_mining_20260916.md`（DE 评估）→ 试点报告 `research_factor_mining/试点报告_20260916.md`。

## 为什么需要
- 全库健康排序因子只有 BP 一个（factor_health），因子库扩展是研究路线图 P2 项；
- 历史证伪率极高（462 因子→训练集 11 有效→样本外 0 转正），必须纪律化、批量化为成本可控的重复劳动。

## 核心纪律（防过拟合，硬编码进脚本）
- 三段切分固定：训练段 2021-2023 / 样本外 2024-2026 / 全期只作淘汰参考；
- S0 先登记后运行（YAML 预登记表达式+经济逻辑），禁止跑完补假设；
- S1 只淘汰不入选（|全期IC|<0.02 或训练段与全期反号 → 弃）；
- S2 训练段 ICIR≥0.5 且正值占比≥60% 且逐年同号才晋级；
- 0 通过如实记录，不为产出放宽门槛。

## 试点结论（2026-09-16）
- 管线全流程跑通，40 因子×103 期=127s（远超 DE 估算，单周末可跑 3000-5000 表达式）；
- 存活漏斗 40→11→0；
- 关键发现：北向持股水平、龙虎榜上榜频率、研报覆盖在小盘域是**稳定负向因子**（2021-23 逐年全负），具备排雷/门控潜力（ATR MAX5 减法先例），待 ablation 验证。

## 正式批次 R2（2026-09-16，DE 上网学习后设计 + TRAE 落地）
- DE 第 2 轮（`data/schedules/de_factor_mining_r2_20260916.md`）上网检索 6 主题（Crossref/Semantic Scholar）：龙虎榜=注意力反转、研报覆盖=忽视溢价、北向负超额=自有实证、Sloan 应计、MAX 彩票、LSY 壳价值。
- 落地 `factor_defs_r2.py` 40 候选（北向自身分位 8 / 龙虎榜席位结构 7 / 研报修正分位 8 / 财务背离 8 / 价格行为 9），**漏斗 40→S1 17→S2 通过 10**——全部负向因子（hint=-1 翻转后通过），价值出口=排雷排除条件。
- 排雷五分位尾部诊断（`run_exclude_diag.py`）：**PX_MAX20/PX_AMT_RATIO_20D/PX_VOL_STD20/PX_LISTED_NEW 4 个确认尾部驱动**（排除高暴露组有增益），其余 6 个单调反向。
- 数据坑修正：DE 误判 top_inst 未落盘（实测已存在 2012-2026，167 万行），LHB_INST_* 2 条已解锁。

## AMT_RATIO 域内排除验证收尾（2026-09-17，DE 执行 + opencode 独立复核）

- 背景：R2 漏斗越过 PX_AMT_RATIO_20D，简化版 ablation 报 +2.65pp 最强。为判定是否落地 ATR 实盘参数，委派 DE 做真实约束回测（`run_amt_exclude_engine.py`，backtest/engine 同口径）。
- **结论：+0.00pp，不落地。** base 与 excl（生产池 eligible 内部再剔 top20%）逐位一致（cagr 0.1691/sharpe 0.898/trades 666）。
- 证据链：①excl 诊断 excluded_avg=2.90/eligible_left_avg=11.57（排除真跑）；②diag_amt_overlap 31 季被选 ATR%最低8只与高活跃剔除集 overlap≈0（生产池全季=0）；③被选股 amt_ratio 分位中位普遍<0.2。
- **根因**：ATR 按 ATR% 升序取前8 + 换手≤8% 硬过滤，amt_ratio≈换手率与低波偏好天然正交 → 域内再排除冗余。
- **+2.65pp 证伪**：简化版为 19期vs基线20期、CAGR 用 nav^(4/len) 折算的期数伪差（剔除后真实增量约+0.4pp），且用非生产小盘池。
- **判定纪律**：增益未达 >+0.5pp → 不落地。ATR 本体不受影响，继续实盘。
- 结题报告 `amt_exclude_engine_结题.md`；验证版 `strategy/atr_lowvol_amt_exclude.py`（研究用，amt_exclude_pct=0 时与生产一致）。

## 2026-11-01 通宵复核（管线停摆 + 口径修复，三处断点全修）

- **停摆事实**：`ic_screen/` 自 2026-09-16 后**零新增批次**（只有 pilot + r2 两批）；`de_factor_mining_r3_prompt_*.txt` 09-25/10-02/10-09/10-16/10-23/10-30 **6 份全 2398B 逐字相同、从未被消费**，`de_factor_mining_r3_*.md` 一个都没有 ⇒ **6.5 周零新增信息，但三任务每周照常 `Ready`**。
- **三处断点**：①Design 腿 `deveco.cmd` 经 `cmd.exe` 引号被吞 → DE 从未启动（`factor_design_de_err.log` 129B 实证），且 `Start-Process -PassThru` 无 `-Wait` 时 `.ExitCode` 恒 `$null`（`$null -ne 0` 为真）→ 一切判失败，成功 run 又被 `$timedOut = -not HasExited` 丢弃；②Screen 腿 `run_latest_batch.py:37` 打印 `✅` 在 GBK 管道抛 `UnicodeEncodeError` → **连续 7 周 rc=1**，ps1 据此推「周末批失败」假告警；③Ablation 腿每周用同一份 r2 旧数据重算、把**已证伪的 +2.65pp 重新推飞书**，`exit 0`。
- **修复**：Design 改 native `deveco.exe`（0.2.4）+ `--auto` + .NET `ProcessStartInfo` + `$stillRunning`/`$timedOut = $stillRunning -and (-not $done)`；Screen 加 `_safe_stdout()`（`reconfigure(encoding="utf-8", errors="replace")`）；Ablation 改为共同网格 + 真实日历年化 + 双动量口径 + 旧口径逐字复刻。
- **独立复核结论（不采信生成报告）**：AMT@20% 增益三口径 = 真实约束 **+0.00pp**（base/excl 逐位一致、`amt_excl_by_rebalance=[]`）/ 共同网格 legacy **+0.40pp** / 生产 12-1 **+0.20pp**，均未达 >+0.5pp 落地阈值；机制 = `amt_ratio≈换手率` 与 ATR 低波偏好天然正交（31 季重叠 0）；增益来源 = 极少数期换 1 只票（AMT@20% 仅 5/19 期），组合4 在 std 口径下直接 **−1.32pp** ⇒ 单票运气非 alpha。
- **落地判定：4 个 PX 排雷因子归档，不进实盘参数**（`atr_lowvol.py` `max_exclude_pct` 保持 0，ATR 本体不动）。`LHB_AMOUNT_RATE_20D`/`LHB_BUY_RATIO_20D` 分位数字字节级相同 ⇒ 去一留一；`HK_*`/`RES_*`/`FIN_*` 尾部不显著。
- **口径声明：单源结论（仅 astock），未经备用源交叉验证**（gpsj 不可用）。
- 判定文档 `research_factor_mining/因子挖掘管线复核与利用判定_20261101.md`；分支矩阵回归 `_test_factor_design_branches.py`（26 断言 / 0 失败）。
