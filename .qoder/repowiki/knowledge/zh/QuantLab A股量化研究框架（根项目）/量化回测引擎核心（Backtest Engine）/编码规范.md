- 所有外部输入（slippage/commission_rate/tax_rate/position_sizing 等）均通过 `cfg.get(..., default)` 读取并显式 `float()/int()` 转换，避免类型错误。
- 函数返回采用 `(trade_or_None, unfilled_reason_or_None)` 二元组模式（execution.fill_buy/fill_sell），未成交原因用字符串常量标识（suspended/limit_up_at_open/below_min_lot 等）。
- 每日日志统一以 `[INFO]` / `[ERROR]` 前缀追加到 `daily_logs` 列表，最终由 report 聚合写入 logs.txt。
- 数值字段在输出前统一 `round(x, 6)` 或 `round(x, 8)` 控制精度，避免浮点漂移污染 CSV。
- 模块顶部注释明确声明 frozen contract（trades.csv 列、equity_curve 列、position 列、WARN 块格式），变更需保持向后兼容。
- 可选功能通过 config 开关控制（如 `sector_heat_mode=zero`、`benchmark_available=False`、`pit_universe.enabled`），缺失时回退到安全默认值而非抛异常。
