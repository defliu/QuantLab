本模块为扁平脚本集合，每个文件是一个可独立运行的CLI或QMT策略入口，无共享包结构：
- 回测入口 `run_backtest.py` 通过 argparse 解析 --config YAML，调用 `backtest.engine.run_backtest` + `data.astock_reader.AstockParquetReader` + `backtest.report` 写入 reports 目录，明确声明不导入 xtquant/passorder。
- 数据更新 `update_data.py` 从 `E:/量化/行情数据更新池` 扫描含“增量”的目录，增量合并 stock_daily.parquet 并重新生成 `D:/QMT_POOL/mfic_fin_data.csv`。
- 因子IC批量测试 `batch_ic_test.py` 加载 alpha101/gtja191 因子注册表，计算 Spearman IC/ICIR 并输出 `reports/factor_ic_report.csv`。
- QMT 策略脚本（`strategy_mfic_sim.py`、`strategy_mfic_sim_gbk.py`、`test_passorder.py`、`test_passorder_with_monitor.py`）遵循 miniQMT 约定的 `init(C)` / `handlebar(C)` 回调接口，使用 `passorder` API 下单。
- Windows 批处理（`.bat`）作为一键启动器，固定 cd 到 E:\QuantLab 后调用对应 Python 脚本。
依赖方向单向指向项目根目录下的 backtest/data 包及外部 parquet/csv 数据源，脚本之间互不引用。
