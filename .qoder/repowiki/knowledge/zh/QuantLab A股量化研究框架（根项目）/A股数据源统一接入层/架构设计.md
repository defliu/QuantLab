模块以 `feed.py` 中的 `DataFeed` 类作为统一入口，通过构造参数 `source="astock"|"duckdb"` 在运行时切换后端实现：astock 路径直接读本地 parquet 文件，duckdb 路径委托 `backtest.data_tools.duckdb_reader.DuckDBDailyReader`。各 reader 遵循一致的 duck-typed 四方法契约（`load_window` / `trading_calendar` / `coverage` / `close`），使上层无需感知具体存储形式。

- 日线数据：`astock_reader.AstockParquetReader`（parquet 多索引）与 `duckdb_reader.DuckDBDailyReader`（支持 jince_zhisuan 与 qmt_self_owned 两种 schema）并行存在，输出统一为 `{code: DataFrame(date, open, high, low, close, vol, amount)}`。
- 财务数据：`astock_finance_reader.AstockFinanceReader` 实现 PIT（Point-in-Time）防前视逻辑，基于 `fina_indicator.parquet` 的 `ann_date/f_ann_date <= asof_date` 选取最新季度，并叠加 `stock_daily.parquet` 的 PE 快照。
- 基准指数：`benchmark_reader.BenchmarkIndexReader` 独立读取 `benchmark_index.duckdb` 的 `index_daily` 表，与主 DuckDB 解耦。
- 股票池与行业：`universe.py` 校验 CSV 格式并返回有效 code 列表；`industry_map.py` 缓存 `stock_basic.parquet` 的 ts_code→申万行业映射。

依赖方向单向向下：`feed.py` → 各 reader → pandas/pyarrow/duckdb；reader 之间互不引用，仅通过约定接口被上层消费。
