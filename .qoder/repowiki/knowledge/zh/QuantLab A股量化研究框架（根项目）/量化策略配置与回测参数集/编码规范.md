- 回测配置统一采用扁平 YAML 结构，顶层键固定为 backtest/data/universe/execution/strategy/strategy_params，便于框架直接映射到对象字段。
- 策略参数通过 `strategy_params` 子树传递，组合层开关（position_sizing/target_leverage/vol_target/industry_cap 等）以数值 0 表示关闭、非零启用，形成统一的开关约定。
- 数据路径使用 Windows 风格反斜杠或 Unix 风格正斜杠混用（如 `E:\...` 与 `E:/...`），由上层加载器统一处理，配置文件中不做转义。
- 同一策略的多场景通过复制基础 YAML 并修改关键参数（如 target_leverage、position_sizing）生成变体文件，文件名以 `_leverage_only`、`_leveraged` 等后缀区分。
