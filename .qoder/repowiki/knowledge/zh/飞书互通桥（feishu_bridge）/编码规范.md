# 编码规范

## 强制规则（继承项目 AGENTS.md）

1. **绝不裸调 lark-cli**。一律经 `bridge.py`，它内部的 `clean_env()` 会清掉
   `OPENCLAW_CLI` / `OPENCLAW_HOME` / `HERMES_HOME` / `LARK_CHANNEL`，
   否则 lark-cli 会以「not bound」拒绝执行。
2. **含中文的 `.ps1` 必须保持 UTF-8 BOM**（项目规则 T-20260903-015）。
   每次编辑 `start_feishu_listen.ps1` 后必须回读首字节验证 `EF BB BF`，
   否则 PowerShell 5.1 按 GBK 解码会吞引号并级联「意外的标记」解析错误。
3. **计划任务注册必须用 `Register-ScheduledTask` 对象方式**
   （`New-ScheduledTaskAction` / `-Trigger` / `-Principal`），
   禁止 XML / `schtasks` 命令行拼接（中文路径会 UTF-8→Latin-1 乱码）；
   注册后必须回读 `Actions.Arguments` 核对实际存储值。
4. **LogonType 一律 `S4U`**、`RunLevel=Limited`，与既有 QuantLab_* 任务保持一致。

## 本模块特有约定

- **幂等键用 `message_id`，不用 `event_id`**（飞书官方建议，`event_id` 会重复投递）。
- **必须过滤 `sender_type == "bot"`**，否则机器人自己的回复会被当成新消息，形成自问自答死循环。
- **状态文件 append-only**：`inbox.jsonl` 只追加不重写；`processed.json` 才做整表写回。
- **发送类操作需显式目标**：`send` 默认私聊诚哥，发群必须显式 `--chat-id`。
- **不静默丢弃消息**：无法回答也要回复说明原因与下一步。
- 涉及实盘下单 / 改策略参数的消息，**只给建议、不执行**。

## 安全

- `~/.lark-cli/config.json` 与 P16 推送**共用**，任何 `config init` / 新建应用操作前
  **必须先备份**（现有备份 `config.json.bak_20261009`）。
- 明文 App Secret 一律视为泄露。
