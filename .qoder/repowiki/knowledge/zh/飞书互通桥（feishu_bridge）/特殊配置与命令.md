# 特殊配置与命令

## 常用命令

```bash
PY="C:/Users/Administrator/.workbuddy-ai/binaries/python/versions/3.13.12/python.exe"

# 健康检查（bot 身份 + token 状态）
"$PY" scripts/feishu_bridge/bridge.py whoami

# 查看未处理消息
"$PY" scripts/feishu_bridge/bridge.py pending

# 主动私聊诚哥
"$PY" scripts/feishu_bridge/bridge.py send --text "盘后复盘已完成"

# 回复某条消息（自动标记已处理）
"$PY" scripts/feishu_bridge/bridge.py reply --message-id om_xxx --text "收到"

# 兜底抓取（常驻监听掉线时）
"$PY" scripts/feishu_bridge/bridge.py pull --minutes 5

# 常驻监听（前台调试用）
"$PY" scripts/feishu_bridge/listen.py
```

## 计划任务运维

```powershell
# 查看状态
Get-ScheduledTask -TaskName "QuantLab_FeishuListen_*" | Select TaskName, State

# 手动拉起（幂等，已在跑则退出）
Start-ScheduledTask -TaskName "QuantLab_FeishuListen_Guard"

# 查看监听进程
Get-Content D:\QuantLab\data\feishu_bridge\listen.pid
Get-Content D:\QuantLab\data\feishu_bridge\listen.log -Tail 20
```

## 状态文件

| 文件 | 说明 |
|---|---|
| `data/feishu_bridge/inbox.jsonl` | 收到消息（append-only） |
| `data/feishu_bridge/processed.json` | 已处理 message_id |
| `data/feishu_bridge/listen.log` | 监听日志（含 `ready` / `websocket: connected`） |
| `data/feishu_bridge/listen.pid` | 守护进程 pid |
| `data/feishu_bridge/pull.log` | `pull` 子命令运行日志 |

## 故障排查

| 现象 | 根因 | 解决 |
|---|---|---|
| `openclaw context detected but lark-cli is not bound` | Agent 环境变量存在 | 用 `bridge.py`，不要裸调 lark-cli |
| `230027 access denied` | 应用缺对应 scope | 到飞书开放平台申请（如 `im:message:readonly`） |
| `99992354 not a valid open_message_id` | 应用缺 `im:message` 系列 scope（权限掩码），按 message_id 定位失败 | `bridge.py reply` 已自动回退为按 `chat_id` 发新消息 |
| 报「该消息不在 inbox 中」 | **手抄 message_id 出错**（实测漏抄一个字符，肉眼看不出差别） | **ID 一律从 `inbox.jsonl` 或 JSON 输出程序化读取，不要手打** |
| `open_id cross app` | 用了别的应用维度的 open_id | 换成本应用下的 open_id |
| 监听进程不在 | 进程被结束 | 等 Guard（≤5 分钟）自愈，或手动 `Start-ScheduledTask` |
| ps1 报「意外的标记」 | BOM 丢失 | 重新写入 UTF-8 BOM |
| 事件长连接无输出 | 无消息到达（正常） | `--timeout` 到点以 `reason: timeout` 退出属正常 |
