# Project_22 RPS每日监控 — 技术栈

- **运行环境**：研究层 Python 3.11（本机 `D:\Python311\python.exe`，pandas 3.0.5 / pyarrow 25.0.1 / numpy 2.4.6 / pyyaml）。**不受 QMT Python 3.6.8 兼容约束**（非 QMT 产物），但保持朴素语法风格、不引入 f-string 以外的新语法糖。
- **数据源**：`D:/astock/daily/stock_daily.parquet`（只读，pyarrow `read_table` 列裁剪 + filters 下推；严禁全量加载）。
- **外部接口（enrich，观察标注用）**：复用 `data/astock_kit.py` 的 `em_zt_pool`（涨停池，日期 YYYYMMDD）与 `ths_hot_reason`（同花顺题材，日期 YYYY-MM-DD，两者格式不同）；网络失败统一返回 [] 按降级处理，不阻断。
- **并发**：`ThreadPoolExecutor` 预取 enrich；astock_kit 模块级限流器非线程安全，用 `_ZT_LOCK` 串行化涨停池请求。
- **状态持久化**：parquet（pyarrow engine）。
- **Windows 峰值内存**：ctypes `GetProcessMemoryInfo`（PROCESS_MEMORY_COUNTERS），psutil 兜底。
- **调度**：Windows Task Scheduler 任务 `Quant_P22_RPS_Daily`（周一至周五 18:30，`DaysOfWeek=62`），入口 `scripts/run_rps_daily.ps1`。交易日判定两层：任务触发器只过滤周末，脚本内再查 `D:\astock\daily\stock_daily.parquet` 目标日是否已有行情（谓词下推窗口 −60/+30 天，约 1~2s）。
- **调度脚本运行环境**：Windows PowerShell 5.1（`powershell.exe -File`，非 pwsh）。因此 `run_rps_daily.ps1` **必须带 UTF-8 BOM**（含中文，无 BOM 会被按 ANSI/GBK 解码吞引号导致级联解析错误）。
- **结果通知**：复用 P16 的 `lark_push.py`（CLI 子进程调用 `--file/--user-id/--title`，不走 import）。收件人 `FEISHU_OPEN_ID` 由 wrapper 运行时正则提取自 P16 `qmt_config.py`，**P22 侧不留副本常量**。
