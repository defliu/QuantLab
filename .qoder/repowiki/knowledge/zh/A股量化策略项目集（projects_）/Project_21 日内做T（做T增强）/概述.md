# Project_21 日内做T（做T增强）概述

## 项目定位
在现有 T+1 策略持仓之上，叠加日内「正T（先买后卖）」与「反T（先卖后买）」增强收益，**净持仓过夜不变**，仅利用日内波动率获取超额收益。

## 核心约束（预注册，不可事后修改）
| 约束项 | 规范 |
|--------|------|
| 入场价格 | 信号触发根 bar 结束，**下一根 1min bar 的 open**（t+1 bar open） |
| 出场价格 | **14:50 强制平仓**（最后一根 bar close），不持仓过夜 |
| 最小成交量 | **≥ 100 股**（零股直接跳过，不计入统计） |
| 候选密度指标 | **双指标并列**：每股日均信号数 + 每百股日均信号数 |
| 参数模式 | **预注册参数**，严禁参数扫描/过拟合 |
| 统计检验 | **按交易日聚类的稳健 t-stat**（Cluster-robust t-stat at trade-day level） |

## 成本模型（分段，唯一权威实现 `strategy/signals/base.py:get_cost_model()`）
- **2023-08-28 前**：往返 **25.4bp**（佣金 2.5×2 + 印花税 5×2 + 过户费 0.2×2 + 滑点 5×2）
- **2023-08-28 后**（印花税减半）：往返 **20.4bp**
- 回测必须按实际日期应用对应成本段，严禁用单一成本贯穿全期；事件表 `pnl_bps` **已含成本**，禁止重复扣

## 交易品种
- **标的池**：A股全市场中波股票（振幅 2.5%-8%、日均成交额 ≥ 0.5 亿、流通市值 20-5000 亿、上市 >1 年、剔除 ST/退市/北交所/次新），标准见 `config/midvol_criteria.yaml`（criteria 静态标准数 3383）
- **扫描实际池**：体检明细过滤后 **3055 只**（静态池，按 2009-2026 全周期中位数建池 → **存在宇宙 look-ahead**，Phase 2 须做动态池复核）；逐年有信号事件股票 2121（2019）→ 3018（2024）
- **调仓频率**：月度（每月 1 号复核）

## 信号族系（F1-F6，预注册参数）
| 族 | 名称 | 核心逻辑 | 亚型 |
|---|---|---|---|
| F1 | 集合竞价 | 开盘竞价价量偏离捕捉隔夜信息冲击 | LONG/SHORT |
| F2 | 早盘动量/反转 | 9:30-10:00 价量行为判断趋势延续 vs 反转 | MOM_LONG/SHORT, REV_LONG/SHORT |
| F3 | VWAP 偏离 | 价格偏离 VWAP 的均值回归 | LONG/SHORT |
| F4 | 量能结构 | 开盘 30min 量能分布（前重/后重）判断主力意图 | FRONT/BACK_LONG/SHORT |
| F5 | 缺口回补 | 隔夜跳空缺口回补概率 | GAP_UP/DOWN_FILL |
| F6 | 脉冲回归 | 5min z-score 捕捉超买超卖瞬时机会 | LONG/SHORT |
