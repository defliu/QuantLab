## 防前视设计（核心工程约束）
1. **入场价 = t+1 bar open**：信号在 bar `i` 触发，入场价取 `i+1` bar 的 open
2. **出场价 = 14:50 bar close**：所有未平仓在 14:50 强制平仓
3. **数据可用性检查**：计算信号时仅使用 `≤ trigger_bar_idx` 的数据
4. **VWAP 实时累计**：`Σ(amount[:i]) / Σ(vol[:i])`，不使用全日 VWAP
5. **成本模型分段**：按 trade_date 选用对应成本段（2023-08-28 分界）

## 并行化策略
- **数据加载层**：`load_reference_data()` 一次性加载 auction + stock_basic（~30M 行，内存常驻）
- **日度扫描层**：`scan_period()` 逐日串行（保持时间序列完整性），单日内股票级并行（`ProcessPoolExecutor`）
- **信号计算层**：单股单日 F1-F6 串行（信号间无依赖，可进一步并行优化）

## 输出数据结构
```python
@dataclass
class SignalEvent:
    ts_code: str              # 证券代码
    trade_date: str           # YYYYMMDD
    family: str               # F1-F6
    signal_type: str          # LONG/SHORT + 细分
    trigger_bar_idx: int      # 触发时 1min bar 索引
    trigger_time: str         # HH:MM
    trigger_price: float      # 触发价（仅参考）
    entry_price: float        # 入场价 = t+1 open
    exit_price: float         # 出场价 = 14:50 close
    direction: int            # +1 买入(正T) / -1 卖出(反T)
    shares: int               # 预估成交股数（<100 跳过）
    pnl_bps: float            # 单笔收益 bps（含成本）
    cost_bps: float           # 单笔成本 bps
    holding_bars: int         # 持仓分钟数
```
