## 统计计算栈
| 需求 | 实现方式 |
|------|----------|
| 聚类稳健 t-stat | `linearmodels.iv.panel.compare` 或手写：按 trade_date 分组计算日均超额收益，再用标准误公式 |
| 年化夏普 | `np.sqrt(242) * mean(daily_excess) / std(daily_excess)`（日频超额收益） |
| 最大回撤 | `(cummax - current) / cummax` 滚动计算 |
| 胜率 | `sum(pnl > 0) / count` |
| 候选密度 | 双指标：`total_signals / n_stocks / n_days` + `total_signals / n_days / 100 * 100` |
