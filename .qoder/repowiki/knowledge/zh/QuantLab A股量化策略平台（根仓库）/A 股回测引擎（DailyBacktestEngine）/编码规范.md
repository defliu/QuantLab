- 执行器、撮合器、组合、分析器等层均声明为无 IO、无全局状态、无随机性的纯函数/纯数据结构模式，所有副作用集中在 engine 与 report 两端的边界。
- 对 A 股价格约束使用集中式规则函数（execution._price_limit 依据 code 前缀 / is_st 推断涨跌停幅度），在 buy/sell 中复用而非各自硬编码。
- 交易日志与诊断以结构化 dict 形式在各层间传递（diagnostics['warnings'] / logs 列表），report 再序列化为 warn block 文本。
- CSV 输出采用显式列顺序常量（_TRADES_COLS、_EQUITY_COLS、_POSITIONS_COLS）并通过统一 _write_csv 写入 UTF-8-sig，保证列顺序作为 frozen contract。
- 运行时标识使用哈希派生：_make_run_id 结合时间戳 sha256 短码，hashing.compute_*_hash 对 universe/data/config 计算稳定摘要，用于 results 子目录命名与 summary 追踪。
- 数值四舍五入统一保留 6 或 8 位小数（金额/价格 round(...,6)，收益率 round(...,8)），避免浮点累积误差在资产合计中扩散。
