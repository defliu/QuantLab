模块按职责划分为四个紧密耦合的层，通过明确的函数契约解耦：
- engine.py 提供 `DailyBacktestEngine` 编排入口，按交易日历推进 T→T+1 open 撮合；内聚 benchmark 系列加载（BenchmarkIndexReader）、run_id 生成、市场数据 window 切片预计算（searchsorted cut_index）、每日警告去重与 strategy_specific 指标聚合等横切逻辑。
- execution.py 是纯函数撮合层，封装涨跌停幅度判定（双创/北交/主板/ST）、lot 取整、滑点/手续费/印花税计算、next_open 模型下的 buy/sell 成交与拒绝分支（suspended/limit_up/down/no_target_cash/capacity_exceeded），返回符合 trades.csv 13 列契约的 trade 字典。
- portfolio.py 以 Portfolio 类维护 cash/positions/available_volume（T+1 冻结买入可用券），实现 mark_to_market、advance_holding_days、apply_trade 和 equity/positions 行构建。
- rebalance.py 提供通用 target_weights → sell_decisions + buy_candidates 转换，内置 equal/vol_parity/custom/absolute 仓位 sizing、行业 cap、max_positions、min_position_value、vol_target + leverage 缩放等可配置风险叠加。
- analyzer.py 纯 numpy 计算 total_return / CAGR / max_drawdown / sharpe / calmar / win_rate / avg_holding_days / excess_return / tracking_error 等业绩指标。
- report.py 负责写 disk，约束 frozen CSV 列序（trades/equity_curve/positions），组装 logs.txt 中的 WARN block 与 report.md 汇总报表。
- hashing.py 统一计算 universe_hash / data_hash / config_hash，配合 engine._make_run_id 完成 run 溯源。
依赖方向单向：engine → (execution, portfolio, analyzer, rebalance) → (report)，无双向 import，数据仅通过 dict/DataFrame 契约传递。
