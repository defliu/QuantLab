因子库无独立配置文件，参数通过 `FactorBase` 子类构造与 `FactorEngine.compute_*` 传参注入；常用命令如下。

**因子库结构自检**：`python scripts/check_factor_lib.py` —— 校验 `factors/*.py` 中因子模块可导入、`FactorBase` 契约（name / category / compute）成立、`FactorEngine` 注册表可用。注意该脚本 2026-08-29 已重写：旧版检查 `backtest/factors/zoo/{alpha101,gtja191}` 与 `backtest/factors/registry.py`，这三个路径在本仓库**从未存在**（E 盘旧开发机布局残留），一跑就 `FileNotFoundError`。

**批量 IC 测试**：`python scripts/batch_ic_test.py`（Windows 快捷入口 `scripts/run_batch_ic_test.bat`）。

**因子健康监控**：`python research_audit/factor_health.py`（另有 `scripts/run_factor_health.bat`），产出 `factor_health_报告.md` 与 `factor_health_ic.csv`。

**事件型因子审计**（`factors/factor_audit.py`，2026-09-05 从「60线归位战法」审计中固化）：

```python
from factor_audit import load_panel, quick_audit
panel = load_panel()
res = quick_audit(panel, signal=my_signal_matrix,   # bool DataFrame 宽表对齐
                  entry=3, holds=[20, 60, 120], stops=[0.0, 0.08])
```

判定门槛：真实信号须位于随机分布 **95 百分位**以上。基准必须用**买入并持有**，禁止用「每日调仓的池内等权净值 cumprod」。
