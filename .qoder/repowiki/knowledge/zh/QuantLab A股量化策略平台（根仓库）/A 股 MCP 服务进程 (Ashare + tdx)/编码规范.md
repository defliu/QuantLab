- 所有 MCP 工具统一以 `@mcp.tool()` 装饰函数声明，参数为原始类型，返回值一律序列化为 JSON 字符串供 Agent 消费。
- DuckDB 查询复用 `get_duckdb_conn(db_name)` 建立的只读连接池 `_duckdb_conns`，按数据库文件名缓存，禁止每次请求新建连接。
- 所有外部调用（尤其是 QMT xtquant）通过统一入口 `XTQuantBridge.call(func, *args, **kwargs)` 包装为 JSON stdin/stdout 通信，并在超时或异常时返回 `{"error": ...}` 而非抛到上层。
- 代码中硬编码的绝对路径集中在顶层配置区（`QMT_PYTHON` / `QMT_SCRIPT` / `DUCKDB_DIR` / `SERVER_HOST` / `SERVER_PORT` / `LOG_LEVEL`），便于集中修改部署位。
- 股票代码在使用前统一 `.upper()` 规范化后再进入 DuckDB 或 xtquant 调用。
