- 手动启动：`python mcp_server.py`（系统 Python 3.12），监听 `http://0.0.0.0:8000/mcp`
- 作为 Windows 服务运行：计划任务 `AshareMCP`（触发器 `onstart`，SYSTEM 高权限）→ `mcp_service.bat` → `mcp_runner.py` → 自动崩溃重启
- 需确保 QMT 客户端位于 `E:\国金QMT交易端模拟` 且正在运行，否则 `get_*_realtime*` 工具将返回错误
- `tdx-mcp/start.bat` 仅启动 `tdx-mcp.exe`，作为 MCP stdio 进程被宿主管理
