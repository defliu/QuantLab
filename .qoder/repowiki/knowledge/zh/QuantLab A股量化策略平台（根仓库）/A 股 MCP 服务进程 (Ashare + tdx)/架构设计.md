本模块包含三个独立的可部署服务入口：
- `ashare-mcp/`：主服务，Python 3.12 + FastMCP（streamable-http，0.0.0.0:8000/mcp）。按职责分层：`mcp_server.py` 注册 `@mcp.tool()`（get_stock_daily/get_index_daily/list_available_symbols/get_latest_date 走 duckdb 连接池 `_duckdb_conns` 查询 `qmt_market_data.duckdb::dat_day`、`benchmark_index.duckdb::index_daily`；get_realtime_quote/ticks/download_history_xtquant 经 `XTQuantBridge.call` 以 subprocess 启动 QMT Python 3.6（`E:/国金QMT交易端模拟/bin.x64/pythonw.exe`）执行 `xtquant_bridge.py`，通过 stdin/stdout JSON 传递函数名与参数），`xtquant_bridge.py` 在 QMT 进程中注入 `Lib/site-packages` 后 import `xtquant.xtdata` 并维护 `HANDLERS` 映射；`mcp_runner.py` 作为 supervisor 检测崩溃并以指数退避重启；`mcp_service.bat` 由 Windows 计划任务 `AshareMCP` 调度。
- `cn_free_quote/server.py`：独立的免费快照服务（与 ashare-mcp 隔离）。
- `tdx-mcp/`：通达信 MCP 客户端，`start.bat` 直接拉起本地 `tdx-mcp.exe` 作为 stdio 子进程被 MCP host 管理。
依赖方向单向：ashare server → 内存 DuckDB conn → 磁盘 DuckDB 文件；实时路径 server → subprocess → QMT Python 3.6 → xtquant 原生接口，不跨进程共享任何 Python 对象。
