模型文件本身即产物，读写方全部集中在 `projects/Project_16_LightGBM股票大师/`，入口经 `data_config.py::MODEL_DIR = "D:/QuantLab/models"`：
- 训练侧：`train_optuna.py` 以 Optuna 调参后产出 `lgb_model_v3*.txt` 候选版本（v3_enh / v3_f3 / v3_g2_strong_real_20260825_1964t / v3_retrain_20260828 / v3_retrain_20260831 / v3_v20_0831 / v3.1 / v3.1b / v3.2 / v3.3 / v3.4 及 v3.4 的 N3/N5/t5 变体）。
- 推理侧：`backtest_dual.py` 用 `lgb.Booster(model_file=args.model)` 做回测推理；`deploy_predict.py` / `deploy_predict_g2.py` 做实盘/模拟盘推理（G2 走独立候选 g2_top2）。
- 晋升侧：`promote_model.py` 与 `auto_promote.py` 负责候选→正式：**先备份旧模型再替换**，正式模型置只读。
- 正式模型 `lgb_model_v3.txt`（3017 棵树 / 27 个特征）为当前主用版本，其余为实验候选或已淘汰版本，按文件名后缀区分（`_enh`=增强特征、`_f3`=含 F3 新闻催化、`_retrain_<date>`=按日重训、`_v3.4_N3/N5/t5`=不同 N 日标签或阈值变体）。
- 训练输入统一为 `data/feature_panel_v3.parquet`，面板与模型的绑定关系由 PANEL_SYNC 部署配置说明约束。
