纯文件系统知识库，无任何程序代码或数据库依赖，由 Qoder/Claude/Copilot 等 agent 运行时根据约定读写：
- `memory/global/MEMORY.md`：存放用户偏好（如称呼「诚哥」）等全局规则，被所有 session / project 继承。
- `memory/projects/<uuid>/MEMORY.md`：每个策略项目的专属记忆，模板字段包含 Project context / Rules / Architecture decisions / Discovered durable knowledge；另含 `MEMORY-historical-*` 系列归档历史研究结论与平台演进记录；`D__QMT_STRATEGIES/` 与 `projects/global/` 是历史迁移产物，保留 `GLOBAL_MEMORY.md`。
- `memory/sessions/ses_<sid>/`：每次对话 session 对应一个独立目录，内建固定结构——`checkpoint.md`（阶段要点）、`notes.md`（笔记流水）、可选 `tasks/T<n>/progress.md`（子任务进度），用 UUID 前缀的 `ses_` 命名便于按 session ID 检索与清理。
- 各 MEMORY 文件内部采用统一的 Markdown 分段（标题+列表）组织知识，agent 通过读取这些文件在 session 启动时恢复上下文，写入时直接追加或替换段落，无需序列号或版本锁，本质是 human-readable + machine-parsable 的无锁 KV。
