- 项目级记忆位于 `memory/projects/<uuid>/MEMORY.md`，并按 `Project context / Rules / Architecture decisions / Discovered durable knowledge` 四段划分，其中 Discoverd durable knowledge 专门沉淀跨 session 可复用的事实。
- 历史研究结论不混入当前 MEMORY.md，而是拆分为独立的 `MEMORY-historical-*.md` 归档文件，便于回溯旧结论而保持当前记忆整洁。
- 每个 session 文件夹命名为 `memory/sessions/ses_<随机id>`，并统一包含 `checkpoint.md`（阶段性 checkpoint）与 `notes.md`（笔记流水）两个必填文件。
- 当 session 涉及明确子任务时，按 `tasks/T<n>/progress.md` 的扁平编号目录维护各任务进度，T1/T2/T… 顺序递增。
- 全局规则（如称呼「诚哥」）集中放在 `memory/global/MEMORY.md` 的 User preferences 段落，而非分散在各 project/session 中。
