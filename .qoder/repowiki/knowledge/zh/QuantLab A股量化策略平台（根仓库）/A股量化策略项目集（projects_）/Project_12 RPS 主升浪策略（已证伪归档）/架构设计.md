项目采用标准 QuantLab 策略项目结构：`specs/SPEC.md` 定义验收指标与假设；`config/` 下按版本/变体维护多份 YAML（strategy.yaml、variant_*.yaml、diag_*.yaml、v3_2020.yaml 等），由 `research/gen_v3.py`、`research/gen_variants.py`、`research/gen_diag_configs.py` 批量生成；`research/` 集中全部回测与诊断脚本，按职责划分：单元测试（`test_rps_momentum_unit.py`、`test_sector_rps_unit.py`）、因子验证（`huangshi_formula_scan.py`、`ic_rps_acceleration.py`、`ml_factor_synthesizer.py`）、诊断对比（`compare_monthly_2020.py`、`analyze_v3_full.py`、`analyze_v4_full.py`）、交易归因（`analyze_pnl_pairs.py`、`debug_*acceleration/pullback*.py`、`append_*pitfalls.py`）；`results/` 保存每次 run 的日志与结题报告；README 与 SPEC 均已标注「已证伪归档」，策略源码位于根仓库 `strategy/rps_momentum.py`，本项目作为隔离的研究沙盒存在。依赖方向单向：research 脚本 → config YAML → 通用回测引擎（来自上级框架），本项目不持有可执行入口。
