项目按任务书拆分 A/B 两个独立回测子项目，文件目录严格对应职责：
- `specs/` 存放需求定义 `任务书_知乎公开策略审计_20260819.md` 及原文存档 HTML，是验收基准。
- `research/` 为轻量研究脚本：`bom_turn_of_month.py` 实现 BOM 月末效应的自研向量化回测引擎（仅依赖 pandas/numpy/duckdb），读写本地 ETF CSV 与 benchmark DuckDB；`ablation_simulator.py` 实现 A0~A3 消融阶梯的自研日线循环模拟器（与框架引擎解耦）；`run_a4_engine.py` 是 A4 干净口径的薄入口，动态 import 本项目的 `strategy/cai_market_audit.py` 注册到 `strategy.registry`，构建 aux_data（TTM股息率、PIT净利同比、总市值宽表、上市日期映射）并调用根目录 `backtest.engine.run_backtest`。
- `strategy/` 提供框架引擎可调用的策略模块：`cai_market_audit.py`（A4 六步选股 + target_weights 模式）与 `cai_market_riskstack.py`（叠加止损、大盘门控、退市排雷的可配置风控变体），两者均通过 `register_strategy` 暴露给引擎执行层，仅读调数据不写盘。
- `config/cai_market_a4.yaml` 以 YAML 集中管理 A4 回测参数（成本、滑点、区间、宇宙路径），被 `run_a4_engine.py` 读取注入引擎。
- `results/` 按输出维度分类：`a4_engine_out/`（引擎 report 包）、`riskstack_out/R*_{id}/`（消融/风控变体各一目录含 equity_curve、meta.json、trades）、各报告 md 与中间 CSV/JSON。
依赖方向单向：research → strategy → backtest/engine（只读），research 也可直接读 `E:/astock/` parquet 自建管道，不反向依赖 results。
