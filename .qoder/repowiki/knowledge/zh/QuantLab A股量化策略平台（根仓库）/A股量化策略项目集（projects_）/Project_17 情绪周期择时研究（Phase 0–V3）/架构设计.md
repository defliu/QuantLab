项目按「Phase 分层 + 任务书冻结判据」组织：`specs/任务书_v*.md` 定义各阶段通过/证伪门槛；`config/strategy.yaml` 提供数据源路径与情绪五指标/阶段 bin 等冻结参数；研究代码以 `research/` 下独立脚本形式存在——每个文件实现一个 Phase 或 Variant（如 `phase0_robust_check.py`、`phase0v2_a_active.py`、`phase0v2_b_overlay.py`、`phase0v3_limitup_structure.py`），并以 build 入口 `research/build_sentiment.py` 生成统一的 `results/sentiment_series.csv` 作为下游脚本共享的情绪序列输入；输出统一落盘至 `results/`（CSV 中间表 + Markdown 结题报告）。依赖方向单向：`build → sentiment_series → phase0vN_* 判据脚本 → results/*_{verdict}.md`，无模块间 import 耦合。外部依赖为本地 astock parquet 数据（`E:/astock/...`）和 `scipy.stats` 统计检验。
