模块采用「源码-构件-配置-研究」四区分离的自包含项目结构：
- `src/`：纯函数式实盘源码（strategy_atr.py 作为主逻辑；_strategy_atr_local.py 为本地 miniQMT 验证适配器；_atr_ew_local_test.py 单测辅助），零 QMT 运行时依赖，通过 `_main_loop(C)` 暴露统一入口。
- `build/`：QMT 部署构件目录，存放由上层 broker/qmt_builder.py 从 src 生成的 GBK 单文件策略（strategy_atr_lowvol_equalweight.py / strategy_atr_lowvol.py / strategy_atr_lowvol_allday.py），含 init/handlebar/exit 生命周期、全局状态 _g_*、BUILD_TAG 与 FIX4a/b/c 三态下单回退。
- `config/*.yaml`：参数化配置中心，同一套策略逻辑通过 YAML 切换回测口径（10w/8只、100w/100只、价格过滤、MAX5彩票过滤、MA200门控、liquid版等），被 backtest/ 框架与实盘同时消费。
- `research/`：手写回测原稿（backtest_atr_lowvol v1/v2/v3）、因子探针、报告生成器与 tests/ 单测，属于研究史料，不直接 import 进 build。
- 数据通道：选股用 C.get_market_data_ex + get_turnover_rate + get_stock_list_in_sector 实时拉全市场；财务指标通过 xtdata.get_financial_data（PIT 安全，ann_date/f_ann_date 过滤）；持账单据落地 D:/QMT_POOL/*.json/csv。
- 与仓库级框架的边界：策略核心在 Project_ATR_lowvol/src；通用回测引擎在仓库 backtest/，由 research/backtest_atr_lowvol_v3.py 和 config/atr_10w_price50.yaml 驱动；QMT 构建由 broker/qmt_builder.py 输出到本目录 build/。
