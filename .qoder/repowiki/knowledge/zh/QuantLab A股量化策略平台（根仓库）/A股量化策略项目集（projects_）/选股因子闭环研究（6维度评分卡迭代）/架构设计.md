本模块是一个纯文档驱动的因子研究项目目录，不含可执行代码，采用「标准报告 + 版本框架」的组织方式：
- `factor_framework.md` 是权威来源，定义 F1~F6 六个维度、各维度得分区间、加权公式（总分=Σ权重×维度分）及等级阈值（S/A/B/C），并附 v0.1 版本迭代记录。
- `README.md` 描述方法论、数据源约定（通达信TDX MCP 行情/技术指标 + wenda 新闻公告）、目录结构与闭环流程（Step1复盘→Step2更新因子→Step3盘前选股→Step4盘中跟踪→Step5盘后验证打分）。
- `reviews/` 保存历史案例复盘（如 20260818_5stock_review.md），作为因子定义的实证来源，并在文末产出“新增硬规则”与待验证观察指标，回灌到 `factor_framework.md` 的版本表。
- `selections/` 按日期命名（YYYYMMDD_selection_N.md），记录当日选股初筛条件、6维评分明细、入选逻辑与对照基准。
- `results/` 存放盘后验证结果（portfolio_monitor / verification）。文件间依赖方向单一：review → factor_framework → selection → result，构成单向反馈链。
数据来源与口径在 README 中统一约束（行情/TDX / wenda 严格区分确证事实与推测归因），避免因子定义漂移。
