- 研究入口脚本在导入同级 config 前先插入本目录和项目根到 sys.path，避免同名模块冲突。
- 因子定义以字典表（FACTOR_CONFIG / FACTOR_WEIGHTS）声明名称、类别与参数，计算逻辑按键名分支生成结果，便于新增因子时仅扩表。
- 因子值计算统一先填充缺失为 0 再返回 Series，并按面板 ts_code 索引 reindex 对齐当日候选池。
- 回测调仓使用 `get_monthly_rebalance_dates` 基于 pandas 偏移字符串（"M" 或 "2M"）按月/双月切割交易日。
- 财务相关因子（ROE/grossprofit_margin）通过 T-45 日查表 + ffill 避免财报披露滞后带来的前视偏差。
- 市值过滤采用 universe_rank_start~rank_end 区间配置而非硬编码代码列表，适配不同指数口径（中证500/1000）。
