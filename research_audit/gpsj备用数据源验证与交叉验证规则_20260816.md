# gpsj 备用数据源验证与回测交叉验证规则（2026-08-16）

## 一、背景

- 主数据源 `E:/astock/`（买断离线资产，2009 起）为框架默认；为避免单一数据源口径风险，需要独立备用数据源做回测交叉验证。
- 备用源来自商业回测软件 huicexitong：`E:/huicexitong/runtime/sj/gpsj.duckdb`（3.6 GiB，只读）。

## 二、数据源能力与限制

| 项目 | 说明 |
|---|---|
| 核心表 | `gpsj.daily_data."日线数据"`，13,766,274 行 |
| 日期跨度 | 1990-12-19 ~ 2026-04-03（滞后主源约 4.5 个月） |
| 字段 | OHLC / 成交量(手) / 成交额(千元) / 复权因子 / 换手率(%) / 市盈率TTM / 市净率 / 总市值 / 流通市值 / ST / 停牌 / 涨跌停价 / 连板 / 资金流 等 |
| PIT 财务 | `财务指标`（公告日期/报告期，226,913 行）、`利润表`（实际公告日期） |
| 其他表 | `停复牌信息`（604,670 行）、`每日涨跌停`（610,885 行）、`trade_cal`、stock_basic（5,819 只） |
| **硬限制** | 2015-01 前**非全市场**（2001-01 仅 189 只/日、2010-01 仅 157 只/日，600000 浦发完全缺失）；全市场有效覆盖仅 2015 起（2015 ~2,459 只/日 → 2026 ~6,200 只/日） |

**结论**：全市场选股回测仅 2015-2026 重叠区可与 E:/astock 严格对比；2015 前备用源不可用于全市场对比。

## 三、口径对齐验证（关键）

gpsj 表内 `收盘价` 列是**前复权价**（= 不复权 × 复权因子 / 最新复权因子），**禁止直接用作原始价**。

正确做法：取 `不复权_开盘价/最高价/最低价/收盘价` + `复权因子`，与 E:/astock raw 口径一致；复权逻辑与 astock_reader 相同（raw 原样 / hfq=raw×adj / qfq=raw×(adj/latest)）。

逐字段抽样验证（000001.SZ / 600519.SH / 300750.SZ / 000858.SZ，2019-05-06 / 2024-06-03 / 2025-01-06）：

- 不复权收盘价、复权因子、换手率、流通市值、成交量、成交额、pe_ttm、pb：**与 E:/astock 完全一致**（同源 tushare）。

## 六、全局规则（写入 AGENTS.md「数据层约定」）

> **每个新策略/因子回测定稿后，必须用备用数据源随机抽取 1 个自然年做同区间对比**，两源 CAGR/最大回撤应基本一致（差异 >1pp 需排查数据口径）；模板 `research_audit/compare_gpsj_astock_2025.py`。
> 注意：gpsj `收盘价` 是前复权价禁止直接用；2015 前非全市场不可用于全市场选股对比。
