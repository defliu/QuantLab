## 发现的BUG

### BUG #1: 策略在非交易时间执行调仓 [P0]

**严重程度**: 🔴 严重

**问题描述**:
- 策略在凌晨00:34执行调仓
- 此时不是交易时间（交易时间：9:30-11:30, 13:00-15:00）
- 所有买入订单返回0，无法成交

**根本原因**:
```python
# strategy_mfic_v2_fullday_gbk.py:26
DEBUG_FORCE_REBAL = True  # 强制每天调仓

# strategy_mfic_v2_fullday_gbk.py:214
is_rebal = DEBUG_FORCE_REBAL or _is_rebalance_day(C, now)
```
策略启动后立即执行调仓，不检查当前是否在交易时间。

**影响范围**:
- 如果策略在非交易时间启动（如凌晨、晚上），会立即尝试调仓
- 所有订单失败，但标记为已调仓
- 导致交易时间无法再次尝试

**修复方案**:
```python
def _is_trading_time(now):
    """检查是否在交易时间"""
    hour, minute = now.hour, now.minute
    
    # 早盘: 9:30-11:30
    if 9 <= hour < 12:
        if hour == 9 and minute < 30:
            return False
        if hour == 11 and minute > 30:
            return False
        return True
    
    # 午盘: 13:00-15:00
    if 13 <= hour < 15:
        return True
    if hour == 15 and minute == 0:
        return True
    
    return False

# 在调仓前检查
if not _is_trading_time(now):
    print("[mfic] 非交易时间，跳过调仓")
    return
```

### BUG #4: passorder参数可能不正确 [P1]

**严重程度**: 🟡 中等

**当前调用**:
```python
# strategy_mfic_v2_fullday_gbk.py:402
order_id = passorder(23, 1101, ACCOUNT_ID, code, 11, price, shares, C)
```

**参数说明**:
- `23`: 买入
- `1101`: 账号类型（股票）
- `ACCOUNT_ID`: '67014907'
- `code`: '605001.SH'（可能需要去掉后缀）
- `11`: 限价单
- `price`: 从tick获取的lastPrice
- `shares`: 计算的股数

**可能问题**:

1. **股票代码格式**:
   - 当前: '605001.SH'
   - QMT可能需要: '605001' 或 'SH.605001'
   - 需要确认QMT的代码格式要求

2. **价格获取**:
   ```python
   price = _safe_price(tick[code].get("lastPrice"))
   ```
   - 非交易时间lastPrice可能为0或无效
   - 应该检查price > 0

3. **数量计算**:
   ```python
   shares = int(cash_per / price / 100) * 100
   ```
   - 每只分配1188元
   - 如果价格较高，可能买不到100股
   - 应该检查shares >= 100

**修复方案**:
```python
# 1. 检查价格有效性
price = _safe_price(tick[code].get("lastPrice"))
if price <= 0:
    print("[mfic] [买入失败] %s: 价格无效 (%.2f)" % (code, price))
    continue

# 2. 检查数量有效性
shares = int(cash_per / price / 100) * 100
if shares < 100:
    print("[mfic] [买入失败] %s: 数量不足100股 (%d)" % (code, shares))
    continue

# 3. 股票代码格式（需要确认QMT要求）
# 可能需要转换: '605001.SH' -> '605001'
# 或保持原样，取决于QMT版本
```
