
1. 现有 6+2 不适合作为“全 A 一级选股器”。

3. 通达信公式里的 `PPART(90)` 筹码密集是关键知识点，但 QMT 中未必可直接复刻。
4. Mimo IMA V3.1 不是完整交易策略，而是主升浪信号研究原型，可作为资料模块。
5. 后续重点是把“抓主升浪”完整迁移为 QMT 内部一体化策略。
