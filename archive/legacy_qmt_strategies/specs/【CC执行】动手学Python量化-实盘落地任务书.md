## 二、分阶段执行计划（CC按阶段推进，不得跳步）

- [ ] **T0-002** 现有回测框架标注"仅供教学参考"，存档归档不上线

- [ ] **T0-004** 新建独立分支 `refactor/live-ready`，所有改动在此分支进行
- [ ] **交付物**：`README_风险隔离声明.md` + git commit
- **无验收不进入下一阶段**

### 🟡 Phase 1：回测重做（Week 2-4，P0必须完成）
- [ ] **T1-001** 数据源切换：实盘信号链路 → QMT内置数据接口
- [ ] **T1-002** 退市股/ST/停牌过滤（剔除≥5%历史样本，幸存者偏差修复）
- [ ] **T1-003** T+1数据严格隔离（当日收盘数据→次日开盘执行，防前视偏差）
- [ ] **T1-004** 摩擦成本模型：佣金0.025%+印花税0.05%+滑点0.1%（单边0.175%）
- [ ] **T1-005** 参数敏感性测试：90%集中度[3%-8%]×70%集中度[2%-5%]网格扫描，步长0.5%
- [ ] **T1-006** IC检验 + 十分位分层回测
- [ ] **目标值**：修正后年化≥14%，夏普≥1.2，最大回撤≤13%
- [ ] **止损线**：若修正后年化&lt;8% 或 Sharpe&lt;0.8 → 放弃筹码因子，停止Phase 2，报告结果
- [ ] **交付物**：`backtest_v2/` 目录 + 回测报告 `report_v2.pdf`

### 🟢 Phase 2：策略核心重构（Week 5-8，P0必须完成）
- [ ] **T2-001** 多因子权重重设：筹码15-20% + 趋势20% + 换手10% + 基本面30%（ROE/营收/质量）+ 风控25%
- [ ] **T2-002** 因子IC检验，剔除IC&lt;0.02的因子，因子间做正交化（相关性&gt;0.7必须处理）
- [ ] **T2-003** 行业中性化处理
- [ ] **T2-004** 选股池压缩：50亿市值+1亿成交+非ST+上市&gt;60日 → 800-1200只
- [ ] **T2-005** 单线程循环扫描 → 向量化计算，目标扫描时间≤12秒
- [ ] **T2-006** 持仓期：5日强制清仓 → 10-15日ATR动态持仓
- [ ] **T2-007** 止盈止损：固定8%/5% → 2×ATR止盈 / 1.5×ATR止损 + 移动止盈
- [ ] **目标值**：TOP20榜单IC&gt;0.05，年换手≤20次，单票最大亏损≤组合1%
- [ ] **交付物**：`scanner_v2.py` + 因子权重配置 `factors.yaml`

### 🔵 Phase 3：对接现有体系（Week 9-10，P1）
- [ ] **T3-001** S/A/B/C分级逻辑封装为标准接口，输出 `suggested_weight` 字段
- [ ] **T3-002** 信号输出标准化JSON/CSV格式，对接通用风控引擎

- [ ] **T3-004** 接入Phoenix策略框架，配置权重≤20%
- [ ] **目标值**：端到端链路延迟≤90s，信号重叠度&lt;30%（保证多样性）
- [ ] **交付物**：`risk_adapter.py` + 对接文档 + Phoenix配置变更

### 🟣 Phase 4：纸面交易验证（Week 11-22，共3个月）
- [ ] **T4-001** 每日盘后运行选股，次日开盘前发送至QMT观察列表
