## 1. 6+2全天版回测 — 之前那版的口径与可信度

先纠正一个数：报告 `config.backtest_days = 180`（不是 60），`max_hold = 3`，`pool = /mnt/d/QMT_POOL/selected.txt`（WSL 路径，说明在 Linux/WSL 跑的独立脚本，非工厂）。equity_curve 2025-09-15 ~ 2026-06-17，约 9 个月。

**四问回答**：

| 口径项 | 实际情况 |
|---|---|
| 数据源 | **mootdx**（`Quotes.factory(market='std').bars(symbol, category=4, offset=800)`，第三方网络日K）。**不是**回测工厂的 astock parquet。 |
| 回测区间 | **180 个交易日**（2025-09-15 ~ 2026-06-17），单一牛市片段。**不是全牛熊周期**。 |
| 股票池 | **外部 `selected.txt`**，不是全 A。而且见下——这是未来池。 |
| 可信度 | **很低，不能代表 6+2 真实历史表现。** 6 条硬伤见下。 |

**六个硬伤**（按致命程度排）：

1. **池子级 look-ahead（最致命）**：`selected.txt` 当前是 **2026-06-22 10:45-10:51** 生成的"505选股"快照（505 只），而回测区间 2025-09-15 ~ 2026-06-17。代码 `read_pool` 一次性读入、`download_all` 下载这批票的历史——**单点池子，不滚动**。等于用 9 个月后的选股结果回测过去 9 个月，前视偏差 + 幸存者偏差双杀。这跟 305 池 DeepSeek、聚宽盘中版是同一类坑（回测总表"关键认知"第 3 条）。**+50.46% 大概率主要来自这个，不是策略 alpha。**
2. **收盘价打分 + 收盘价成交**：打分用 `hist = df[df.index <= today]`（含今日收盘），`buy_price = sell_price = 今日 close`。当天看到收盘才决定当天收盘买/卖——**日内 look-ahead，不是 next_open**。工厂红线是 next_open，这版没遵守。
3. **无交易成本**：代码全程无佣金/滑点/印花税。178 笔 / 9 个月是高换手，加成本（V1.1 SPEC 测算单次约 0.11%+冲击）会显著拉低。
4. **无涨跌停过滤**：买入侧只有 `bias5 > 10` 跳过，没有涨停板拦截；max_hold=3 高换手时可能买在涨停。
5. mootdx 数据源 PIT 无保障（非买断 astock，复权处理不明）。
6. 无 PIT universe（退市股未按日快照排除；9 个月短周期影响小但仍是缺陷）。

**结论**：+50.46% / 夏普 1.84 **不可信**，不能作为 6+2 历史表现的判断依据。最致命的是池子 look-ahead——这个数字大概率修掉池子后会大幅缩水甚至转负。

## 3. VT 因子库（GTJA 191）结论

**归档文档已落盘**（核实过，Glob 没命中是 knowledge_base junction 问题，Read 能读到）：

**具体结论**：
- VT 因子库 = GTJA191(191) + Alpha101(101) + Qlib158(158)，约 450 个量价因子。
- 大盘/中盘：全期(2021-2026)筛出 9/8 个 |ICIR|>0.5 有效因子，但**训练集(2021-2023) 0 个有效** → 全期"有效"是 **2024-2026 牛市过拟合**。根因：GTJA191/Alpha101 是 2014/2015 发布的，10+ 年过去 A 股大盘/中盘量价因子已衰减、定价充分。
- 小盘：训练集 11 个有效（非过拟合，小盘定价不充分），但**样本外回测 2024-2026 = -24.54% / max_dd -33.91% / IR -1.47**，完全失效（小盘 2024 杀跌 + 因子衰减 + 高换手成本）。
- 基本面因子（EP/BP/SP/DP/低换手/小市值）全期+训练集都 ICIR<0.5，本身弱（没过拟合但无效）。
- **总结论：462 因子 × 3 universe 科学证伪，A 股近 5 年多因子 alpha 难，不建议实盘。**

**是永久放弃还是暂缓**：归档 ≠ 永久放弃。归档文档明确"harness 留作因子验证工具"。重启条件（归档"不做的事"反推）：

## 4. V1.1 事件门控层 + 假突破评分，是否值得提取集成到 6+2

V1.1 SPEC 在 `agent_hub/main_uptrend_v1_1_upgrade/strategy_spec_main_uptrend_v1.1.md`（2026-06-20）。两个组件分开看：

### 事件门控层（模块 7：10 类事件 × 28 条规则）— 值得提取，但有前提

- **价值：高**。纯规则型风控（不依赖 ML），独立于选股逻辑，10 类事件（立案/审计非标/ST/业绩变脸/减持/债务违约/质押冻结/监管函/异常波动/停牌核查）× 4 级动作（禁入/退出/降权×0.3-0.7/预警），权重叠加规则、流动性检查（跌停无法退出 + TWAP）、事件时间戳规则都有设计。逻辑上和 6+2 的 `SellStrategyEngine` 是同一层（持仓后风控），可并存或融合。证据强度有分级标注（P0 强证据：立案/审计非标/ST/业绩变脸）。
- **集成障碍（最大）**：依赖**事件数据管道**（`event_data.py` 需公告数据：立案/审计/ST/减持/质押/监管函…）。6+2 全天版当前是纯量价（astock OHLCV），**没有公告/事件数据源**。没有数据，门控层是空壳。
- **建议**：值得提取为独立风控模块（`backtest/risk/event_gate/` 或 `core/event_gate/`），但集成 6+2 前必须先解决事件数据源（akshare / 通达信 / 另买？）。可以先把模块写好 + mock 数据验证规则逻辑，数据源到位再接。

### 假突破评分（模块 4：11 分制）— 不急于集成

- **价值：中**。是入场质量评分，和 6+2 的 `dimension6plus2` 趋势评分**同一层**。叠加会重复打分，替换要重新校准权重。
- **集成障碍**：① 11 分制 8 个维度全部标 ⚠️"经验规则待验证"；② 支撑它的 **H12 条件概率验证已废弃**（复权 look-ahead + 命题偏移 2 缺陷，记忆 `p0-h12-paused-validity-doubt`，回测总表 `#已废弃`）。阈值"≥6 有效 / ≤3 禁入"没有验证支撑。
- **建议**：不急于集成。先在 V1.1 框架内跑通 H12 + 因子 IC 验证（W01-W03 工单），确认假突破评分阈值有效，再谈集成。直接集成 = 把未验证规则塞进已部署策略。

**一句话**：事件门控值得提取（先补数据源），假突破评分先验证再谈。
