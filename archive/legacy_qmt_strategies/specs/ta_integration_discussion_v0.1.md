## 一、背景

### 1.1 什么是 TA

TradingAgents-astock（简称TA）是一个A股多Agent投研框架，已在本地部署并验证通过：

- **7个AI分析师**：市场/舆情/新闻/基本面/政策/游资/解禁
- **辩论机制**：Bull vs Bear 辩论 + 三方风险辩论（激进/保守/中性）
- **4层决策**：分析师 → 研究经理 → 交易员 → 组合经理
- **输出**：Buy/Hold/Sell + 目标价 + 止损价 + 完整报告
- **数据源**：mootdx TCP + 腾讯/东财/同花顺/新浪（全免费直连）
- **模型**：火山引擎 DeepSeek V4 Flash（已验证跑通）
- **成本**：~1.5元/只（30-50次LLM调用）
- **耗时**：5-10分钟/只

### 1.2 现有策略链路

```
QMT全天版策略 → 外部池/初选池 → 6+2评分器 → 四层卖出风控
→ 置换方案C（5天收益<3%淘汰）→ 尾盘14:40-14:57执行买入
```

### 1.3 讨论起因

诚哥想：**把TA加进策略链路，每天让TA给候选股做深度分析，判断哪些票最值得买入。**

## 二、讨论过程

### 2.1 三个方案的比较

| 方案 | 描述 | 结论 |
|------|------|------|
| A：TA作为硬过滤器 | 候选池全跑TA，只买Buy的 | ❌ 不推荐——成本高、误杀多 |
| B：TA作为评分加权 | TA结果量化成分数合并到评分器 | ❌ 不推荐——强行量化丢失信息 |
| **C：TA作为买入前最后验证** | **现有策略选出前3→TA验证→确认买入** | **✅ 推荐** |

### 2.2 最终倾向方案（方案C）

```
Day N 收盘后
  │
  ├─ QMT策略跑完 → 评分器排序 → 选出前3候选
  │
  └─ TA逐只分析前3（不赶时间，慢慢跑）
      ├─ 每只输出: Buy/Hold/Sell + 止损价 + 目标价
      └─ 汇总飞书报告

Day N 晚上 → 诚哥看报告，确认次日买入计划

Day N+1 → 诚哥在合适价格买入（开盘/盘中/尾盘都行）
          在TA给的止损范围内，挂好止损
```

### 2.3 时间特性说明

TA **不适合盘中用**（分析5-10分钟，行情已变），但适合**盘后深度分析**：

- TA的结论是中期判断（3-6个月），不受几分钟行情波动影响
- 与现有策略的5天持仓周期不冲突——TA判断"会不会暴雷"，策略找"短线机会"
- 两者是 **AND 关系**

## 三、三位同事的评估意见

### 3.1 量化策略架构师

**TA定位：否决层，不是决策层**

| TA结论 | 处理方式 |
|--------|---------|
| Buy | 维持评分器原结论，买入 |
| Hold | 降级处理，降低仓位或转为观望 |
| **Sell** | **一票否决**，即使评分器高分也不买 |

**冲突处理原则**：
- TA的Sell = 硬否决
- 评分器的卖出信号也需尊重
- 双重确认才执行

**建议实施路线**：
- Phase 1（1-2周）：只分析不执行，统计TA与策略收益的相关性
- Phase 2（2-4周）：TA作为否决层上线（Sell不买）
- Phase 3（稳定后）：根据数据决定是否启用Hold降级

### 3.2 量化科学家

**核心风险警告**：

| 风险 | 等级 | 说明 |
|------|------|------|
| 过拟合 | 🔴 极高 | 7分析师+辩论机制极易拟合历史噪声，LLM过拟合极难检测 |
| 信号不稳定 | 🔴 高 | LLM随机性，同一标的每天信号可能不同 |
| 数据源问题 | 🟡 中 | 东财push2间歇性被封，有兜底方案 |
| 成本 | 🟢 低 | 1089元/年，几乎可忽略 |

**特别警告**：
> "TA最危险的问题不是它不准，而是你无法证明它不准。"
> 传统量化策略可以用回测验证，但TA的7分析师+辩论机制是黑盒叙事推理，历史回测参考价值有限。

**建议先影子交易3个月**，积累实际表现数据再做决策。

### 3.3 CIO/技术决策

**架构方案建议**：

| 维度 | 建议 |
|------|------|
| 自动化程度 | **半自动**（TA出报告→人决策），全自动风险太高 |
| 容错机制 | TA跑崩/超时 → 跳过TA，纯QMT策略不停摆 |
| 团队分工 | Hermes调度，TA分析，CC开发，诚哥决策 |
| 扩展性 | 初期3只，架构预留扩展到10只的能力 |

## 四、诚哥的最终倾向

**TA为主，同事小组为辅**

```
日常（80%）：TA全自动跑
  ├─ 7分析师 + 辩论 → 完整报告
  └─ 成本1.5元/只

关键决策（20%）：TA报告 + 同事小组复核
  ├─ TA出报告后，派1-2个同事审一下
  └─ 增加2-3元/只，多一层人工验证
```

**理由**：
- TA在数据获取和流程标准化上完胜，这是框架本身的价值
- 同事小组的优势是灵活性，适合做复核/挑战TA结论
- 成本上TA便宜一半，且不需要每次写prompt
