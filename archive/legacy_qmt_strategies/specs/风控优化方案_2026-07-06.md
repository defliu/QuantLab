# 风控优化方案 — 控风险 + 让盈利奔跑

## 当前风控引擎（SellStrategyEngine）已有能力

| 层级 | 功能 | 现有程度 |
|------|------|---------|
| 底线层 | 累计-5% / 单日-7% → 清仓 | ✅ 已有 |
| 清仓层 | 连续3日<MA20 → 清仓 | ✅ 已有 |
| 预警层 | 放量/量价背离/MACD缩短/MA5斜率走平 → 减仓30% | ✅ 已有 |
| 确认层 | 破MA10/长上影/高位放量阴线 → 再减50% | ✅ 已有 |
| 跟踪止损 | 3档回撤(6%/8%/10%) + 破MA5(盈利>10%) + 吊灯ATR | ✅ 已有 |
| 反弹恢复 | 减仓后3日反弹可恢复 | ✅ 已有 |
| 禁入黑名单 | 清仓后20日 | ✅ 已有 |

## 缺失的三大块（建议按此顺序加）

### Phase 1：事件风险门控（P0，防黑天鹅）

从主升浪V1.1提取事件门控层，集成到现有风控引擎：

| 事件 | 门控动作 | 数据来源 | 工作量 |
|------|---------|---------|-------|
| 立案调查 | 禁入+退出 | 东财公告API | 中 |
| 业绩变脸（预盈转预亏） | 退出+禁入20日 | 财报API | 中 |
| 质押>80% | 禁入+退出 | 财报API | 中 |
| 监管函/问询函 | 退出/降权×0.5 | 东财公告API | 中 |
| 股东清仓式减持 | 退出 | 东财公告API | 中 |
| ST/退市风险 | 禁入+退出 | 已有ST过滤 | 低 |

**效果**：主要防的是"持仓突然暴雷"——A股最大的单一持仓风险不是涨跌，是踩雷。

### Phase 2：跟踪止损增强 — 让盈利跑起来

当前跟踪止损是固定3档(6%/8%/10%)，问题在于：
- 高波动股（如科技股）一震荡就触发，盈利跑不起来
- 低波动股（如银行股）回撤到6%可能已经破位

**建议改为ATR自适应**：

| 当前 | 优化后 |
|------|--------|
| 固定回撤6%/8%/10% | 按ATR动态计算：回撤阈值 = max(ATR×2.5, 6%) |
| 破MA5+盈利>10%才清 | 破MA10+ATR放大+盈利>15%才清（给更多空间） |
| 无大盘环境分层 | 大盘震荡市→收紧(ATR×2)，大盘趋势向上→放宽(ATR×3) |

**效果**：高波动股不会因为正常波动被震出，低波动股也不会等破位才触发。

### Phase 3：大盘环境感知层

现有风控引擎完全不看大盘状态，导致：
- 大盘连续下跌时，仍然在积极选股买入
- 大盘震荡时，减仓信号和买入信号同时存在，互相矛盾

**建议加一个"大盘状态机"**：

| 大盘状态 | 买入限制 | 风控力度 |
|---------|---------|---------|
| 上涨（上证>MA20>MA60） | 正常 | 标准（ATR×2.5） |
| 震荡（上证>MA20但<MA60） | 仓位≤50% | 收紧（ATR×2） |
| 下跌（上证<MA20） | 只卖不买 | 最严（ATR×1.5） |
| 极端（单日跌>5%或连续3日跌>10%） | 熔断，暂停交易 | 危机模式 |

**效果**：大盘向下时自动缩仓，减少逆势买入的亏损。

## 优先级和实施路线

| 阶段 | 内容 | 工作量 | 效果 |
|------|------|-------|------|
| **Phase 1** | 事件门控层（防暴雷） | CC 2-3天 | 避免踩雷归零风险 |
| **Phase 2** | ATR自适应跟踪止损（让盈利跑） | CC 1-2天 | 减少被震出，提高盈亏比 |
| **Phase 3** | 大盘环境感知层（逆势缩仓） | CC 1-2天 | 减少逆势亏损 |

**关键原则**：不改选股逻辑，只在风控端加层。上面三层全部加完后，跑一下6+2的全A股回测，看风控优化后的夏普/回撤/盈亏比变化。
