# 会议纪要：买点信号作为第9维度加入6+2评分体系

**日期**：2026-07-02
**召集人**：诚哥
**参会**：量化策略架构师、量化科学家、CIO/风控官
**议题**：把通达信买卖点信号（买点1/买点2）作为第9个评分维度，以加分形式加入6+2评分系统（ScoreCalculator6Plus2）

---

## 一、背景

黄氏主升浪策略有两套通达信公式体系：
- **选股公式（gs_1_\*）**：从全市场筛选股票，核心逻辑为均线多头排列 + 角度≥45° + 阳线比例≥60% + 回踩不破5日线
- **买卖点公式（gs_0_\*）**：在K线图上标识买入/卖出信号，买点1（强势启动）+ 买点2（回踩不破5日）

现有6+2评分系统共8维度100分：
1. Breakout Validity (22分)
2. Trend Health (13分)
3. Consolidation Strength (20分)
4. Volume-Price Health (12分)
5. MACD Momentum (12分)
6. Valuation Safety (7分)
7. Sentiment (7分)
8. Sector Heat (7分)

**诚哥提案**：不改变选股公式，把"有买卖点信号的票"作为第9维度加分。有买点信号的票额外加分（买点1加10分、买点2加8分），总分从100变为100~110分，买点好的票自然排名靠前，没买点信号的票也不会被排除。

---

## 二、三位同事核心结论

### 2.1 一致同意项

| 结论 | 说明 |
|------|------|
| ✅ **加分方案优于硬合并** | 保留选股池不变，买点好的票排名靠前，没买点的票也不会被排除 |
| ✅ **技术上可行** | 约60行纯增量代码，不涉及架构重构 |
| ✅ **买点1和买点2应分开加分** | 两种买点逻辑不同，分开加分更合理 |
| ✅ **建议渐进部署** | 先数据采集，再模拟运行，最后根据数据决定是否正式启用 |

### 2.2 关键发现：买点信号与现有维度存在系统性重叠

买点信号与6+2评分中三大高权重维度高度重叠，**不是独立增量信息**：

| 重叠维度 | 权重 | 买点1（回踩反包） | 买点2（趋势突破） |
|---------|:---:|:-----------------:|:-----------------:|
| Breakout Validity | 22分 | 60% | **90%** |
| Consolidation Strength | 20分 | **85%** | 55% |
| MACD Momentum | 12分 | 70% | 70% |
| **合计重叠分值** | **54分** | **~39分** | **~46分** |

**特别风险**：买点1的"回踩不破5日（L≥MA5×0.98）"与Consolidation维度（low≥MA5×0.998）本质是同一条件，阈值只差0.018。若买点1加10分，则"回踩不破5日"特征在总分中= Consolidation 20分 + 买点1 10分 = **30分**，占比过高。

### 2.3 权重分歧

| 参会者 | 买点1 | 买点2 | 总分上限 | 核心理由 |
|:------|:----:|:----:|:--------:|----------|
| 量化策略架构师 | +10 | +8 | 110 | 不压缩现有维度，买点作为独立加分 |
| 量化科学家 | +5 | +3 | 108 | 买点1（回踩反包）独立增量更高 |
| CIO/风控官 | **+3** | **+5** | 108 | 买点1与Consolidation重叠85%，过度加权风险高；买点2有筹码密集度增量信息 |

## 三、推荐方案

### 3.1 保守方案（综合三位意见折中）

| 信号 | 加分 | 说明 |
|:----|:---:|------|
| 买点1（回踩反包） | **+5分** | 与Consolidation重叠85%，但回踩反包形态有独立增量 |
| 买点2（趋势突破） | **+5分** | 与Breakout重叠90%，但筹码密集度是纯增量信息 |
| 两者同时触发 | **+8分**（封顶） | 双信号共振最有价值，但不可简单相加 |
| **总分上限** | **108分** | 买点信号最多占评分的7.4% |

### 3.2 工程实现要点

1. **dimension6plus2.py** 新增 `_calc_buy_signal_score()` 方法
2. 买点信号数据接入：推荐离线CSV管道（通达信导出→Python读取），后续可升级为Python端实时重算
3. 买点1和买点2互斥取最高分（同时出现时取买点1）
4. 总分上限从100调整为动态上限（100 + 实际加分）

### 3.3 渐进部署路线

```
Phase 1 (1-2周): 仅数据采集，不执行加分
  → 统计有买点信号 vs 无信号股的后市表现
  → 验证买点信号是否提供独立增量alpha

Phase 2 (3-4周): 保守方案（+5/+5），模拟运行
  → 观察排名变化和信号股后市表现
  → 按牛/震/熊市场环境分层统计

Phase 3 (第5周起): 根据数据决定
  → 若信号股显著跑赢 → 可上调权重
  → 若无显著差异 → 撤回，保持纯6+2
```
