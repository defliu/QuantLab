# SPEC: 验证"10:00 唯一买入时段"的量化可行性

## Objective

### 目标

验证主升浪策略将买入时段从全天4个操作点（09:24预警/10:00/13:30/14:30）**缩减为仅10:00一次买入**的量化可行性。

### 背景

Hermes 组织了 3 路子代理（研究分析/量化科学/红队审查）对"10:00 最佳买入时段"进行了两轮并行讨论，核心结论：

| 维度 | 结论 |
|------|------|
| 逻辑可行性 | 可行，有量化支撑 |
| 核心优势 | 10:00买入比09:30多付约0.4-0.8%溢价，但假突破率下降15-25个百分点 |
| 最大风险 | 单点集中 + 日内冲高回落 + 统计样本不足（交易频率下降约75%） |
| 红队警告 | 幸存者偏差——10:00的高胜率可能只是早盘滤网的结果，而非该时点本身的优势 |

### 需要验证的核心假设

1. **假突破率假设**：10:00的假突破率（30-38%）是否显著低于09:30（45-50%）？降幅是否真有15-25个百分点？
2. **溢价成本假设**：10:00买入相对开盘价的平均溢价是否在0.4-0.8%范围内？
3. **收益优势假设**：10:00唯一买入的预期收益是否优于多时点策略？
4. **空仓率假设**：10:00无信号的空仓率是否在75-85%？空仓的机会成本多大？
5. **冲高回落风险**：10:00买入后日内最大回撤的分布如何？是否频繁触发止损？
6. **不同市况稳定性**：牛/熊/震荡市下，10:00的优势是否一致？

### 验收标准

完成以下回测并输出报告，回答上述6个假设的真伪：

1. 算力池32只代表股 + 全市场对照组的时段分拆统计
2. 4个测试组（A/B/C/D）的收益/风险对比
3. 各时段假突破率的卡方检验
4. 不同市况下的稳定性分析
5. 明确标注：已验证事实 / 合理假设 / 待进一步验证

### 核心分析模块

#### 模块1：分时段假突破率统计

将全天拆分为以下时段，分别统计假突破率：

| 时段编号 | 时间窗口 | 说明 |
|:--------:|----------|------|
| T1 | 09:30-09:35 | 开盘冲击期 |
| T2 | 09:35-10:00 | 早盘消化期 |
| **T3** | **10:00-10:05** | **候选买入点** |
| T4 | 10:05-11:30 | 上午中盘 |
| T5 | 13:00-13:30 | 午后开盘 |
| T6 | 13:30-14:00 | 午后中盘 |
| T7 | 14:00-14:30 | 尾盘前段 |
| T8 | 14:30-15:00 | 尾盘 |

假突破定义（沿用V1协议）：
- 突破后N分钟内回落至突破价下方并维持
- N=30分钟（对T3/T4/T5/T6），N=15分钟（对T7/T8）
- 需同时考虑涨跌停限制

输出：各时段假突破率、样本量、95%置信区间、卡方检验p值。

#### 模块2：四组回测对比

| 组别 | 规则 | 预期交易频率 |
|:----:|------|:-----------:|
| **基准组** | 多时点（09:30/10:00/13:30/14:30均可买入） | 高 |
| **A组** | 仅10:00买入，原评分阈值 | 中 |
| **B组** | 仅10:00买入，评分阈值上调20% | 低 |
| **C组** | 仅10:00买入 + 涨幅>2.5%则放弃 | 中低 |
| **D组** | B+C组合优化 | 最低 |

统一风控规则（沿用现有策略）：
- 止损：-5%
- 止盈：+15%
- 趋势破坏：跌破20日均线
- 交易成本：双边0.13%（佣金0.03%+印花税0.1%）

#### 模块3：敏感性分析

- **阈值敏感性**：评分阈值上调10%/15%/20%/25%/30%
- **涨幅过滤敏感性**：1.5%/2.0%/2.5%/3.0%/3.5%
- **市场状态分层**：牛市/熊市/震荡市（按沪深300指数划分）
- **滑点敏感性**：0.1%/0.3%/0.5%/1.0%

## Testing

### 必测场景

1. **时段切分正确性**：验证突破事件的时间戳正确落入对应时段
2. **假突破判定一致性**：同一突破事件在不同时段参数下结果一致
