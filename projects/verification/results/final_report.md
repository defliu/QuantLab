## 六、最终推荐

### 策略排序

1. **⑤ 红利低波** - 推荐（回撤小、防御性好、容量大）
2. **① 质量小市值** - 可选（收益最高但回撤较大）
3. **④ 指数增强** - 防御（低波动但收益低）
4. **② PEAD** - 不推荐（A股PEAD效应弱）
5. **③ 低换手反转** - 不推荐（高换手成本高）
6. **⑥ ML多因子** - 淘汰（严重过拟合）

### 推荐配置

**50万-300万资金：**

```
70% → 红利低波（压舱石）
30% → 质量小市值（增强收益）
```

### 风险提示

1. **市场风险**：2026年Alpha压缩严重，量化多头平均超额仅3%
2. **风格风险**：小盘股可能在风格切换时大幅跑输
3. **流动性风险**：质量小市值策略容量有限（2000万-5000万）
4. **过拟合风险**：回测收益≠实盘收益，建议打7折
