# Project_19 可转债双低策略（立项 SPEC，2026-09-12）

> 状态：🟡 研究中（W2-1 轻量回测阶段，未上实盘）
> 依据：DE 三轮讨论 R1/R2/R3（`data/schedules/de_strategy_directions*.md`、`de_cb_datacheck_20260912.md`）
> 数据实锤：Tushare 转债域权限实测 + 东财交叉验证（D1-D9 详见 `data/schedules/de_cb_datacheck_20260912.md`）

## 一、定位与逻辑

- **一句话**：转债"下有债底、上跟正股"的不对称 payoff + 条款复杂性导致的系统性错误定价，用双低（低价格 + 低溢价率）规则化收割。
- **与现有策略关系**：资产类别不同（含债性）、信号源不同（条款/溢价率），组合层面低相关——真正的分散腿。
- **不做的**：不预测方向、不做条款博弈的复杂对冲，第一版只做"双低 + 信用排雷"的规则化组合。

## 三、规则集（预注册）

**P0 硬规则（不可 ablation，实盘底线）**：
- R1 评级：`issue_rating` ≥ AA-（历史回测用 issue_rating 作 PIT 代理；模拟盘当下排雷用 newest_rating）
- R4a 强赎：东财 NOTICE_DATE 公告日 T+1 强制卖出；公告后不再新买
- R5 正股兜底：正股 ST/*ST 排除并清仓

**可 ablation 规则（阈值回测后定稿，定稿前不许看样本外）**：
- R2 债底代理：现价 ≤ 到期赎回价×折扣（0.95~1.0）且剩余期限 ≥0.5~1 年
- R3 深度低价异常：现价 < 85~90 且评级 < AA 排除
- R4b 强赎事前计数：正股收盘 ≥ 130%×转股价 近 30 日计数达 10/30~15/30 不新买（**依赖转股价历史，第一版降级为仅 R4a**）
- R6 规模/流动性：剩余规模 ≥0.5~1 亿 或 近 20 日均成交额 ≥500~1000 万
- R7 到期：剩余期限 <0.5 年移出

**三硬前置（R3 数据实锤强制项，回测骨架必须实现）**：
1. 摘牌/僵尸行三保险：`delist_date` 非空即截止 ∪ 东财 `CEASE_DATE` 补洞 ∪ `vol > 0` 逐日过滤（岭南转债 248 行 0 量僵尸行实证）
2. 溢价率双锚点 ablation：转股价无历史 → 分别用 `first_conv_price`（上界）与 `conv_price`（下界）跑双低排序，分年超额方向一致才判稳健
3. 强赎事件表以东财 `NOTICE_DATE` 为源（Tushare cb_call 无权限）

## 四、预注册证伪判据（命中任一即归档，不恋战）

1. 双低+排雷（P0 规则集）2019-2026 逐年超额 vs 中证转债出现 **≥3 个负年份**，或全期年化超额 **<3%**
2. 剔除表现最好 1 年后全期年化超额 **<2%**（"扩容红利+债牛 beta"假象）
3. 2024-2026 超额 **<2%/年且单调下滑**（进入失效通道）
4. "P0 规则集全开"版本全期年化 **<8%** 或最大回撤 **>-20%**（payoff 叙事坍塌）
5. 以 2021-2023 定规则/阈值 → 2024-2026 样本外年化超额**转负**
