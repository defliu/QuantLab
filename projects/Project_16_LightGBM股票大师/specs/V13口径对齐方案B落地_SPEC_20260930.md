## 2. 回测口径锚点（必须逐条对齐，来源 scan_rotate_cost_real.py）

| 环节 | 回测口径 | 落地实现 |
|---|---|---|
| 候选池 | `day.nlargest(100,"prob") → nlargest(10,"prob")` = **模型 prob Top10**（非 combo） | build_v13_final 用生产同款模型 `lgb_model_v3.txt`（周更指针）对最新快照推理，取 prob Top10 |
| 评分 | `scorecard_real.compute_real_scorecard(day, est)`：F1/F3/F4 代理分 + F2/F5/F6 真实数据，**asof 全部 T-1（信号日）** | 同函数直接复用 |

| 排序 | `cand.nlargest(1, "total_new")` 按 total_new 降序 | 同 |
| 入场 | 信号日 d → **d+1 开盘价**（open→open） | 纸面对比两臂统一「执行日开盘」入场 |
| 可执行过滤 | 一字涨停 / 停牌 / 无量买不进 | 纸面对比尽力复刻（见 §4.3 注） |

### 诚实偏差表（新链 vs 回测，纸面期间逐日观测）

1. **模型版本**：回测默认 v3_enh（08-23 冻结）；生产/新链用 `lgb_model_v3.txt` 周更指针（与 16:30 deploy 同款）——这是既有生产机制（周更重训），非本次引入；纸面并行同时观测两臂，模型版本对两臂同权。
2. **volume_ratio 口径**：回测用主库预计算列；新链用 incr×主库现算（定义一致，源略异）。
3. **F3**：回测=面板代理分；新链同代理分（对齐✓，与旧链的新闻 F3 正是本次要剥离的差异）。
4. **快照慢变量**：merge_live_features 的 pe_ttm/turn_ma5 等为主库末值前向填充（F6 主源走 daily_basic 规避，代理分输入沿用快照，与 16:30 deploy 完全同源——两臂共用同一快照，公平）。

## 3. Phase 1 交付物（本 SPEC 范围）

### 3.1 `build_v13_final.py`（新，项目根）

- 时机：每交易日 **20:20**（16:43 model_top10 / 16:35 快照 / 19:30 moneyflow / 20:05 daily_basic 全部就绪后）。
- 输入：feature_panel_v3 + `_prefer_snapshot`（复用 deploy_predict 函数）、lgb_model_v3.txt、incr、daily_basic、moneyflow、stock_basic、新浪接口。
- 输出：
  - `data/selections/<T-1>_final_list.csv`（按信号日命名，次日执行）：ts_code/name/model_prob/proxy score_total/F1-F6(真实卡)/total/rank/redline_pass + 溯源列（main_net/industry_pct/volume_ratio/pe_ttm/turnover_rate/f2_source/f5_source/f6_source）
  - `data/selections/<T-1>_final_list.meta.json`：模型路径+sha256、快照 sha256、各数据源 max_date、参数、生成时间——asof 审计同款纪律。
- fail-loud：非交易日跳过（exit 0 [SKIP]）；快照/增量不新鲜（当日无数据）exit 1；池空、SC_F2/SC_F5 恒值、main_net 全 NaN → exit 1（借 G2 防死代码事故纪律）。
- 幂等：同日重跑覆盖重生成（确定性脚本自有产物；live 阶段 rebalance 读取时另做 asof 只读留档）。
- **PAPER 阶段不接 rebalance，不下单。**

### 3.2 `v13_paper_parallel.py`（新，项目根）

- 时机：每交易日 **20:30**（final_list 产出后）。
- 双臂记录（幂等去重，追加 `results/v13_paper_parallel_log.csv`）：
  - **old 臂** = `<T>_selection_full.csv` 中 total≥58 按 total 降序 top5（旧链 09:45 重排信号，执行日 T）
  - **new 臂** = 信号日 D=max(final_list 日期 < T) 的 `<D>_final_list.csv` 中 redline_pass 按 total 降序 top5
  - 两臂统一执行日 T 开盘入场；**两臂均不施加 position_filter**（PF 是执行层正交件，live 两链都保留 lite，信号对比保持纯度）
- 回填（复用 `paper_forward.load_open_panel` 主库+增量合并 open 面板）：entry=执行日 T 开盘，exit=第 5 个交易日开盘（HOLD_DAYS=5），另记 ret_1d；停牌/无量标记 unfillable 剔除统计（一字涨停仅主库覆盖日可判，诚实降级）。
- 汇总：`results/v13_paper_parallel_report.md`——每臂 n/均值/胜率/中位、逐日配对差（new−old 日均臂差）、top5 重合度、红线空仓日计数；数据源停更 fail-loud exit 2。

## 5. Phase 2：live-switch（**门禁达标后另启，本 SPEC 仅预登记**）

**门禁判据（纸面并行 ≥15 个执行交易日样本）**：
- new 臂 − old 臂日均配对收益差 ≥ −3bp/日（不显著劣化，噪声容限）
- new 臂胜率/回撤无结构性崩坏（胜率差 ≤10pp）
- 若 new 臂显著更差 → 停止迁移，旧链保留，调研结论修正归档
- 若基本持平 → 建议切换（对齐回测的架构收益是长期的）

**切换步骤（届时执行，均需再确认）**：
1. `rebalance_daily.py` 增 `--final-list` 候选源（读取 asof 留档 + sha 校验，同 G2 7 字段纪律）
2. 新任务 `Quant_P16_V13_Rebalance_0932`（09:32，market_tier → rebalance --final-list --live，限价锚开盘价，保留低开校验/一字板过滤）
3. TRAE 09:45 任务停用（保留推送）；10:05 guard 幂等判据对齐新链
4. F3 催化降级为推送提示（不进分数）
5. 回滚方案：rebalance 默认路径不变，去掉 `--final-list` 即回旧链；final_list 缺失时 fail-safe 空仓早退（宁缺毋滥）
