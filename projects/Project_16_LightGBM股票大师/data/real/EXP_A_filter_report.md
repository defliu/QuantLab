# 实验A：负向过滤（当日涨停/一字板剔除）可执行回测报告

> 目的：用 **v3_enh 模型 + v3_enh 面板**（当前最优基线），在可执行口径回测的每日选股前**剔除当日涨停/一字板股**（主库 `E:/astock/daily/stock_daily.parquet` 口径：`close >= up_limit - 0.001` 且 `is_st == 0`），对比 剔除 vs 不剔除 的可执行超额。**不改模型。**

> **口径**：scan_rotate_cost 可执行（open→open 开盘进出、剔除隔夜跳空、T+1 一字板/停牌不买）；前10池 + 评分卡红线58 + top2；成本=佣金万2(双边,最低5元)+印花税万5(卖出)+过户费万0.1(沪市)；滑点敏感性 0/0.1%/0.2%。测试期 2024-07-01 ~ 2026-08-14（516 交易日）。

> **红线遵守**：全程只读未改 V1.1 资产（`lgb_model_v3.txt`/`deploy_predict.py`/`qmt_config.py`/`run_scheduled.ps1`）。新增产物均写入 `data/real/`。

## 一、结论速览（TL;DR）

**当日涨停负向过滤对 v3_enh 无明显增益，甚至在 N=3/N=5 拖累超额。** 原因：v3_enh 本身**极少选出当日涨停股**（实际买入中仅 3.4%~7.1%），且其实际买入样本的隔夜跳空均值为负（-0.08%~-0.24%），不存在 v3.2（82.7% 涨停、跳空 +2.55%）那种“追涨停买不进”病灶。剔除后反而丢失了少量在 N=3/N=5 下盈利的强势动量标的。

| 基准参照 | 不剔除（=v3_enh 基线） | 剔除当日涨停 |
|---|---|---|
| 可执行 N=5 / 滑点0.1% 日均超额 | **+0.0555%**（复现 V32_RESULT 的 +0.056%） | +0.0282% |
| 方向 | — | N=1/N=10 改善；N=3/N=5 变差 |
| 实际买入中当日涨停占比 | 3.4%~7.1% | 0%（按构造） |
| 实际买入隔夜跳空均值 | -0.08%~-0.24% | -0.08%~-0.20% |

> 结论：**负向过滤不是 v3_enh 的修复方向**。v3.2 的病灶（追涨停）来自涨停/资金流特征，与 v3_enh 无关；v3_enh 的可执行短板另有原因（见实验B 标签错位假设）。

## 三、根因分析

1. **v3_enh 的候选池（前10）当日涨停占比仅均值 16.3%、中位 10%**（见运行日志），且其中能通过评分卡红线58 与可执行过滤（T+1 一字板/停牌）真正买入的更少——**实际买入中当日涨停股仅 3.4%~7.1%**。对比 v3.2（买入样本中 82.7% 为当日涨停），v3_enh 并无“追涨停”倾向。
2. **v3_enh 实际买入样本的隔夜跳空均值为负**（-0.08%~-0.24%），即多数票 T+1 开盘价**低于** T 收盘价，可执行口径不但不吃亏反而略微占优；说明 v3_enh 的盈利来源不依赖隔夜跳空，与 v3.2 病灶（+2.55% 跳空、开盘追高）完全不同。
3. **剔除当日涨停在 N=3/N=5 反而变差**：被剔除的少量当日涨停票中，有一部分在 3~5 日持有期内可执行收益为正（强势股的短中线动量），剔除后池子变小、次优替代票质量下降，超额从 +0.0555% 降到 +0.0282%。
4. **N=1/N=10 剔除略有改善**（N=1 提升约 +0.05pp，N=10 提升约 +0.04pp）：短线/长线窗口下，当日涨停票的高开回落损耗更大，剔除有一定帮助；但幅度小，且 N=3/N=5（策略实盘持有期）为负贡献。
5. **结论**：v3_enh 的“可执行超额偏低”（N=5/0.1% 仅 +0.056%）不是“买不进涨停”造成的，负向过滤不是 v3_enh 的修复方向；该思路更适合修复 v3.2（特征导致的追涨停）。
