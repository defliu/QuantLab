## 三、实证分析结果

### P1-2 统计显著性（g2，红线60/N=10/TOP2/滑点0.1%）

| 指标 | 值 | 判定 |
|---|---|---|
| 组合日均超额 | **+0.150%**（param_thr60_real +0.149% 完全复现 ✓） | — |
| 成交笔数 | 102（≈47 独立轮次） | — |
| 单笔收益折算 t（~47 轮） | 2.17 | 边缘 |
| 组合日超额折算 t（~47 轮） | **0.39** | 不显著 |
| **block bootstrap 95% CI**（块长 11 日） | **[-0.021%, +0.328%]** | **含 0 → 组合层面不显著** |
| 剔除最优 1 笔均值 | +2.589%（仍正） | 非单票运气 |
| 剔除最优 5 笔均值 | +1.779%（仍正） | 非单票运气 |
| 最优 5 笔占全部收益 | 43% | 收益集中但非唯一来源 |
| Bonferroni（α=0.0001） | 未过 | 参考（500 组合高度相关，过严） |

**结论**：最保守口径（组合层面+正确处理自相关）**不显著**，与 hy4 判断一致；
但**非单票运气**（剔极值稳健）是积极信号——alpha「存在但未证明」。

### P1-3 卖出侧过滤影响量化

- 复跑 g2 全参数空间（N=1/3/5/10 × 滑点 0/0.1%/0.2%）：**卖出被一字跌停挡住次数 = 0，退市清仓 = 0**；
- N=10/0.1% 结果 +0.149% 与改动前 **完全一致**（旧值亦 +0.149%）；
- **结论：hy4 担心的"卖出无跌停过滤系统性高估收益"在该数据集/配置下实际影响为 0**，但代码修复仍保留（防御未来场景、语义更正确）。

### P1-4 红线 walk-forward

| 区间 | 红线 | 日均超额 |
|---|---|---|
| IS 2024-07~2025-06 | 50/55/58 | ≈-0.025%（几乎一致） |
| IS | **60** | **+0.132%**（IS 最优） |
| IS | 62 | +0.018% |
| **OOS 2025-07~2026-08** | **60（IS 前定）** | **+0.078%（正）** |

**结论**：IS 前定选参即红线 60 → 「红线 60 是事后挑参」不成立；OOS 仍正 → 参数有样本外支撑。
但 IS 段 58→60 从 -0.027% 跳到 +0.132% 的符号翻转再现（hy4 裂缝 3 的脆弱性确认），参数敏感。
局限：OOS 与模型 test split 重叠、仅 ~25 独立轮次，为弱证据。
