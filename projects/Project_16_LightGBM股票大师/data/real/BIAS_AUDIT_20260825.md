# 偏差审计报告（2026-08-25）

> 对最优配置（g2_strong_real + 真实F2/F5 + 红线60 + 持仓2）回测结果的三类偏差审计。
> 测试期 2024-07-01 ~ 2026-08-14（516 交易日）。

## 1. 未来函数（Look-ahead bias）—— 通过

- 设计：T 日特征（收盘后可得）→ 模型 T 日评分 → T+1 开盘买入，时间对齐正确。
- 逐日打分用 `est`（T+1 快照）仅用于可执行过滤（一字板/停牌）与 open→open 收益计算，属正确的执行模拟，非特征泄漏。
- 定点核对：2024-07-05 三只样本的 `mf_main_net` 与当日 moneyflow 完全一致（T 日对齐）。
- 龙虎榜/北向/研报/筹码/竞价均为 T 日盘后可得数据。

## 2. 幸存者偏差（Survivorship bias）—— 影响很小

- 全库 5820 只；测试期内提前终止（疑似退市/长期停牌）70 只。
- 面板含其中 45 只（1.05%）；市场基准包含它们（方向上使超额略保守）。
- N=10 台账买入 462 只中退市/停牌 0 只 → 买入池无幸存者偏差实质影响。

## 3. 过拟合 / 时期依赖（Overfitting）—— 存在，需正视

子区间稳健性（日均超额 @ 滑点 0.1%）：

| 区间 | 红线58 N5/N10 | 红线60 N5/N10 |
|---|---|---|
| 全程 | +0.024% / +0.055% | +0.095% / +0.149% |
| 前半 2024-07~2025-06 | -0.069% / -0.027% | -0.012% / +0.132% |
| 后半 2025-07~2026-08 | +0.141% / +0.173% | +0.150% / +0.180% |

结论：
- alpha 高度集中后半段（2025-07 后），前半段明显弱；N=5 前半段红线 60 为 -0.012%。
- **N=10 + 红线 60 相对稳健**：前半 +0.132%、后半 +0.180%，两子区间均为正。
- 红线 60 与持有期 N 为测试期全期寻优，存在参数过拟合成分。
- 步行前推视角：若在前半段选参（红线 60 N10 已是两阈值最优），后半段（未见数据）+0.180% 仍为正 → 该组合有样本外支撑。

## 应对措施

1. 后续参数改用**步行前推（walk-forward）**选参（前半段定参，后半段验证），不再全期寻优。
2. 以 2025-07~2026-08 作为样本外段，N=10 + 红线 60 已通过（+0.180%）。
3. 最终以每日前向纸面测试（`paper_forward.py --live`，定时任务 paper_forward_daily）持续跟踪样本外表现。
4. 年化收益（N10 75.88%）为回测口径，受时期依赖影响，实盘预期应保守下调。
