## 3. 主判据（冻结）

对每个变体 v ∈ {rank_univ, rank_pool, ladder545, ladder2468}，在 **OOS 段**：

1. **边际票集合**（逐日，Top10 池内、可执行过滤后）：
   - R_d(v) = {total_v ≥ 60 且 total_abs < 60}（rank 侧新增）
   - A_d(v) = {total_abs ≥ 60 且 total_v < 60}（abs 侧新增）
2. **逐日配对差**：
   Δ_d(v) = meanEx(R_d) − meanEx(A_d)，meanEx 为集合内 ex 的 nanmean；
   **空集约定**：一侧为空集（或全 NaN）时该侧 meanEx 记 0；
   **双侧均为空集的日子 Δ_d = 0 并计入样本**（保守稀释）。
3. **点估计**：Δ̄(v) = mean over OOS 全部交易日的 Δ_d。
4. **推断**：**circular block bootstrap**，块长 L=5 交易日，重采样 B=10000 次，
   对 Δ̄ 的 bootstrap 分布取 percentile 95% CI。
   双侧 p_raw = 2 × min(P(Δ* ≥ 0), P(Δ* ≤ 0))；**Bonferroni 校正 p = min(1, 4 × p_raw)**
   （4 变体族）。
5. **子区间符号一致性**：OOS 前 1/3（前 floor(n/3) 个交易日）与后 1/3（后 floor(n/3) 个）
   各自的 Δ̄ 子段均值，要求三者（前 1/3、后 1/3、全 OOS）符号一致且非零。

**单变体「有方向证据」判定（三重门，全部满足）**：
(a) 95% block bootstrap CI 不含 0；
(b) Bonferroni 校正后 p < 0.05；
(c) 前 1/3 与后 1/3 子段均值符号一致，且与全 OOS 符号一致。

任一门失败 → 该变体裁决为**不可识别**。

**工作包 B 总裁决**：仅当 ≥1 个变体通过三重门时，总裁决 =「有方向证据」（并指明变体与方向）；
否则总裁决 = **不可识别**。禁止给出任何带方向的点估计结论作为裁决。
