## 2. §9-1/2 多行 INIT 真修（本轮核心）

产出 `("CONT", 原文, ts)`：

```python
prev_was_event = False
for line in txt.splitlines():
    ...
    em = LINE_RE.search(line)

        out.append((...)); prev_was_event = True; continue
    if prev_was_event and line.strip():

```
