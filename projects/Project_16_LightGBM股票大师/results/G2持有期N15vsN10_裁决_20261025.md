# G2 持有期 N15 vs N10 裁决报告 · 2026-10-25（已按审计修正）

> 背景：2026-10-08《P16三策略优化方案》B1 建议回退 N15→N10，当时证据 n=91、t≈−1.5 未过线、从未执行，live 保持 N15。本次双线复验。
> ⚠️ 单源结论（仅 astock），未经备用源交叉验证。
> ⚠️ **本报告首版（同日）有 3 处错误，已按 `G2持有期N15vsN10_审计_20261025.md` 修正**，修订处标 `【修订】`。

## 一、双线证据（修订后）

### 纸面配对线（`G2持有期N15vsN10复核_20261025.md`）
公共窗口 08-17~09-23，**n=197 / 27 个信号日**：

- rank≤15 逐笔：N15−N10 = **−2.00pp/笔，t=−3.07**
  【修订】首版为 −2.47pp / t=−3.08。差额来自 300773.SZ（2026-09-11 信号）在 10-08~10-14 停牌、
  `open=0` 被算成 `r15=−100%`，单笔贡献 −95.5pp，占均值 19%。已修数据过滤。
- rank≤3 逐笔：−2.58pp，t=−2.83
- **【修订·关键】日级聚合（每日先票内等权，消除同日多票相关性）：−0.79pp，t=−0.68 → 未过线**
  日期块 bootstrap（重抽信号日 5000 次）95%CI **[−2.96, +1.52]**，P(均值<0)=0.76。
  197 笔实际只有 27 个独立信号日（日均 6.8 只）+ 相邻日 N=10 窗口重叠 → 逐笔 t 虚高约 2.7 倍。
  **B1 要求的「公共窗口累积配对 t>2」在正确口径下从未达成。**
- 【修订】9 月毛差主要是**市场 beta**：市场调整后超额差 −0.42pp（逐笔 t=−0.45）/ +0.33pp（日级 t=+0.70），
  符号不一致且不显著；8 月超额差 +0.97pp（t=+0.62）。

### 5 年分段回测线（`G2持有期N15vsN10_5年回测_20261025.md`）

live 模型、同参数、唯一变量持有期，11 个半年段：

- 段胜负 N10 胜 5 / N15 胜 6；**【修订】11 段配对 t = −0.83**（首版误写 −0.72），远不显著
- 累计复利：N10 +355.6% vs N15 +597.4%
- **【修订·关键】剔除 2026H1 后并非「反转」，而是几乎持平：N10 +327.4% vs N15 +323.1%（差 4.3pp）**
  首版「N10 +604.5% vs +351.0%、方向反转」为计算错误。
- 【修订】本表**不是纯 OOS**：live 模型训练切分 = train 2020-01~2023-06 / valid 2023-07~2024-06 /
  test 2024-07~（`train_g2.py:214-217`），故 2021H2~2024H1 共 6 段属样本内/验证内，仅 2024H2 起 5 段是 test。
  按分窗重算：train +2.58pp（t=+0.27）/ valid −2.28pp（2 段）/ test −13.04pp（t=−1.15）/
  test 剔 2026H1 −1.75pp（t=−1.10）。**任何分窗都未过 |t|>2。**
- 【修订】末段 `2026Q3+` 实际只到 **2026-08-14**（面板截止），32 个交易日，非「至 10-23」。
- 【修订】N10/N15 因周转节奏不同会选中**不同的票**（2026H1：N10 21 笔/STOP 5 vs N15 17 笔/STOP 2），
  段差含选股路径分叉成分，不是「同票多持 5 天」的边际收益。

## 二、判读（修订后）

1. **纸面线的「过线」是伪显著**：正确口径（剔除停牌 0 价 + 日级聚合）t=−0.68，置信区间跨 0。
2. **回测线任何分窗都不显著**；剔除 2026H1 后两臂累计几乎打平（+327.4% vs +323.1%），
   N15 的累计领先全部来自 2026H1 单段（+64.82% vs +6.59%），而该段仅 17~21 笔交易。
3. **市场调整后纸面线略偏 N15**（日级 +0.57pp，t=+0.70，不显著），与「改回 N10」方向相反。
4. 两条线的方向甚至相反（纸面逐笔偏 N10、市场调整后偏 N15、回测长窗口无差异），
   说明差异在噪声范围内，**不构成改参依据**。

## 三、裁决建议（供诚哥拍板）

**维持 N15 不变（不执行 B1 回退建议）。**

理由（修订）：
1. 纸面线在正确统计口径下**从未过线**，其反向信号 19% 来自一笔停牌假亏损、其余主要是市场 beta；
2. 回测线无论全样本、分训练窗、剔 2026H1 均无统计显著差异；
3. 改参无收益而成本确定——N10 年换手多约 8 轮（每轮 20~60bp，年增 1.6~4.8% 成本），
   且引入执行口径扰动风险；
4. B 级参数纪律：证据不足时维持现状。

后续观察点（口径修正）：纸面样本继续累积，若 10、11 月**日级聚合口径**连续两月 N15−N10 各月 t<−2，
再重新提请裁决。（首版写「纸面连续两月 t<−2」时用的是逐笔口径，须改日级口径，否则会因伪显著反复触线。）
