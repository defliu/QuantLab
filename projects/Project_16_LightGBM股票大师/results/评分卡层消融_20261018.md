## 〇、为什么要跑这个

2026-10-17 [B21 信号内产版策略级回测报告](B21信号内产版_策略级回测报告_20261017.md) 给出内产版（沙箱内特征 B21 + 简化红线 prob≥0.60）年化 **+18.8%**；
而官方口径 G2（43 特征模型 + 评分卡 total_new≥60）冷启动年化 **110.1%/113.6%**。差 6 倍，但差在哪没拆过。
本消融做 2×2：**模型档（0825_1964t 官方锚点所用 / 0915_1522t 现役）× 评分卡层（ON / OFF）**，
其中 `scorecard_OFF` 把 per_day 的 `total_new` 直接换成 `prob*100`（帧内已含 prob 列，引擎零改动），
等价于「候选池仍由 prob 决定，但门槛与排序都只用模型分」——即沙箱内产版的简化红线语义。

**校验档**：0825 + 评分卡 ON 必须复现 jq_metrics 官方锚点。实测 **PASS**：
总收益 357.41% / 年化 110.12% / 夏普 2.278 / 回撤 -16.71% / 交易 78 笔 —— 与锚点逐项一致 → harness 可信。

## 二、效应分解

| 效应 | 对比 | Δ年化 | 读法 |
|---|---|---|---|
| **① 评分卡层（0825 模型）** | 110.12% → 19.43% | **-90.7pp** | 拿掉评分卡 ≈ 抹掉 82% 的年化 |
| **①' 评分卡层（0915 模型）** | 68.71% → 30.36% | **-38.4pp** | 现役模型对评分卡依赖小得多 |
| **② 模型档（有评分卡）** | 110.12% → 68.71% | **-41.4pp** | 官方口径下 0915 现役 < 0825 |
| ②' 模型档（无评分卡） | 19.43% → 30.36% | +10.9pp | 只看模型分时 0915 略优（与 B21 报告方向一致） |

**交互**：评分卡对 0825 模型的增益（+90.7pp）远大于 0915 模型（+38.4pp）——两模型与评分卡的互补性差异极大，不能把"评分卡增益"当常数外推。

**风险面（比收益更关键）**：拿掉评分卡后回撤从 -16.7% 恶化到 **-34.8%**（0825）/ -22.0%（0915），盈亏比从 2.70/1.85 掉到 1.17/1.28。
即评分卡层同时贡献**收益与风控**：它筛掉的是"高 prob 但脆弱"的票。

**执行口径**：无评分卡时"跳到执行跳过"从 37 涨到 81（Top2 by prob 更常撞一字板/停牌/无量）——评分卡排序同时降低了不可成交概率。

## 三、结论（四条）

1. **官方口径 110.12% 中约 90.7pp 来自评分卡层**（同模型对照，单一变量）。这解释了内产版 18.8% 与官方 113.6% 的差距主体：**沙箱砍掉评分卡层 = 放弃最大的单一收益与风控来源**，不是模型退化问题。
2. **独立发现（需单独核查）：现役 0915 模型在官方口径下只有 +68.71%，比 0825 低 41.4pp**（夏普 1.84 vs 2.28）。这意味着 09-15 的模型换版在官方口径下很可能是一次**降级**；与 09-10 策略层门禁记录（08-25 = +0.213%/日）方向一致。**不改任何生产配置，仅登记待核查**（涉及是否回退 0825 属策略变更，须单独实证+拍板）。
3. **交叉验证成立**：无评分卡的官方口径（19.43% / 30.36%）与 B21 报告内产版 18.79% 同量级 → 两个独立 harness 互证。
4. **附注不一致（不改变主结论）**：B21 报告的"现役43f 臂"为 +6.59%（TOP3 + tier 门控 + gap 校验 + 窗口至 09-30），低于本消融同模型同红线（TOP2、无 tier/gap）的 +30.36% 约 24pp，原因未定位，建议后续核查该 harness。

## 四、口径与近似（诚实声明）

1. `scorecard_OFF` 是"**评分卡整层拿掉**"的极端对照，**不是**"把沙箱内可实现的部分评分卡内移"的最佳可实现版（F1/F3/F4 理论上可内移，F2/F5/F6 不可得）；
2. 单源（仅 astock），未做 gpsj 备用源交叉验证；窗口仅 2024-07~2026-08（2 年，含小盘普涨 regime）；
3. deploy=0.95（引擎原默认，与 jq_metrics 锚点一致）；止损/止盈/追盈按开盘判定，与 live tick 级有差；
4. 持仓上限 TOP2 与实盘 G2 TOP_N=3（2026-09-21 拍板）不同；tier 门控 / gap 低开校验 / ST 强制卖出未纳入（与 jq_metrics 官方口径一致）；
5. 全部为回测数字，未做模拟盘验证。
