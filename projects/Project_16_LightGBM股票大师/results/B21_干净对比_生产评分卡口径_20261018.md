## 六、结论

1. **生产评分卡信号层（SC60）年化 -3.87%**，较同模型简化红线（+12.26%）-16.1pp，较 B21 内产版（+5.84%）-9.7pp。
2. 评分卡层（生产元口径 F2）在同 harness 下无正贡献（-16.1pp），与官方消融方向相反。
   - **归因三角（F2 语义 vs harness）**：同模型 prob 红线 +12.26% → 生产 F2（元）-3.87% → 退化 F2（万元，官方消融 F2 语义）-5.12%；F2 语义差 -1.3pp，退化口径评分卡较 prob -17.4pp。
   - **方向反转主因 = harness**：退化 F2（官方消融语义）在本 harness 同为负（-17.4pp）——官方 +38.4pp 为官方 harness（TOP2/无 tier/08-14 窗/官方引擎）产物，与 F2 语义无关。
   - **旧口径（t1_open）三角**：prob +6.59% → 生产 F2 +4.79%（退化 F2 +4.67%）——评分卡层贡献 -1.8pp，与主口径方向一致（均非正）。
3. **对原问题的回答：沙箱解除后原方案（生产评分卡）并不优于 B21 内产版（-9.7pp）**；简化红线方案在策略级已是更优信号层。
   - **tier 口径稳健性**：两口径下生产评分卡均劣于同口径 B21 内产版（t0_close -9.7pp / t1_open -14.0pp）且均无正的评分卡层贡献——「原方案不更优」结论对 tier 口径稳健；但 **B21 vs 现役 43f 的相对强弱随 tier 口径反转**（B21-现役 gap：t1_open +12.2pp vs t0_close -6.4pp），tier 口径取舍需拍板（影响内产版 vs 现役的结论与已上线方案的评估）。
4. 诚实披露：同期全市场等权基准（不可投资参照）仍高于全部配置（小盘普涨行情），绝对 alpha 的持续性依赖风格环境；引用任何口径数字必须带第五节披露。
