## 一、目标与定位

在原工作流（仅选股 + 预警）基础上，升级为**全自动交易闭环**：

- 盘后：自动选股（QMT 本地粗筛）→ 新浪智研实时复核（F2 资金 + F3 新闻）→ 出完整版清单
- 次日 09:45：自动换仓（`rebalance_daily.py --live`，先卖被 PK 的、买新晋 top2）
- 盘中：六档盯盘（`qmt_monitor.py --once --auto-sell`）自动止损止盈
- 全程：**无智能体、无人工**（仅需 QMT 客户端保持登录在线）

## 三、架构流程

```
[交易日 16:30] 盘后链路（无人值守）
  xtdata_update.py               拉当日增量
  merge_live_features.py         生成当日快照 latest_features.parquet
  deploy_predict.py --model v3    模型粗筛 → 预选池 Top100
  [QMT 本地] F1/F4/F6/F5 评分      实时量价 + 板块涨幅
  [新浪智研] Top20 资金+新闻复核    填 F2/F3 → 完整版清单 *_selection_full.csv

[交易日 09:45] 自动换仓（无人值守）
  rebalance_daily.py --date <今> --live   读完整版清单 → 卖被PK / 买新晋 top2

[交易日 六档] 自动盯盘（无人值守）
  qmt_monitor.py --once --auto-sell        09:45/10:30/11:00/13:30/14:00/14:30
                                             止损-7% / 止盈+15% / 移动止盈 → 自动卖出

[周一 17:00] 周更重训（需研发电脑 + 人工同步）
  研发电脑 build_features_v2 → v3面板 → train_optuna → 拷回服务器
  sync_from_dev.ps1 归位校验
```

## 四、待开发模块（启用前需完成）

1. **`collect_sina_review.py`（新建）**：新浪智研 API 采集 Top20 主力资金/新闻 → 生成 `data/tdx_review.json`（与 `review_full.py` 兼容格式）。
   - 接口形态：`GET https://mcp.finance.sina.com.cn/api-call/<code>?params`，Header `X-Auth-Token: <key>`
   - 资金：待确认 A 股资金趋势接口 code（MCP 清单中资金趋势标注为美股，A股需登录 API 文档页确认）
   - 新闻：公司资讯/公告接口（待确认 code）
2. **自动买入接线**：建 Windows 计划任务 `Quant_Rebalance_0945` → `rebalance_daily.py --live`（真实委托，需用户最终确认）。
3. **自动卖出接线**：盯盘六档改 `--auto-sell`（改 `run_scheduled.ps1` monitor 分支 或建 6 个计划任务）。
4. **QMT 保活守护**：脚本检测 QMT 进程掉线自动重启/告警（QMT 非常驻服务，这是无人值守最大风险点）。
5. **切换开关**：在 `qmt_config.py` 加 `WORKFLOW = "original" | "auto_trade"`，一键切换，避免改多处。

## 五、风险与注意

- 自动卖出/换仓为**真实委托**，启用前务必模拟盘验证 1-2 周（当前为模拟盘账号 70180771）。
- 新浪智研为按量收费，脚本需做请求次数预算与失败重试（避免超额扣费）。
- 重训仍需研发电脑（8GB 内存不够）→ 每周一次人工同步，无法彻底无人值守；若要彻底，需加内存到 16GB。
- QMT 客户端掉线/断网/重启需人工重登 → 用保活脚本缓解但不能 100% 解决。
