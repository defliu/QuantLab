## 一、Objective（策略目标）

### 1.1 核心目标

在 A 股市场捕捉主升浪行情，通过**板块+个股双强 RPS 过滤**识别高强度趋势股票，配合**严格风控**控制回撤，实现风险调整后收益最大化。

### 1.2 量化目标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 年化收益率 | ≥ 15% | 扣除成本后 |
| 夏普比率 | ≥ 0.8 | 测试集 |
| 最大回撤 | ≤ 25% | 测试集 |
| 胜率 | ≥ 45% | — |
| 盈亏比 | ≥ 1.5:1 | 扣除成本后 |
| 信息比 | > 0.5 | 相对沪深 300 |

### 1.3 核心假设

| # | 假设内容 | 证据状态 |
|---|---------|---------|
| H1 | 板块 RPS 前 5 的个股有持续超额收益 | ⚠️ 业界验证，需 PIT 回测 |
| H2 | 个股 RPS>90 的股票翻倍概率显著高于市场 | ⚠️ IMA 文章声称 7.8 倍，需验证 |
| H3 | 大盘门控（000300>MA60）可大幅降低回撤 | ✅ 诚哥通宵研究已验证（回撤砍半） |
| H4 | 严格风控（4 层体系）可将回撤控制在 25% 以内 | ✅ 北京炒家实盘验证 |

## 三、策略架构

### 3.1 信号流程

```
[大盘门控] → [个股 RPS 过滤] → [突破确认] → [放量确认] → [等权建仓]
     ↓              ↓                ↓              ↓              ↓
  000300>MA60   RPS>90        突破20日新高   量>5日均量1.5x   前20只
     ↓              ↓                ↓              ↓              ↓
  熊市空仓      全市场前10%     趋势启动       资金确认        分散持仓
```

### 3.2 风控体系（4 层）

#### Layer 1：分仓（防黑天鹅）
- 单票 ≤ 1/20 = 5%（等权 20 只）
- 总仓 ≤ 100%（牛市）/ 0%（熊市，大盘门控）

#### Layer 2：硬止损（机械化）
- 个股浮亏 > 8%：立即离场
- 跌破 20 日线：离场（暂未实现，留待 v1.1）

#### Layer 3：移动止盈（保护利润）
- 最高价回撤 > 12%：清仓

#### Layer 4：大盘择时（动态仓位）
- 000300 > MA60：允许开仓
- 000300 < MA60：空仓

#### Layer 5：时间止损（防死扛）
- 持仓超过 60 天：强制离场
