# 529 选股 + 集中持仓 + 风控引擎 方案设计（2026-08-15）

> 前置实证：`research/huangshi_top5_rank_test.py`，全 A 2019-2025，529 信号池内排序对比。
> 一句话结论：**"趋势最强前5只"被数据否定（6 个趋势指标全部跑输全池）；"ATR 低波前5只"有效（不损收益、提胜率）**。

反向验证：趋势"最弱5只" fwd20 +0.80%~+0.88%，接近全池——证明 529 的 alpha 来自**分散买入启动前夜**，不是追最强。
ATR 前30%（约4只/日）更是 +1.40%/47.6%——**池内低波筛选增益随仓位扩大更明显**。

### 核心结论
1. "趋势最强 = 好票"直觉在 529 池内**不成立**（6/6 指标证伪），与 QuantLab 历史教训一致：追高=买在情绪顶点；RPS 主升浪已因候选枯竭+单票运气证伪。
2. **ATR 低波是池内唯一有效排序维度**（QuantLab 已验证 ATR 低波为 A 股强因子，此处独立复现）。
3. 集中 5 只 vs 全池（日均12只）本质是"收益换集中"：集中不增加 alpha，只放大方差；收益端必须靠风控保护。

## 二、推荐方案：529 启动前夜选股 + ATR 低波取前 N + 分层卖出风控

### 选股层（PIT 安全）
- 529 版信号：低位筹码蓄势（90% 筹码 ≤25% 区间）+ 3 日内突破 60 日高（日均约 12 只，无枯竭风险）。
- 池内按 ATR%（20 日真实波幅/收盘价）升序取前 N。**N 待定档：5（集中进攻）/ 8（平衡）/ 12（全池防御）**，实证显示 N 越大越优，建议实盘起步 N=8~12。

### 持仓与建仓
- 信号出现日收盘买入（T 日信号、T+1 开盘执行更保守，待回测定夺）；等权 1/N。
- 滚动持仓：每日新信号入池，按 ATR 排序补空位，非信号日不交易（低换手）。
- 每票上限 20%（N=5 时）防单票灾难，或直接等权不设上限（实证看）。

### 风控层（复用 SellStrategyEngine 分层卖出，四层）
1. **底线**：个股止损 -8%（黄氏/QuantLab 标准），硬止损不商量。
2. **清仓**：组合回撤 -15% 全清；大盘 MA200 门控（2022/2023 两年亏损全在熊市，门控可砍掉大部分，代价年化 -4.4pp 已有实证）——**门控收益/风险取舍待回测定夺**。
3. **预警**：单票浮亏 -5% 预警，减半仓。
4. **确认**：持有 60 天到期强制卖出（529 fwd60 仍 +2.22%，中期持有有效）；趋势破位（跌破 MA20）提前确认卖出。

### 交易细节（沿用项目红线）
- 涨停买不进/跌停卖不出/停牌跳过（回测引擎已支持）。
- 成本：佣金万2.5 + 印花税卖出千1 + 滑点 0.1%。
- 每票资金 ≤ 子账户本金 20%（N=5），账户总额约束走 `capital_allocation.yaml`。

## 三、预期特征（基于实证推算，非回测承诺）
- 胜率 47-49%（ATR 前5实证），每笔期望 +1.1%~1.4%/20 日。
- 年化不可线性外推（持仓重叠+风控+成本影响），**必须跑完整引擎回测**。
- 风险提示：529 单票幅度温和（大涨≥20% 仅 5.2%），本策略赚的是"稳定小赢"，不是"押中大牛"；与 RPS 单票运气的赌法完全相反。

## 四、待回测验证项（下一步）

2. 信号日收盘 vs T+1 开盘建仓差异（撮合 look-ahead 防护验证）。
3. 卖出四层风控参数敏感度（止损 8%/回撤 15%/持有 60 天）。
4. 与 ATR 低波主策略的相关性（若高相关则无组合价值，若低相关可作进攻腿）。
