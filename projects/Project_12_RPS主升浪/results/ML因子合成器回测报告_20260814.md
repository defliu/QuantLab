# ML 因子合成器 — 回测研究报告（2026-08-14）

> **日期**: 2026-08-14
> **定位**: 验证"ML 是否能比手工等权更好地组合已验证因子"
> **对比基线**: 4 因子等权手工（诚哥拍板，最公平）
> **区间**: 2019-01-01 ~ 2026-06-30（全 A，PIT）
> **输入**: BP(行业中性z) / ATR%(低波) / 换手率 / ROE（4 个已验证因子，截面归一化）
> **标签**: 未来 20 日相对沪深300 是否超额（分类）
> **模型**: LightGBM 滚动训练（过去 30 调仓日），每月重训，TOP50 等权
> **状态**: #已回测（ML 跑赢等权，但两者均负收益）

---

## 一、结论（一句话）

**ML 在"组合已验证因子"环节确实优于手工等权**（全期年化 -2.50% vs -4.76%，+2.26pp；回撤 -36.7% vs -53.2%；夏普 -0.18 vs -0.70），**但两者均为负收益**——ML 放大因子质量，不能无中生有。

---

## 二、回测结果（全 A，2019-2026）

| 指标 | 4因子等权（手工） | ML 合成 | 差异 |
|---|---|---|---|
| 全期年化 | -4.76% | **-2.50%** | ML +2.26pp ✅ |
| 全期回撤 | -53.2% | **-36.7%** | ML 好 16.5pp ✅ |
| 全期夏普 | -0.70 | **-0.18** | ML 明显好 ✅ |
| 训练段年化 | +3.23% | +9.20% | ML 强 |
| 验证段年化 | -16.04% | -4.68% | ML 强 |
| 测试段年化 | -12.21% | -6.45% | ML 强 |

## 三、特征重要性（ML 学到了什么）

| 因子 | 重要性 | 占比 | 解读 |
|---|---|---|---|
| **ATR%（低波）** | 4634 | 34.3% | ML 最重视 |
| **换手率** | 4602 | 34.1% | 第二重视 |
| ROE | 2586 | 19.2% | 质量，中低 |
| BP | 1673 | 12.4% | 价值，最低 |

**关键发现**：ML 用数据自己"发现"低波 + 换手（合计 68%）是最强组合——**这正是你 ATR 低波实盘（18.7% 年化）用的两个核心因子**。等权基线给 BP/ROE 各 25%（过高），而 ML 把权重集中到真正有效的因子上。

---

## 四、诚实解读

### ✅ ML 有真实价值（不是 Project_04 的失败）
- ML 在"组合已验证因子"这个环节**稳定跑赢手工等权**（全期 + 三段切分都赢）
- 回撤改善 16.5pp，夏普大幅提升
- 证明了 ML 因子合成的价值定位是对的

### ⚠️ 但两者都亏钱（核心限制）
- 输入的 4 个因子在"连续打分选 TOP50"框架下本身不足以盈利
- 与 ATR 实盘（18.7%）的差异：ATR 用**严格合格域过滤 + 季频 + 大盘门控**，这里是连续打分选 TOP50
- **ML 放大的是因子质量，不是凭空创造 alpha**——因子差，ML 只能从 -4.8% 改善到 -2.5%

### 💡 下一步可行方向
若要把 ML 变成盈利策略，需把 ML 合成接入**已验证盈利的框架**：
```
ML 合成因子 → ATR 低波合格域过滤（ATR%<6 + 换手1-8%）
           → 大盘门控（000300>MA60）
           → 季频调仓 + 风控
```
即：用 ML 替代"手工排序"，但保留 ATR 的过滤/门控/风控层。
