## 一、引擎实现说明

- `strategy/huang_529.py` 新增 `trailing_stop` 参数（None=关；0.15=规则 `收盘 ≤ 持有期最高收盘
  ×(1-0.15)` 触发，与止损/到期同层卖出）。
- **PIT 关键实现**：引擎语义为「决策日 T 的 `market_window` 只含至 T-1 的数据，`position.last_price`
  已被 mark 为 T 收盘」。故 `_peak_close_since_entry` 取 `max(窗口内 entry_date 起的收盘, 今日收盘 last)`；
  若 entry_date 当日刚买入（窗口尚无入场日 bar），仅用 last 兜底。
- **排障记录**：初版按「window 含当日」假设实现，导致入场日 peak 误取全史最高
  （601107 案例：entry=2019-01-08 时 peak 返回 5.67 前史高 → dd=-22% 假触发 → 3 年区间 trail 触发 824 次、
  buys 177→927，远超离线预期）。修正后同区间 trail 触发降至 55 次、buys 200，机制正常。
- 回归：修正后 1922 段 base = 14.22%/454 笔，与旧 `v3_1n_n12_h60_s12_1922` **完全一致**，base 行为零回归。

## 三、引擎级 vs 离线反事实：为什么结论反转

| 指标 | 离线反事实（§2.4，固定 423 笔入场） | 引擎级（本验证，含补位再入场） |
|---|---|---|
| trail 出场笔数（全样本） | 108 笔，均收 +7.41% | 115 笔，均收 +5.38%，胜率 39% |
| 全样本单笔贡献 | +0.20pp/笔 → CAGR +0.7pp | CAGR +2.66pp（但结构不同） |
| 2023-2026 | 断言「2022/2023 改善、仅 2024 微降」 | **-1.16% vs base +6.77%** |

**根因**：离线反事实把 423 笔入场**冻结**，只改卖出规则，无法刻画「trail 早退 → 槽位释放 →
补位再入场」的换仓动力学。引擎级跑出来：trail15 全样本 churn 927 vs 837（+11% 换手），
2023-2026 段 `holding_expired` 均收从 +7.32%（137 笔）被压缩到 +4.66%（111 笔），
45 笔 trail 出场均收仅 +1.56%（胜率 44%）——**把 2023-2026 本就不高的「到期均收」右尾提前砍断**。
与报告 §2.2「信号衰减全在盈利端」的结构判断一致：近年 529 靠 60 天持有期吃延续段，trail15 在
延续段不足的市场上频繁止盈离场，换手上升、右尾截断，净效果转负。

**结论（预注册规则兜底）**：离线反事实的「trail15 唯一正优化」结论在引擎级**不成立于 2023-2026**。
预注册条件 ②③ 双双告负 → 模拟盘**不启用 trail15**，部署纯 base。
