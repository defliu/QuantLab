## 修复方案

### 1. 3b 换手率三态语义修复（P0 回归）

**问题**：`_g_turnover_available = None` 初值，消费处 `if _g_turnover_available is True:` 才应启用过滤，当前写法 `if _g_turnover_available:` 把 `None` 当 falsy → 永远不进过滤分支。

**修复**：
```python
# 初值三态语义
_g_turnover_available = None   # None=未知/未探测，True=有数据可用，False=探测过不可用→fail-open

# 探测成功时
if turnover_map:
    _g_turnover_available = True
else:
    _g_turnover_available = False

# 消费处：严格三态
if _g_turnover_available is True:
    to = turnover_map.get(code)
    if to is not None and (to < _MIN_TURNOVER or to > _MAX_TURNOVER):
        skip_turn += 1
        continue
# None/False 直接跳过过滤（fail-open）
```

**验证**：微测试 2 只同质股票（换手 3% vs 20%），20% 票被剔除、3% 票通过。

### 2. 3d `passorder` 第 6/7 参统一（P2）

**问题**：build 买入/卖出/部分卖出 三处均传 `price` 作为第 6 参（modelprice），src 传 `-1`。V2 规范：第 6 参=-1（自动取五档价），第 7 参=股数。

**修复**：build 与 src 统一改为：
```python
passorder(23, 1101, _ACCOUNT_ID, code, 5, -1, delta, 'ATR_EW', 2, '', C)  # 买入
passorder(24, 1101/1102, _ACCOUNT_ID, code, 5, -1, shares, 'ATR_EW', 2, '', C)  # 卖出
passorder(24, 1101/1102, _ACCOUNT_ID, code, 5, -1, shares, 'ATR_EW', 2, '', C)  # 部分卖出
```
> 两种写法在 QMT 均可跑，但统一到 `-1` 与 V2 对齐，并在代码注释标注“防坑指南坑1”。

### 3. 3f 源码编码规范化（P0 根因）

**问题**：src `strategy_atr.py` 使用 `# -*- coding: utf-8 -*-`，build 生成脚本 `build.py` 以 UTF-8 读取再 GBK 写入，Fix4 编辑过程触发“GBK 读入经 errors='replace' 再回写”导致中文腐蚀。

**修复**：
1. src 统一为真 UTF-8 无 BOM（首行 `# -*- coding: utf-8 -*-` 保留）
2. `build.py` 读取时 `encoding='utf-8'`，写入时 `encoding='gbk'`，**不再**对中文字符串做任何 replace/转码
3. build 产物首行强制 `# coding=gbk`
4. validate 新增：`assert txt.count('?') < 10`（允许极少数合法问号）
