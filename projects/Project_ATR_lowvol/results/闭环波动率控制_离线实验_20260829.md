# 闭环杠杆波动率控制 · 离线 overlay 实验（2026-08-29）

> 对应报告「可落地量化策略挖掘 2026-08-28」第 1 条 + 看板 T-20260829-002。
> 结论：**在 ATR_FIX_v4 上不成立，不部署。**

## 方法

- 实现 `strategy/vol_target_sizer.py::ClosedLoopVolTarget`（有状态闭环控制器，arXiv 2603.01298）。
- 离线套在最新 ATR 基线净值曲线上（`reports/20260816_113157_85e0a7_atr_lowvol_10w_price50/equity_curve.csv`，2019-01-02~2026-06-30，1814 交易日，已实现夏普 0.894）。
- 参数：σ^tar=15%/√252，h=126，g=55，θ=0.6，κ∈[-1,1]；L∈{1.0,1.5}；并与开环对照。

## 结论

1. **闭环版严格劣于开环版**，也严格劣于无 VT 基线：CAGR 6.8~7.6% vs 基线 16.96%，夏普 0.68~0.79 vs 0.894。κ 反馈把敞口压得更狠（均敞口 0.39/0.46 vs 开环 0.81/0.83），是过度防御。
2. **根因**：ATR_FIX_v4 年化波动约 18.5% **高于** 15% 目标波动，VT 只能单向缩敞口，永远在砍暴露——而 ATR 的 edge 恰在集中满仓的复利主力年份。无论开环/闭环，VT 都lose。
3. 与 **T-20260815-001**（已证伪无杠杆开环 VT）结论一致：本仓库 ATR 低波策略 **不适合波动率目标化 overlay**。
4. 论文宣称的「闭环比开环改善换手与回撤」在本数据未发生（开环夏普反而更高）。可能论文场景（IVV 买入持有，σ^tar≈σ̂ 故 w≈1）与 ATR（σ̂>σ^tar 故 w<1 被永久压制）机制不同。
