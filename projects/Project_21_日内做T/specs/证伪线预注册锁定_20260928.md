### 零股与密度统计口径（已拍板，2026-09-27 / 2026-09-28）

- 单笔预计股数 < 100 股的信号：**直接跳过、不入统计**（既不计事件数，也不进分子）。
- 每股日均 = Σ(该股全期有效信号数) / 交易日数；每百票日均 = Σ(全池单日信号数) / 交易日数 × 100 / 3055。
- 两指标**并列输出**，仅前者作过线依据。

## 二、M1 Go / No-Go 结构（进入 Phase 2 的条件）

必须同时满足：

- [ ] 上表 1~7 判据**至少 3 个信号族**全部通过（沿用 `signal_framework.md` M1 的「至少 3 族」结构）
- [ ] 合并六族：交易日聚类 t ≥ 2.0 **且** 年化夏普 ≥ 1.0（扣全成本）
- [ ] 候选密度过线（每股日均 ≥ 1.0）
- [ ] 2024（OOS）不转负，或亏损可解释

**通过 → Phase 2（分钟级回测引擎）；不通过 → 归档结题**（P12/P18 模式：报告 + 证伪归因落 `results/`）。
