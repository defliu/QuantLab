# Project_15 · 选股因子闭环研究

> 立项时间：2026-08-19
> 核心逻辑：**案例复盘 → 沉淀因子 → 选股验证 → 再复盘** 的闭环迭代

## 项目目标
从每日5只股票的选股-持仓-复盘全链路中，沉淀出可量化、可复用的「短线选股成功因子」，不断迭代优化选股成功率。

## 方法论

### 6维度选股评分卡（v0.1，首版由2026-08-18案例定义）
每只候选股票按以下6大维度打分，维度权重从实战中动态调整：

| 权重 | 维度 | 评分标准（满分10分） | 数据来源 |
|---|---|---|---|
| **25%** | F1 位置健康度 | 年内涨幅∈[-15%, +20%]得10分；>+50%扣至≤3分；<-30%扣至≤5分 | TDX行情 |
| **20%** | F2 资金认可度 | 主力净流入+量比>2得10分；净流出且缩量得≤2分 | TDX ProInfo |
| **20%** | F3 催化强度 | 有确证性基本面利好（财报/回购/并购）得10分；零消息得≤2分；纯概念得≤5分 | wenda新闻/公告 |
| **15%** | F4 技术形态 | MACD多头放大+RSI(6)>65得10分；MACD死叉/缩量得≤3分 | TDX技术指标 |
| **10%** | F5 板块β联动 | 所属板块当日>2%得10分；板块跌得≤4分 | TDX行业涨幅 |
| **10%** | F6 估值/流动性合理性 | PE(TTM)∈[10x, 30x] 且 换手率∈[1%, 8%]得10分；换手率<0.5%或>15%扣分 | TDX CwInfo |

> 加权总分 ≥70 分 = 纳入备选；≥80 分 = 优先推荐；<50 分 = 一票否决。

## 闭环流程

```
Step 1 复盘前一日5只 → Step 2 更新因子权重/标准 → Step 3 当日盘前选5只
      ↑                                                          ↓
      └─────────────── Step 5 盘后验证打分  ←  Step 4 盘中跟踪
```
