## 三、方法论（可复用资产）

- **信号扫描范式**：与 `Project_12/huangshi_formula_scan.py` 同构 —— 加载 astock 日线（hfq）→ `compute_indicators` 向量化指标 → 布尔信号 Series → 前向收益/命中率/超额/年度分解。
- **PIT 安全**：信号只用"不含当日"的前值判断（`gshift`）；未来函数 = 回测第一杀手，改信号必须重查。
- **向量化行业 RPS**：`compute_sector_rps_panel`（行业映射 → 个股 trailing 20 日涨幅 → 按日行业等权 → 当日全行业 RPS 百分位 → 映射回个股），替代 `sector_rps.py` 的逐日循环，供全面板扫描用。
- **主数据源**：`E:/astock/daily/stock_daily.parquet`（2009 起，读 parquet 时必须把 `trade_date`/`ts_code` 含进列投影，否则 pyarrow 不恢复 MultiIndex）。
- 复跑命令见 `results/买卖点策略潜力评估报告.md` §8.2 与增强版报告 §四。

## 五、硬约束 / 教训（踩过必记）

1. **门控/板块救不活无 alpha 的信号**：门控在 P10/P13 对"本身有 alpha"的策略是有效增强器（聚焦牛市时段、压缩回撤），但对无 alpha 的形态买点只压缩交易时段、不创造单信号 edge。**增强器 ≠ 造 alpha 器**。
2. **正均值是右尾幻觉**：命中率 <50%、中位数负，均值却被少数大赢家拉正 —— 这种"正均值"不可交易，必须同时看命中率 + 中位数 + 样本外。
3. **样本外必测**：区间一（2019-2025）弱正超额在样本外（2015-2018）全翻转，单区间结论不可信。
4. **gpsj is_st 语义相反（框架级 P1，未修）**：`data/gpsj_reader.py` 的 `is_st` 与 tushare 相反（gpsj ST=0 是 ST、1 正常，透传未反转），做 gpsj 交叉验证时 ST 过滤必须对齐 astock 口径（本项目的 `cross_validate_gpsj.py` 直接用 astock is_st 对齐）。详见 `全局复利与踩坑日志.md` 32b。
5. **单笔期望为正 ≠ 组合可交易**（DPO 超跌反转实证，T-20260904-007）：信号级逐笔模拟（n=64,800、胜率 57.7%、单笔 +3.86%、10/12 年正、成本×2 仍正）推进到 Top-K 等权组合 + walk-forward 后崩盘——OOS(2020-2026) 年化 +0.31%（基准 +12.0%）、卡玛 0.006、正超额 2/7、成本×2 转负。组合化把"全买分散"的统计性弱 alpha 变成择股集中 + 满仓暴露的高 beta 深跌股风险。详见 `results/DPO组合回测_20260904.md`。
6. **实盘候选必须过组合级回测 + walk-forward OOS**：逐笔模拟只能用于信号初筛（正期望/胜率），任何"可实盘候选"结论必须再过"Top-K 组合 + 逐年超额 + 训练段选参→样本外验证"。backtest-expert 的 OOS < 训练段 50% 即红旗线在本策略得到验证（OOS 为训练段 1.5%）。
