# DPO 超跌反转策略 —— 组合级回测 + walk-forward 样本外验证（2026-09-04 立项结题）

## 结论摘要（诚实裁定）

**从「研究型可实盘候选」（T-20260903-005）降级为「组合化不可行，不立项实盘」。**

前次信号级验证（T-20260903-005）显示「绝对超跌零下金叉 + 固定持有 20 日」逐笔模拟胜率 57.7%、单笔 +3.86%、成本×2 仍正、10/12 年正。但本次把信号推进到**真实资金形态（Top-K 等权组合 + 组合级回测 + walk-forward 样本外）**后：

- **walk-forward OOS（2020-2026）崩盘**：训练段（2015-2019）最优参数卡玛 0.39 → OOS 年化仅 **+0.31%**（基准 +12.0%）、卡玛 0.006、**正超额 2/7 年**、**双边成本×2 后年化 −1.37% 转负**。样本外不足训练段 2%，远低于 backtest-expert「OOS ≥ 训练段 50%」的红旗线。
- **全样本最优组合**（thr=−10% / K=40 / hold=15）年化 +17.5%，但回撤 **−45.8%**、卡玛 0.38、正超额仅 6/12 —— 未达预注册接受线（卡玛 >0.6、正超额 ≥8/12）。
- 主口径（V2 / K=10 / hold=20）年化仅 +2.20%、回撤 −63.7%、正超额 4/12、成本×2 后 +0.41%。

**机制**：信号级「全买分散」是统计性弱 alpha，靠大数定律平滑；Top-K 组合化把择股集中 + 满仓暴露叠加到高 beta 深跌股上，牛市/结构市（2020/2026）选出「继续崩的深跌股」跑输基准 20-44pp，回撤被放大到 −45%~−90%。**单笔期望为正 ≠ 组合可交易**。

> ⚠️ **单源结论（仅 astock），未经备用源交叉验证（gpsj 不可用，按全局降级规则标注）**。

## 5. 为什么组合级摧毁了信号级 alpha（方法论核心）

信号级 S2（T-20260903-005）：逐笔模拟 64,800 笔、胜率 57.7%、单笔 +3.86%、10/12 年正 —— 这是**每笔独立交易的期望**。真实资金按组合运作后：

1. **择股集中放大方差**：信号级"全部信号都买"靠大数定律平滑右尾；Top-K 只买 K 只，在 2020/2026 结构市里"跌幅最深优先"选中的是下跌动量未止的票（超跌反转在结构市退化为接飞刀）。
2. **满仓暴露**：深跌股高 beta，2015-2016/2018/2020/2026 下跌段组合同步深跌，回撤 −45%~−90%。信号级只看单笔盈亏、看不到组合路径。
3. **OOS 参数不稳**：训练段最优（thr=−20% K=20 hold=20）在 OOS 失效 —— 深度阈值与持有期的"单调/高原"仅在全样本内成立，分段后不稳健。

**两条新铁律（沉淀到 P18 PROJECT_MEMORY）**：
- **单笔期望为正 ≠ 组合可交易**：信号级逐笔模拟（n 万级、10/12 年正）在 Top-K 组合化 + 样本外后崩盘（OOS +0.3% vs 基准 +12%、成本×2 转负）。
- 继「正均值是右尾幻觉」之后：**任何"实盘候选"结论必须过组合级回测 + walk-forward OOS**，逐笔模拟只能用于信号初筛。

## 6. 最终裁定

- **不立项实盘**。组合级回测 + walk-forward 样本外证伪了 T-20260903-005 的"可实盘候选"暂定结论。
- 信号级发现（绝对超跌零下金叉 + 固定持有为统计性弱 alpha）**保留为研究结论**，但不可直接资金化。
- 残余方向（深跌反转 + 熊市/震荡门控 + K≥40 大分散）属于"打补丁救弱 alpha"，违背本仓"增强器 ≠ 造 alpha 器 / 不救无 alpha 信号"原则（P18 PROJECT_MEMORY §五.1），**不建议继续投入**。
- 与本仓既有实证同族收敛：P18 形态买点（信号级证伪）、P12 趋势选股（组合级 −60.8%）、本策略（信号级弱 alpha → 组合级/OOS 证伪）——**A 股结构型/情绪型信号无稳定的可资金化 alpha**。

## 7. 局限
