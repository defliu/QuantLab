# 买卖点信号增强版评估 —— 「信号 + 大盘门控 + 板块过滤」

- **日期**：2026-08-27
- **前置**：`买卖点策略潜力评估报告.md`（B 方案证伪：4 类买点裸信号无稳定 edge）
- **本次问题**：按建议的增强方向，叠加「大盘门控 + 板块过滤」后，4 类买点是否从"无 edge"变成"可用 edge"？
- **结论**：**增强版仍证伪** —— 门控/板块过滤救不活裸信号，样本外所有变体全部转负。

---

## 一、方法

在 `buypoint_signals.py`（裸信号）之上增加两层过滤，形成 4 个变体，对每个买点模块分别评估：

| 变体 | 含义 |
|---|---|
| base | 裸信号（对照） |
| gate | 信号 + 大盘门控（INDEXC > MA20 > MA60，严格版） |
| sector | 信号 + 板块过滤（个股所属申万行业等权 20 日涨幅的全行业 RPS 百分位 ≥ 80） |
| gate+sector | 信号 + 大盘门控 + 板块过滤 |

实现为向量化（`research/buypoint_enhanced.py`）：
- 大盘门控：指数收盘序列计算 MA20/MA60，映射到面板日期。
- 板块过滤：`E:/astock/basic/stock_basic.parquet` 行业映射 → 个股 trailing 20 日涨幅 → 按日期分组行业等权 → 当日全行业 RPS 百分位 → 映射回个股。与 `rps_momentum` 板块 RPS 同口径（已确认门控在 P10/P13 对小盘价值/主升浪有效，这里检验它对形态买点是否同样有效）。

评估口径与前次一致：信号后 5/10/20/60 日前向收益、命中率、相对上证指数超额、年度分解。

## 三、分析与结论

1. **增强版证伪，无变体可用**：门控/板块过滤对裸买点信号的改善幅度极小（区间一最好也只到命中率 48.3%），且全部在样本外消失并转负。**门控在 P10/P13 对"本身有 alpha 的策略"是有效的回撤/收益增强器，但对"本身无 alpha 的形态买点"救不活** —— 门控只压缩交易时段，不创造单信号 edge。
2. **区间一的正均值仍是右尾幻觉**：即便 gate+sector 后趋势低吸 fwd20 均值 +0.95%，中位数 -1.60% 依然亏损；靠少数大赢家拉均值，不可执行。
3. **与 P12/P17/P16 结论链完全互证**：A 股全市场"技术形态/趋势动量/涨停接力/情绪择时"等结构型信号均无独立 alpha，本报告把"买点形态 + 门控 + 板块"也收口进同一结论。
4. **方向性建议（不变）**：这些买点只适合作为**信号提示 + 人工决策**工具（满足需求文档本意），**不适合作为任何可回测/可实盘的策略基础**。不要再投入资源往"让形态买点变成策略"的方向走。
