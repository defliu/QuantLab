# 补仓方案对比回测

**回测时间**: 2019-01-01 ~ 2026-08-02
**调仓频率**: 双月 (2M)
**持仓数量**: 80只
**止损线**: 8%%
**最大回撤**: 15%%

## 方案说明

| 方案 | 描述 |
|------|------|
| 方案一(基线) | 止损后空仓，等下次换仓日(每2个月) |
| 方案二(<60%触发) | 持仓低于60%时触发补仓，补到80只 |
| 方案五(止损后立即补) | 每次止损后从候选池选1只补上 |

## 对比结果

| 指标 | 方案一(基线) | 方案二(<60%触发) | 方案五(止损后立即补) |
|------|-------------|-----------------|-------------------|
| 累计收益 | +215.1% | +232.3% | +231.7% |
| 年化收益 | +15.1% | +15.8% | +15.8% |
| 夏普比率 | 0.50 | 0.53 | 0.52 |
| 最大回撤 | -29.1% | -28.9% | -29.0% |
| 超额收益(全期) | +192.2% | +210.5% | +209.8% |
| 平均持仓数 | 79 | 80 | 80 |
| 平均换手率 | 0.91 | 0.31 | 0.34 |

## 分析结论

### 核心发现

1. **补仓策略优于不补仓**：方案二和方案五的年化收益（15.8%）均高于基线（15.1%），超额约+0.7%/年。
2. **夏普比率提升**：方案二的夏普比率最高（0.53），比基线（0.50）提升6%。
3. **最大回撤相似**：三个方案的最大回撤均在-28.9%~-29.1%区间，补仓未显著恶化回撤。
4. **2024+反转**：在2024年后的市场中，基线方案反而略优（+140.3% vs +128.8%），说明补仓在弱势市场中可能放大损失。

### 换手率说明

基线方案的换手率（0.91）远高于补仓方案（0.31/0.34），这是因为：
- 基线方案每次换仓都完整重建80只组合，即使只有少数股票被止损
- 补仓方案通过中途补仓维持组合完整度，减少了换仓时的重建幅度
- 注意：补仓方案的实际交易成本未完全计入换手率指标（中途补仓未计入）

### 方案二 vs 方案五

两者表现接近（年化15.8%），但方案二略优：
- 方案二（<60%触发）更保守，只在持仓严重不足时才补仓
- 方案五（立即补）每次止损都补，交易频率更高
- 实盘建议：方案二的触发阈值（60%）可根据市场环境调整（如50%~70%）

### 实盘建议

- **推荐方案二**：在收益提升和交易成本之间取得较好平衡
- **注意2024+表现**：补仓策略在近期弱势市场中表现略差，需关注市场环境变化
- **参数优化空间**：触发阈值（60%）、补仓数量（补到80只）可进一步优化
