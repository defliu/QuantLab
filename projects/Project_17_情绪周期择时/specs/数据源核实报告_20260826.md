## 二、关键文件实测

### 2.1 board/ths_daily.parquet（297.6 万行）

- 索引：`(trade_date, ts_code)`；样例起始 `2007-08-01`，代码形如 `881101.TI`
- 列：open/high/low/close/pre_close/avg_price/change/pct_change/vol/turnover_rate/name/total_mv/float_mv
- 可派生：板块涨幅榜、成交额占比、换手率分位、板块 RPS——全历史、PIT 安全

### 2.2 board/ths_index.parquet（2722 个指数）

- 列：ts_code/name/count/exchange/list_date/type
- type 分布：I(1264 行业多级)/N(916 概念)/TH(250 主题)/S(140 特色)/BB(93 大盘基准)/R(33 地域)/ST(26 风格)
- 用途：板块代码→名称映射；建议 Phase 0 只用 I/N 两类，剔除 BB 基准

### 2.3 lhb/limit_list_d.parquet（16.4 万行）

- 索引：`(trade_date, ts_code)`；2019-11-28 ~ 2026-08-21
- limit 类型：U 涨停 101074 / Z 炸板 37446 / D 跌停 25599 → **封板率 = U/(U+Z) 直接可算**
- limit_times 连板数：1板99047 / 2板16299 / 3板5310 / …最高11+ → 连板高度、梯队可算
- up_stat 形如 `8/10`（10天8板）；open_times 开板次数；first_time/last_time 封板时间；limit_amount 封单金额
- industry 覆盖率 100% → P16 特征 `zt_ind_cnt_v32`（行业涨停家数）可用此表独立重建验证
- 按年记录数：2020:25694 / 2021:23183 / 2022:24905 / 2023:13483 / 2024:30625 / 2025:26466 / 2026:18301

### 2.4 D:/QMT_POOL/sector_heat.json（旧管道根因实锤）

```json
{ "update_date": "20260713", "stock_heat": { "002800.SZ": 75.84, ... } }
```

- 是 QMT 端运行时写入的**个股**热度当日快照（且已过期一个月），无历史序列
- 回测引擎 `backtest/engine.py` 因此硬编码 `sector_heat_available=False`、默认 `mode=zero`
- 结论：zero mode 根因 = 旧管道只产运行时快照；Phase 0 应改为从 ths_daily+limit_list_d 自建历史序列

## 三、缺口与对策

| 缺口 | 影响 | 对策 |
|---|---|---|
| 2019-11 前无涨停明细 | 情绪指标长回测受限 | 2009~2019 用 `daily.stock_daily.up_limit` 推导涨停家数兜底（无炸板/连板）；主回测期取 2020 起 |
| 2024-12 前无 PIT 板块成分 | 个股↔概念映射有前视风险 | 主线识别优先用板块指数自身行情（无需成分）；选股层用 `limit_list_d.industry`（当日记录自带，PIT 安全） |
| ths_daily.name 列早期为空 | 板块命名不全 | 以 ths_index.parquet 为唯一映射源 |
| gpsj 备用源无板块/涨停表 | 交叉验证受限 | 按 AGENTS 规则抽自然年对比时，仅对比个股收益曲线部分，情绪序列以 astock 单源自洽校验 |
