## 一、立项依据

1. **P12 死因不重叠**：RPS主升浪证伪结论是「无择时层→候选池枯竭→持仓集中→单票运气」，本项目的核心正是补择时层与赢面仓位层。
2. **P16 实证**：行业涨停家数 `zt_ind_cnt_v32` 进入 LightGBM Top10 特征，情绪特征携带真实定价信息（V32_RESULT.md）。
3. **数据零缺口**（2026-08-26 核实）：板块指数日线 2007 起 + 涨停/炸板/连板明细 2019-11 起，详见同目录《数据源核实报告_20260826.md》。

## 二、方法论→量化映射

| 养家概念 | 量化定义 | 数据来源 |
|---|---|---|
| 情绪温度计 | 涨停家数、连板高度(max limit_times)、封板率 U/(U+Z)、昨日涨停溢价、晋级率 | limit_list_d |
| 周期五阶段 | 冰点/回暖/高潮/退潮/混沌：五指标 z-score 合成分位数阈值划分 | 同上派生序列 |
| 赢面大加仓/小试错 | 五阶段 × {0%, 30%, 60%, 90%} 目标仓位的静态映射表（先固定后优化） | 阶段判定输出 |
| 主线热点 | 板块涨幅榜前N + 成交额占比跃升 + 行业涨停家数集中度 | ths_daily + limit_list_d.industry |
| 强势股跟随 | 主线板块内：当日涨停/近5日涨幅前列，T+1 开盘介入，非涨停价追单 | daily + limit_list_d |

## 三、难点与对策（继承自评估结论）

1. **执行降维**：养家打板不可回测也不可复制 → 全部改为 T+1 跟随；回测撮合遵守真实约束（次日开盘价成交、涨停不可买、跌停不可卖）。
2. **生态漂移**：2015-2020 与 2021+ 游资生态不同 → 分段报告，判据必须在 2021+ 子样本独立成立。
3. **样本量小**：情绪周期年轮约 3-6 圈 → 预注册判据 + 参数冻结，禁止扫参后挑最优。
4. **容量风险**：主线强势股流动性差 → 设最低流通市值与成交额门槛；容量上限单独测。

## 四、Phase 划分与预注册判据（硬门控）

### Phase 0：情绪温度计有效性（当前阶段）

- 构建 2019-11 起日频情绪五指标序列 + 五阶段分类序列。
- **通过判据**：
  - P0-1 阶段哑变量对全市场小盘池（circ_mv<50亿，剔除ST/新股/退市）未来5日收益的 IC ≥ 0.03；
  - P0-2 高潮阶段 vs 冰点阶段的未来20日收益差 t 检验显著（p<0.05），且方向符合假设；
  - P0-3 序列无前视：全部指标只用 T 日收盘可得信息。
- **证伪红线**：IC<0.01 或方向反转 → 归档结题，不进 Phase 1。

### Phase 1：阶段仓位择时回测

- 基线：同一股票池、同一卖出风控的无择时等权策略（复用 engine）。
- **通过判据**：
  - P1-1 卡玛比率较基线提升 ≥ 30%（全期与 2021+ 双口径）；
  - P1-2 最大回撤收窄且年化让渡 ≤ 4pp（参照 P10 大盘 MA200 门控的代价基准）;
  - P1-3 gpsj 备用源抽年交叉验证差异 ≤ 1pp。
- **证伪红线**：仅全期达标、2021+ 不达标 → 判定为生态过拟合，归档。

### Phase 2：主线跟随选股

- **通过判据**：
  - P2-1 每个信号日主线板块内可交易候选 ≥ 5 只（防 P12 式候选枯竭，必检 `candidate_passed_avg_per_day`）；
  - P2-2 加入主线过滤后相对 Phase 1 组合有增量超额（夏普提升 ≥ 0.1）；
  - P2-3 容量测试：1000 万本金下滑点敏感度可控（D-6 通过）。
- 上线前置：B 模块全过 + D-1/D-2/D-6 至少达标（AGENTS 硬规则）。
