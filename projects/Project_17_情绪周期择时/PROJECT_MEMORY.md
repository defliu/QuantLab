## 经验教训

- **2026-08-26 Phase 0 预注册证伪（归档结题）**：情绪温度计五指标对宽基小盘池无反转型择时预测力——阶段哑变量 IC≈0（-0.002/2021+ +0.004）、冰点vs高潮 fwd20 差 0.11pp 不显著（p=0.87）、且连续情绪分对未来收益 IC 全为正（+0.026~+0.056）=动量延续，方向与养家「高潮回落、冰点加仓」假设相悖。与 P12/P16「趋势动量已证伪」相互印证。可复用资产：`results/sentiment_series.csv`（日频五指标+阶段）、`research/build_sentiment.py`（涨停明细→情绪序列构建方法，后续任何情绪类研究直接复用）。
- **教训**：立项时目标变量若用「宽基小盘池」而非「活跃股池」，情绪类择时信号极易被稀释；若未来重试应直接换目标变量（活跃池/题材股），但按预注册纪律不可事后改判据。
- **2026-08-26 Phase 0 v2 双方向复检证伪（归档结题）**：按 v1 教训换目标变量重试后仍然全败。**方向A（活跃池=昨日涨停股 fwd20 超额分层）**：三判据全 FAIL 且显著反向——高情绪组 e20=-2.01%（p=0.9998）、剔一字板后 -4.79%，即**买不到的一字板才是名义赢家、实际可买的都是输家（打板负期望实证）**；四分位非单调，情绪分层对涨停股次日溢价无区分度。**方向B（连续分位顺势覆盖层）**：形式弱阳性（B2 回撤 PASS/B3 让渡 PASS 但 B1 夏普 FAIL），被恒定仓位对照揭穿——**恒定 30% 仓 CAGR +0.98%/MDD -13.31% 全面碾压覆盖层 -0.02%/-31.65%**，弱阳性纯属现金拖累假象；分年度仅 2024 大胜、2025 踏空最惨。**方法论沉淀：任何「择时改善回撤」的结论必须先跑恒定仓位对照**——平均仓位低本身就会浅回撤，与信号好坏无关；覆盖层跑输同仓位恒定组合=信号劣于平均。
- **总结论**：情绪周期在本数据环境下的可量化投影（宽基反转择时/活跃池打板/顺势满仓覆盖层）全部证伪；连板高度 IC 虽强但不可执行变现。「大神」超额大概率在盘口博弈与信息优势等不可回测维度。翻案唯一路径=带新目标变量重新预注册。
- **2026-08-26 Phase 0 v3 活跃池连板结构检验证伪（活跃池方向永久关闭，P17 整体归档）**：按「换目标变量重试」拍板最后一次预注册，仍证伪。设计：连板=T及T−1连续两日在涨停U名单（up_stat 交叉核对 99.8% 一致），fwd5 相对小盘池超额，三判据 M1（连板组 e5>0 非重叠 p<0.05）∧M1′（剔一字板变体>0 p<0.10）∧M2（连板−首板差>0 两样本 p<0.05）。**结果：M1 PASS（+1.97%，p<0.0001）、M1′ FAIL（剔一字板后 -2.32%，p=1.0 显著反向）、M2 PASS（+1.47pp，p=0.0042）**。关键机制：**名义正超额 100% 由买不到的一字板（T+1 开盘缺口≥9.5%）贡献，可执行口径立转负**，与 v2 方向A（fwd20 剔一字板 -4.79%）双窗口互证。分年度 2019→2023 连板超额逐年衰减（+10.8%→+0.7%）、2024/2025 转负；fwd20 连板 -2.94%（短动量被均值回归吞噬）；情绪四分位 Q4 不升反降（非单调，情绪条件对打板无增益）。
- **方法论沉淀（防未来重演）**：a)「名义正超额」必须过执行感知关——凡涨跌停/一字板相关研究，先剔不可买样本再谈结论，v2 方向A 与 v3 两轮独立实证「买不到的一字板才是名义赢家」；b) 连板/涨停股短期动量即使存在也依附于不可执行的一字板，任何「接力/打板」类假设需先验证可执行口径；c) 情绪时间序列条件（无论反转或顺势）在多目标变量下均无增益，P17 已穷尽四路（宽基反转/活跃池分层/覆盖层/连板接力），**不再重启情绪类立项**。
