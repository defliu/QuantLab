接入形态与成本

· 多供应商 fallback：同一能力 discover 返回 2–4 家 provider（hangseng_polysource / caidazi / cn_financial_pro / cninfo），每家带 success_rate 与 avg_execution_time_ms 信号，可按成功率/时延路由，单个 provider 不可达自动切下一个。

· 免费额度：credits_ledger 实测 granted=1000、consumed=2、net=998；单次 call 扣 1 分。P16 每日 ~50–100 次调用可撑约 10–20 个交易日，之后 $19/月 Pro 档（1万积分）。

· 失败不收费：官方契约 failed calls not charged；龙虎榜大数据量会截断（41KB→20KB+下载URL），需按 url 拉全量。

实测踩坑（接入时必须注意）

坑正确做法
MCP 调用要用 tools/call，不能把工具名当顶层方法（否则 -32601 Method not found）tools/call + {name, arguments}
call 必须带 search_id（来自上一步 discover 返回），否则 Missing required parametersdiscover → 取 search_id → call 同会话传入
龙虎榜 / 板块工具需必填参数（如 mode、edate）先看 inspect 的 params 或错误回显的 parameter_help

建议分工（给后续任务书用）

主 F2 源：仍建议 Tushare 每日刷新 parquet（schema 一致、本地零延迟）；QVeris 作实时校验/兜底层，盘中/盘前拿不到本地值时用其四档值补齐——口径一致，不产生 skew。

F3 / 龙虎榜 / F5 板块资金流：可由 QVeris 直接供给，替代连挂的悟道 MCP。
