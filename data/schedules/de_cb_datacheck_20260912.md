## D1 行情历史深度 —— **PASS**

**验证方式**：①全市场口径：2019-2026 每年抽 3 个交易日（共 19 个有效抽样日），拉 cb_daily(trade_date) 计数，与 cb_basic 按 list_date/delist_date 推算的当日存续券数比对；②个券口径：2018-12-31 前上市的存续老券池 108 只中取 12 只，逐日全历史拉取比对交易日历。

**通过判据**（预注册）：2019-01-01 起逐日覆盖 ≥95% 存续转债·交易日。

**实测结果**：
- 全市场抽样覆盖率（cb_daily 计数 / basic 存续数）：**96.3% ~ 99.7%**，19 个抽样日全部 ≥95%；
- 个券：10/11 只有行情的老券覆盖 **99.7%~99.93%**（福能 99.93%/山鹰 99.93%/华源 99.72%/张行 99.72%/凯中 99.7%/横河 99.7%/万顺 99.7%/德尔 99.7%/苏农 99.93%/长久 99.93%）；
- 异常两只：蓝天转S1（117103.SZ，定向工具）全历史 0 行；岭南转债 86.13%——但其 2024-08 之后的行均为 0 量僵尸行（见 D7），**真实活跃交易覆盖约 73%**（2019-01~2024-08 窗口）；
- 分页限制：未触及（单次最大 ~1900 行成功）。

**裁定：PASS**。2019 起回测数据深度成立；僵尸行过滤是前置条件（不是 D1 的失败，是 D7 的风险项）。

## D2 转股溢价率计算链 —— **PASS（带实质性限制，必须双锚点 ablation）**

**验证方式**：
1. 实测 `cb_daily` 字段集：`ts_code, trade_date, pre_close, open, high, low, close, change, pct_chg, vol, amount` —— **无转股溢价率字段**（任务书"若自带则两口径核对"的条件分支未触发）；
2. 自算链：溢价率 = cb_daily.close / (正股收盘 / conv_price × 100) − 1，抽样 **20 只活跃 CB × 最近 20 交易日 = 400 组**；
3. 正股腿交叉：Tushare `daily` 正股收盘 vs **本地 astock 权威源**（D:/astock/daily/stock_daily.parquet 不复权收盘）：**100/100 组完全一致（mean_absdiff = 0.000）**；
4. 转债腿交叉：东财 push2his kline vs Tushare cb_daily：受东财限流，仅完成 **1 券全窗口比对（立讯转债 128136.SZ，2026-08-10~09-11 共 25 个交易日收盘价逐一完全一致，最大差异 0.000）**；其余 19 券请求被限流拒绝，如实标注**未完成**；
5. 合理性：400 组溢价率分布 min 4.09% / 中位 38.5% / p95 180% / max 206%，**无负溢价异常**，量级与转债市场常识一致。

**通过判据**（预注册）：抽样 20 券×20 日与集思录/iFinD 口径人工核对，误差 <0.5%。

**实测结果**：集思录/iFinD 对照源本轮不可达（未注册/无权限）；已完成的替代互证 = 正股腿 100/100 精确一致 + 转债腿 1 券 25 日精确一致 + 分布合理性。**半 PASS**：算术链在"近期窗口 + 当前转股价"口径下成立。

**实质性限制（最重要的发现）**：`cb_basic.conv_price` 是**当前快照**（bond_cov 历史序列无权限），**转股价下修/除权调整无历史版本**。对历史回测：曾下修券用当前转股价会**低估其历史溢价率**（当前转股价 ≤ 历史转股价 → 转股价值被高估）。处置方案（写入 W2-1 任务书）：
- 双锚点 ablation：受影响券（conv_price ≠ first_conv_price 者）分别用 `first_conv_price`（溢价率上界）与 `conv_price`（下界）两口径跑双低排序，若分年超额结论方向一致则判定稳健；
- 该 ablation 必须**预注册**后纳入 §2.3 证伪检验，不许只报乐观口径。

**裁定：PASS（近期口径实证成立；历史口径需双锚点 ablation 兜底，方案已给）**。

## D3 评级 PIT —— **PASS（issue_rating 为 PIT 代理，证据充分）**

**验证方式**：全量 1164 只拉取 issue_rating/newest_rating 两字段，统计覆盖率与差分；对差分券核对摘牌状态与评级变迁方向。

**通过判据**（预注册）：确认 newest_rating 是否仅当前快照；历史回测用 issue_rating 作 PIT 代理；记录覆盖率。

**实测结果**：
- 覆盖率：issue_rating **1101/1164（94.6%）**，newest_rating **1100/1164（94.6%）**；
- 两字段不一致 **151 只**，典型样本全部指向 newest_rating 为**终态/最新快照**而非历史序列：
  - 洪涛转债：发行 AA → 最新 **CCC**（2022 摘牌，违约链）
  - 众信转债：发行 AA → 最新 **BBB**（2022 摘牌）
  - 辉丰转债：AA → **A**；久其转债：AA → **A**
  - 岭南转债：AA → **C**（2024 到期违约）；东时转债：AA → **C**（2026 到期，东方时尚）
  - 上调样本：雨虹转债 AA → AA+（2020 摘牌时点后仍被更新过）
- newest_rating 对已摘牌多年的券仍在（且反映信用恶化终态），说明它既非"历史某时点"也非严格"当前"，而是**跟踪到生命末期的最新评级快照**——对历史回测一律视为不可 PIT 使用。

**裁定：PASS**。历史回测 PIT 代理 = **issue_rating（发行时点评级，无前视）**；模拟盘当下排雷用 newest_rating。R1 规则（AA- 硬下限）两口径均已落地可行。

**验证方式**：cb_basic.delist_date 统计 + 存活券与 2026-09-11 实际成交集合比对 + 东财 CEASE_DATE/DELIST_DATE 交叉 + 僵尸行实证。

- 两源互证：与东财共同摘牌券 716 只，**delist_date 零冲突（mismatch=0）**——两源摘牌日期完全一致；
- **两类缺口实锤**（不修就把偏差引入回测）：
  1. **到期违约/到期摘牌券 delist_date 双源皆空**：岭南转债（2024-08-14 到期违约，Tushare/东财 delist_date 均 NULL，东财 CEASE_DATE=2024-08-13 可补）、东时转债（2026-04-08 停止交易，同型缺口）。恒逸转2（2026-09-08 停止交易）为进行时样本；

**裁定：PASS（有条件）**。幸存者偏差防护**三保险必须全部写进回测骨架**：

## 讨论纪要（任务 A 相关部分）

**1. 任务书假设与实测不符之处**：
- 【数据口径】`cb_basic` 默认字段**不含**评级/条款字段——第二轮 §2.1 写"cb_basic 有 newest_rating/issue_rating"（基于 schema 文档）没错，但**不显式传 fields 就拿不到**，这类"schema 有 ≠ 默认给"的坑是接口行为与文档假设的第一处偏差；
- 【数据口径】中证转债指数在 Tushare 是 `.CSI` 后缀——任务书 D8 写"Tushare 指数接口，代码以实测为准"已预判，实测坐实；
- 【接口行为】`cb_call`/`bond_cov` 的 token 权限不足（40203/40101）——第二轮把 D5 列为必做项时假设接口可用，实际**当前 token 无权限**，这是排期上唯一实质受阻项；
- 【数据质量】cb_daily **摘牌后输出 0 量冻结价僵尸行**（岭南转债实证）——两轮任务书均未预见，属于新发现的回测污染源，也是本轮最有价值的实锤之一；
- 【数据口径】`conv_price` 无历史版本（bond_cov 不可用）——第二轮 D2 预案"用下修公告日重建转股价序列"依赖的接口就是 bond_cov，该预案在本 token 下不可执行，需降级为双锚点 ablation。
