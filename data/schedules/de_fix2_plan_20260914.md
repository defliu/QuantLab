追价实现（对齐指令 1a 的语义，`_fetch_price` 失败回退 `price`）：

```python
if attempts > 1:
    px = _fetch_price(code)
    if not px or px <= 0:
        px = price if price and price > 0 else None
else:
    px = price if price and price > 0 else _fetch_price(code)
```

### 设计权衡（为何 60×10 而非 300×3 或 60×15）

- **对齐红线语义**：AGENTS 实盘红线的语义是「pending 超时必须重试，约 300s×3≈15 分钟仍不成交才**允许**放弃」——是放弃时点的**下限**，不是要求等满。60s×10=10 分钟满足「不早于约 15 分钟口径的保守侧」且比原 5 分钟大幅延长。
- **不取单轮 300s**：单轮 60s 已覆盖限价单短期撮合窗口；轮次多 = 追价机会多（第 2 轮起每轮刷新现价，小步跟上移动行情），比一次挂高 300s 更可控、滑点更友好。
- **不取 MAX_RETRY=15（满格 15 分钟）**：rebalance_daily 换仓多笔**串行**，单笔上限 15 分钟时整轮换仓最坏溢出交易时段；10 分钟是「单笔耐心」与「整轮窗口」的折中。
- 601890.SH 案例（09-14）：旧逻辑 5 次全挂 9.78 贴日低（日低 9.76），高开低走行情下既无追价、窗口又短，两处缺陷本修复一并解决。
