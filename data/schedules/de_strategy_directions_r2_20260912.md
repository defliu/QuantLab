### 1.1 Q1 详述：三个收益源的"安全扩容上限"

我方 Q1 的观点（容量内数倍空间）在**流动性维度**上是对的——P10 容量表显示 1000 万才 -2.9pp、5000 万才减半（P10 报告 §10），50 万级别扩容在流动性上完全无虞。但扩容决策的真实约束不在流动性，在两处：

1. **纸面数字有系统性乐观偏差（验证债）**：P10 的容量表建立在 18.0% 状态机口径上，真实每日风控口径是 7.5%，且该口径下 2024+ 超额 **-44.4%**（P10 报告 §1）。扩容一个"近期窗口超额为负、赌的是 BP 长期溢价"的策略，吃的是容量余量，承担的是 alpha 衰减风险——这没错，但规模要与之匹配。
2. **账户风格集中度**：3 个收益源 5/5 落在小市值 A 股（第一轮 §1.1），每扩 10 万都在加深账户对同一危机情景（2024H1 微盘危机类）的暴露。扩容后的单策略规模不应超过账户总资产的 ~5%。

**分源建议值**（均为模拟账户 70180771 内 capital_base 调整，非真实资金）：

| 收益源 | 现值 | 建议安全扩容上限 | 估算依据 | Gate（每阶段放行条件） |
|---|---|---|---|---|
| ATR 低波合格域 | 10万 | **→40万**（分两阶段 10→25→40） | 集中版 8 只，40万 时单票 5万；按 P10 同款「单票≤当日成交额2%」约束需个股日成交额 ≥250万，合格域小盘低波通常数千万级（**估算值，需实测核定**）；真实约束是 2026 YTD -4.37% 的风格逆风（ATR 报告 §三） | 每阶段模拟盘 1 个月真实记录不劣于回测下界；宽池版（ATR 报告原版，期末 68 只）可另议承载 50-100万，但需先过 B/D 模块 |
| BP 价值（P10） | 10万 | **→50万**（分两阶段 10→30→50） | 容量表 1000万 才 -2.9pp（状态机口径，P10 报告 §10），50万 = 容量上限的 2.5-5%，留 5-20 倍余量对冲口径误差；扩容赌的是 BP 长期溢价（IC 0.069/ICIR 1.74/胜率 81%、2018-2025 逐年 IC 全正，P10 报告 §3）而非近期动量（2024+ 每日口径超额为负） | 同上；另加 BP 因子 IC 监控（P10 报告 §3 已就绪脚本）连续 2 期 IC>0.03 |
| P16 短线量价 ML（G2+融合） | 10万×2 | **→0（不扩）** | 纸面前向 G2 仅 4 笔 -0.0715%/胜率 25%、融合上线时 0 笔（第一轮 §1.2.4 引策略优化审计_20260910.md）；测试期 100% 落在训练窗内（双重使用）未消化 | 纸面前向累计 ≥30 笔且滚动超额为正，再议扩容 |

**资金分配比例建议**（950 万闲置口径）：

- 扩容现有：+70万（ATR +30 / P10 +40，P16 +0）≈ 闲置的 7%；
- 新方向首批：B 全天候模拟盘首笔 10-20万 → 过线后目标 200-300万（分 2 批）；A 转债数据验证过线后模拟盘 10-20万；
- **扩容:新方向 ≈ 1:4~1:5**（首批资金口径）；
- 剩余 ≥500万 保持货币 ETF/现金，随各 Gate 逐级释放——"先论证再铺"原则（第一轮 §1.3）不因并行而放松，只是把"论证"和"小额铺"的时间轴重叠了。

一句话：**我方 Q1 的"并行"我接受，但把并行理解为"两条腿都分批小额、都设 Gate"，而不是"扩容可以按容量上限数倍加注"——容量上限衡量的是"装得下"，不是"值得装"。**

### 2.2 双低 + 信用排雷可执行定义（阈值给区间，标注验证方式）

**双低基础排序**（先排雷后排序）：双低分 = 转债价格 + 转股溢价率×100，升序取前 20 等权，周频或月频调仓（周/月两档都跑，预注册后不许换）。

排雷规则集（先排雷、后进双低池）：

| # | 规则 | 具体定义 | 阈值区间 | 验证方式 |
|---|---|---|---|---|
| R1 | 评级下限 | 评级 < AA- 的券排除（A+/A/无评级全排除）；历史回测用 issue_rating 作 PIT 代理（见 D3）；AA- 券要求 R2 同时通过 | **AA- 及以上（P0 硬规则）**；ablation 跑"AA 及以上"对照档定最终线 | 回测 ablation：AA- vs AA 两档的分年超额差 |
| R2 | 债底空间（第一版代理） | 持有到期不亏钱：现价 ≤ 剩余票息现值 + 到期赎回价（maturity_call_price）；简化第一版：**现价 ≤ 到期赎回价 × 1.0 且剩余期限 ≥0.5 年**（即买入价不透支到期赎回价）；精算纯债价值（同评级企业债 YTM 贴现）列 P2 | 赎回价折扣系数 0.95~1.0；剩余期限下限 0.5~1 年 | 回测 ablation |
| R3 | 深度低价异常 | 现价 < 85~90 **且**评级 < AA 的券排除（市场已定价信用恶化，双低天然会捞这类券——这是第一轮 §3.1 理由 2 的正面处置） | 价格下限 85~90 | 回测 ablation |
| R4a | 强赎规避·公告即卖 | cb_call 公告日（ann_date ≤ 当日，is_call=1）→ T+1 内强制卖出，不等强赎日（强赎杀溢价是确定性事件） | **P0 硬规则** | 无需 ablation（制度性动作），但要回测执行假设的敏感性 |
| R4b | 强赎规避·事前不新买 | 正股收盘 ≥ 130%×当期转股价 的近 30 日计数达阈值后**不再新买入**（持仓保留，靠 R4a 兜底） | 计数阈值 **10/30 ~ 15/30** | 回测 ablation（规避太早损失末段拉升 vs 太晚承担溢价坍缩，收益代价量化后拍板） |
| R5 | 正股兜底 | 正股 ST/*ST → 排除且持仓清仓；正股收盘 < 1~2 元（面值退市缓冲）→ 排除 | ST 线 **P0 硬规则**；价格线区间 1~2 元 | 价格线回测 ablation |
| R6 | 规模/流动性 | 剩余规模 ≥ 0.5~1 亿；近 20 日日均成交额 ≥ 500~1000 万（小盘债日均几千万成交，第一轮 §二.A 风险③） | 规模 0.5~1 亿；成交额 500~1000 万 | 回测 ablation |
| R7 | 到期 | 剩余期限 < 0.5 年 → 移出双低池（到期博弈是另一套逻辑，不混入） | 0.5 年（固定） | 无 |

**P0 硬规则 = R1 评级下限 + R4a 公告即卖 + R5-ST 兜底**，这三条是信用风险实质化（2026H1 已 56 只强赎，第一轮 §二.A）后的底线，不做 ablation、不可关闭；其余规则全部做成开关矩阵，跑 ablation 后定稿——**定稿规则集必须预注册后才许看样本外**（P17 预注册纪律）。

### 2.3 证伪判据（预注册，命中任一即归档不恋战）

对齐第一轮 §3.1 三条反对理由 + 审计清单五问：

1. **收益质量**：双低+排雷（P0 规则集）2019-2026 逐年超额 vs 中证转债出现 **≥3 个负年份**，或全期年化超额 **<3%** → 放弃；
2. **泡沫期检验**（审计清单第 2 问）：剔除表现最好的 1 个年份后全期年化超额 **<2%** → 判定"扩容红利+债牛 beta"假象，放弃；
3. **拥挤衰减**：2024-2026 超额 **<2%/年且单调下滑** → 判定进入失效通道（对齐因子健康 DEGRADED 逻辑），放弃；
4. **payoff 叙事**：排雷 ablation 中，"P0 规则集全开"版本全期年化 **<8%** 或最大回撤 **>-20%** → "下有债底上跟正股"叙事坍塌，放弃；
5. **样本外**：以 2021-2023 定规则集与阈值 → 2024-2026 样本外年化超额 **转负** → 放弃。

外部数字（国海 23.02%/雪球 41.28% 等，第一轮 §二.A 引突破清单）继续只作背景，不作立项依据（审计清单硬规则）。

## 三、B 方向（全天候）配置决策建议书草稿

### 3.1 定位重申

B 是**配置决策不是策略研发**：收益全部来自 beta，A 股 beta 长期平庸有本仓实证（P08 指数增强 0.4%、P05 红利低波 3.7%，第一轮 §3.2 引全局控制台），组合年化预期 **4-8%**（第一轮 §二.B 风险①）。它的价值不在收益，在把 950 万闲置从"现金零收益+全额押注 A 股小盘风格"改成"多资产浅回撤 + 危机情景不同跌"。预期管理写进建议书正文，避免上线后拿 4-8% 与 18% 纸面策略攀比。

### 3.2 资产池与初始比例

资产池（代码待实测项标注）：510300（沪深300）、510500（中证500，卫星）、十年国债 ETF（**代码待实测**）、货币 ETF（511990/511880）、518880（黄金）、513100（纳指 QDII，**待实测**，见 §3.4）。

### 3.3 再平衡机制

- 月度检查 + **绝对偏离 ±5pp 触发**再平衡 + 季度末硬再平衡兜底；
- 频率刻意保守："少动比多动赚钱"是本仓审计案例的实证遗产（知乎 RL 轮动输给等权躺平 30.75% vs 32.49%，审计清单案例索引）；
- ETF 再平衡的摩擦成本（佣金+冲击）在低频下可忽略，但仍计入回测。

### 3.4 压力情景回撤估算（方法 + V1/V2 数字）

方法：固定比例线性叠加，假设三资产同时受压、相关性不提供保护（保守口径）。**压力参数为拍板项（假设，非实证数字）**：股 -30%（对齐 2018 级熊市量级）、国债 -5%（久期约 8 年对应利率 +60bp 量级）、金 -15%（高位回撤量级）、纳指 -35%、货币 0。

- **V1**：0.25×(-30) + 0.05×(-30) + 0.30×(-5) + 0.25×0 + 0.15×(-15) = **-12.75%** → 15% 组合回撤红线内（AGENTS.md 风控优先级），留 2pp 缓冲；
- **V2**：0.20×(-30) + 0.05×(-30) + 0.30×(-5) + 0.20×0 + 0.15×(-15) + 0.10×(-35) = **-14.75%** → 贴线，需拍板者明确接受或减股至 25% 换缓冲。

### 3.5 风险平价 vs 固定比例 vs 等权躺平（回应 Q4 后半）

- 无杠杆风险平价 ≈ 波动率倒数加权 → 权重被低波资产（债/货币）主导，股票敞口可能压到 <10%，预期收益反而低于 V1；它的优势场景是**杠杆组合**（"风险平价/波动率择时在杠杆组合下有效"，第一轮任务书【已被验证有效的】），而 B 明确不加杠杆；
- **预注册判据**：风险平价（滚动 60 日协方差，月频）与 V1 固定比例年化差 **<1pp/年** → 弃风险平价（复杂度性价比，审计清单第 5 问）；等权躺平对照（1/4 等权含货币，月再平衡）必设且**必须写进报告正文**（审计清单第 1 问；P17 记忆教训：恒定仓位对照曾全面碾压精心设计的覆盖层）；
- 我的预判（可被回测推翻）：大概率 V1 ≈ 风险平价 < 等权躺平（等权股敞口更高，牛市占优），届时按预注册判据执行，不许事后换判据。

### 3.6 模拟盘验证计划

1. 回测半天出数（三线对照 + 压力情景 + 分年，2015 起，重点 2018/2022 压力段——第一轮 §二.B）；
2. 诚哥拍板比例（建议 V1 起步）；
3. 模拟盘 70180771 首笔 **10-20万** 铺 V1，验证 ETF 委托/成交/对账/再平衡全链路，判据 = **1 交易日无 P0**（对齐 P10 模拟盘标准，AGENTS.md：MOCK 测不到集成层 bug）；顺带小额实测 513100 与十年国债 ETF 的 QMT 可交易性（Q5 待实测项在此关闭或坐实）；
4. 观察 **≥2 周**（含至少一次真实再平衡触发或人工演练）→ 二次拍板加仓至首期目标 **200-300万，分 2 批、间隔 ≥2 周**；
5. capital_allocation.yaml 追加独立虚拟子账户 + `scripts/check_capital_allocation.py` 退出码 0 才许部署（AGENTS.md 资金分配红线）。

### 3.7 证伪判据（预注册，第一轮 §二.B 基础上细化）

1. 2015-2026 全区间卡玛不优于 100% 沪深300 的 **1.5×**（具体倍数线诚哥拍板，建议 1.5×）→ 关闭；
2. 等权躺平对照**全面更优**（年化 ≥V1+1pp 且卡玛不差）→ 直接执行等权躺平，弃 V1/风险平价；
3. 风险平价 vs V1 差 <1pp/年 → 弃风险平价（§3.5）；
4. 压力情景回撤 >-15% 且减股无法修复 → 减配或否决；
5. 与现有 5 策略合成组合后夏普无实质改善（合成相关性 >0.5 或组合卡玛持平）→ 分散叙事落空，降级为"纯闲置资金货币化"处理（只留货币腿）。

### 3.8 QDII 可行性小结（回应 Q5）

- ①数据可得性：astock ETF 管道（etf_xtdata，P11 遗产）是否覆盖 QDII **待实测**；iFinD MCP 港美股域可作对照源；
- ②QMT 可交易性：**待实测**（搭 §3.6 第 3 步顺带验证，不单独立项）；
- ③汇率与溢价：人民币升值直接拖累纳指腿收益（不对冲，接受）；QDII 高溢价是结构性风险（额度紧张时溢价可达个位数到两位数百分比，**常识性风险提示，非白名单数字**），处置 = **溢价 >3% 暂停买入该腿改持货币**，溢价回落再补——买入规则写进模拟盘脚本；
- ④结论：**值得纳入但仅 V2、≤10%、带溢价熔断**；两条待实测任一失败 → V2 撤销，V1 不受影响。
