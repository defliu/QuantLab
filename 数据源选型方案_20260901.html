A股量化交易数据源选型方案

调研时点：2026-09-01（同日晚上按 QuantLab 实际核验并调整）｜ 适用范围：A股量化研究与实盘（日频 / 分钟频为主）｜ 针对 QuantLab 现状定制

核心结论（先看这里）

  1. 不存在"全国唯一最佳"的数据源，只存在"按交易频率 × 资金容量 × 合规身份"分档的最优组合。数据源的选型错误不在"选贵了"，而在用高频数据做低频策略（多花钱无收益）或用爬虫源跑实盘（稳定性与合规双失）。
  2. 对你（日频调仓、容量 1000–2000 万、A股小市值多因子）而言，最优解是三层组合：买断离线库做回测主干 + 券商授权通道做实时与增量（零边际成本）+ 一份商业 API 做财务 PIT 校验与补漏，年现金成本控制在 200–3000 元。Wind / 恒生聚源 / L2 逐笔在这一档位是纯浪费。
  3. QuantLab 现有链路已接近该最优解（D:/astock 离线主仓 + 按职责分组的实时链 + 09-01 晚新增 astock_kit 独立源与每日定时快照）。⚠️ 原稿"①离线增量依赖人工投放；②资金流与集合竞价字段单点依赖；③实时链过度依赖东财系反爬通道"三条短板已于 09-01 晚前逐步缓解：①P16 的 xtdata_update.py + Quant_Daily_Update（16:30）已实跑 xtdata 每日自动增量（人工 Updatedata 降冷备）；②资金流已锚定 mcp_tdx 当日口径 + 悟道 capital_flow（iFind 降仅兜底，T-20260831-003 已实锤 iFind 前一日口径虚高）；③astock_kit（腾讯/mootdx 行情 + 东财 datacenter 两融/股东户数/大宗/解禁/龙虎榜/涨停池/研报，定时 17:30 落盘）提供东财系之外的独立源。
  4. 优先级排序：先补"自动化增量"（零成本，收益最大），再补"财务 PIT 交叉校验"（¥200/年），最后才考虑付费终端。在策略本身未跑出稳定超额前，任何年费过万的采购都是负期望。

四、选型决策路径

按"先定策略频率与容量，再倒推数据源"的顺序走，可以避免 90% 的过度采购。

第 1 步
定频率
日频 / 周频调仓 → L0+L1+L3 即可。
分钟频择时 → 加 Tushare 历史分钟或 QMT xtdata。
Tick / 高频 → 必须 L2 逐笔 + 极速柜台，且触发强监管。
第 2 步
定容量
< 100 万 → 全免费栈跑通逻辑。
100 万 – 2000 万 → 日频完全够用，年预算 ≤ ¥3000。
> 5000 万 → 冲击成本成为主矛盾，才需要考虑 L2 与执行算法。
第 3 步
定主干
回测主干必须是本地买断库（parquet / DuckDB）。任何依赖在线 API 逐次拉取的回测都不可复现、不可审计。
第 4 步
定冗余
每个关键字段至少 2 个独立源。单点字段 = 单点故障，实盘中会直接表现为信号失真或误判成交。

风险二：程序化交易已入强监管，报备是前置条件

沪深北三所《程序化交易管理实施细则》自 2025 年 7 月 7 日起正式实施（来源：中国金融信息网、经济日报、央视网 2026-07-30 报道，多源一致）。要点：

  • 高频交易认定标准：单账户每秒申报/撤单合计最高达 300 笔以上，或单日申报/撤单合计最高达 20000 笔以上。
  • 四类异常交易监控：瞬时申报速率异常、频繁瞬时撤单、频繁拉抬打压、短时间大额成交。
  • 额外报告义务：触发高频标准的，须额外报告服务器所在地、系统测试报告、故障应急方案；交易所可实施差异化流量费/撤单费。

对你的实际影响：日频调仓、单日委托笔数量级在几十笔，远低于高频阈值，基本不受约束。但"程序化交易报告"本身与使用频率无关——通过 QMT 自动下单即属程序化交易，须确保已在券商侧完成报备与风险测评（C4 及以上）。另注意 2026 年以来的两项新动向：券商独立交易单元全面整改（3 月起暂停新申请、不得由单账户独占）、深交所交易系统接入由局域网转广域网（5 月技术修订），均指向高频基础设施，日频策略不受直接影响。

风险三：关于"爬虫合规收紧"的一处纠偏

网络流传"2026 年 1 月 1 日施行的新《网络安全法》大幅收紧了未经授权抓取公开数据"的说法，依据不足。核对全国人大常委会《关于修改〈中华人民共和国网络安全法〉的决定》（2025-10-28 通过，主席令第六十一号，2026-01-01 施行）全文可见，本次修订新增内容集中在：党的领导与总体国家安全观入法、支持 AI 基础研究与算力建设、网络运营者处理个人信息的法律适用衔接、关键信息基础设施运营者分级处罚、销售不合格网络关键设备的责任、行政从轻减轻豁免机制。未检索到针对"公开数据抓取 / 爬虫"的新增条款。

但这不意味着爬虫无风险：相关风险主要来自《数据安全法》《反不正当竞争法》及司法实践（如"实质性替代"认定），而非本次网安法修订。结论不变——学习与回测阶段可用 AKShare 等免费源，实盘与生产环境应使用授权商业源或券商通道，只是理由应建立在"稳定性与数据源自主可控"上，而非援引一条不存在的法条。
