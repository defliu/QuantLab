## 三、三个硬约束（比数据更本质）

1. **T+1 制度**：做T必须挂底仓，当日买入部分不可当日卖出。策略形态 = 对已有持仓做日内增减仓：
   - **正T**（先买后卖）：日内低点加仓，冲高卖出等量底仓，净仓位不变。
   - **反T**（先卖后买）：冲高先卖部分底仓，回落接回，净仓位不变。
   - 底仓来源 = 现有持仓策略（Phase 3 挂靠对象另行拍板）。
2. **成本线是第一杀手**：现行往返成本 ≈ 佣金万 2.5 双边 0.05% + 印花税卖出 0.05% + 滑点双边 0.1% ≈ **0.20%/次**（2023-08-28 印花税减半后口径）。**历史分段（r2 修补）**：2009 ~ 2023-08 印花税为卖出 0.1%，且早年佣金普遍高于万 2.5，当时真实往返 ≈ **0.25%~0.30%/次**——历史回测必须按当时实际成本扣，禁止拿今日成本算旧年份（旧年份恰是高振幅、日内信号最好看的区间，低估成本 = 假阳性直接埋在最有利的年份里）。做T单次目标毛利通常 1~2%，净期望死于成本是常态。**所有信号从第一次评估起就扣成本**，毛 alpha 不算数。
3. **风格矛盾要直面**：实盘主力持仓 = ATR 低波（低波动票日内振幅天然小，做T毛利空间薄）。做T更适合振幅 2.5%+ 的中波动票。→ Phase 1 做全池研究（按振幅分层看结论落在哪一层），**M1 必须产出「ATR 低波持仓振幅带」专层结论（r2 前置）**。**知情二选一提前声明**：若净 alpha 仅存在于 2.5%+ 振幅层，Phase 3 只有两条路——挂靠低波持仓（大概率空转）或另建独立高波底仓（本质变成新策略，与本项目「不是独立选股策略」定位冲突）——该拍板放在 **M1 裁决时**一并做，不等 Phase 2 做完才发现空转。

## 四、研究路径（三阶段）

### Phase 1：日内信号预研（当前阶段，3~5 天，不建引擎）

沿用 Project_18 预研模式：信号扫描 + 前向收益评估，无回测引擎依赖。

**信号清单（首轮 6 族，r2 补 F6）**：

| 编号 | 信号 | 直觉 |
|---|---|---|
| F1 | 竞价类：高开幅度、竞价量比分位、竞价强度 → 开盘后前向收益 | 竞价信息量（数据现成） |
| F2 | 早盘动量/反转：09:30–10:00 收益 → 10:00–11:30、13:00–15:00 前向 | A股日内反转效应（学术有支撑） |
| F3 | VWAP 偏离：价相对当日累积 VWAP 偏离度 → 回归概率与幅度 | 日内均值回复 |
| F4 | 开盘 30 分钟量能结构：振幅占比、量能集中度 → 剩余时段收益 | 日内节奏 |
| F5 | 隔夜跳空回补：跳空缺口 → 当日回补概率 | 缺口引力 |
| F6 | **盘中脉冲回归（r2 新增）**：分钟频触发——5 分钟收益 z-score 越阈（急跌买入正T / 急拉卖出反T）→ 前向回归概率与幅度 | 做T实践核心触发形态、样本量最大；F1~F5 均为「每日一次早盘决策」形态，缺盘中 opportunistic 触发族 |

**技术口径（防坑清单，执行时逐条对照）**：
- **复权口径**：日内收益用原始价（除权在盘前，日内 OHLC 同日无除权）；跨日比较（隔夜跳空、竞价 vs 昨收）用 `adj_factor` 复权价。
- **09:30 首根 bar 含集合竞价成交量**：做量能信号时剔除或单列，防口径污染。
- **look-ahead 三防线**：信号只用 t 时刻及之前数据；前向收益自 **t+1 根 bar 开盘**进入（`P_{t+k}/P_{t+1,open} − 1`）；信号计算窗口内不含前向数据。
- **可成交过滤**：前向窗口内涨停不可买、跌停不可卖、停牌剔除；样本按日频候选量检查（`candidate_passed_avg_per_day`，P12 必检指标防"信号枯竭"）。
- **未完成回转强平（r2 新增）**：回转当日了结——正T买入后持续走低（多仓过夜）、反T卖出后拉回不接（底仓踏空）是实盘做T第一杀手。前向收益评估必须包含强平分支：**至 14:50 未平仓者强制以收盘价了结，强平损益计入单笔净期望**，禁止隐含「回转必然完成」的乐观假设。
- **成本敏感性（r2 分段）**：基准往返成本按时间分段——**2023-08-28 前按 0.25%（印花税卖出 0.1% 口径），之后按 0.20%**；敏感性围绕分段基准 ±0.10% 三档（前段 0.15%/0.25%/0.35%，后段 0.10%/0.20%/0.30%）。裁决以分段实际成本为准，禁止全期统一 0.20%。
- **保守成交价代理（r3 新增）**：F2/F3/F6 类盘中信号额外用 t+1 bar **VWAP 或收盘价**（而非开盘价）成交重算一档，筛掉「只在开盘瞬间成立」的假 alpha——无 tick 条件下对 0.1% 滑点假设的替代校验，该档不过则信号按不过裁决。
- **统计裁决口径（r2 新增，r3 补聚类层级）**：裁决口径 = **单笔等权平均净期望**（不是聚合 PnL、不是市值加权）。分钟级 × 5826 只名义样本百万级，但横截面共同冲击（千股同涨跌日）使名义样本量虚高——必须补按年、按市场状态聚类的稳健性检查，**聚类最低层级 = 交易日**（同日千股同向是最主要的相关源，禁止按原始笔数算显著性），并单列**剔除 2015 股灾极端日后**的结论，防个别极端日贡献全部 alpha。
- **分年统计**：尤其 2015（异常波动）、2018、2022、2024（熊市年）必须单列；依赖单一泡沫年（如 2026H1）的信号直接停（Trae v2/v3b 教训）。
- **调参纪律**：首轮参数敏感性扫描（非精调）；若需调优，2009–2018 调参、2019+ 样本外，预注册后不得回改。**裁决只认每族预注册的默认参数点，敏感性扫描仅作稳健性展示，禁止取扫描最优值过线（r3 新增）**——6 族 × 多参数构成多重检验，「扫描取最优」正是「跑出好结果再找理由」的统计学入口，与预注册初衷相悖。

**预注册证伪线（数值待诚哥拍板锁定，拍板后不可回改）**：

| 判据 | 建议线 |
|---|---|
| 单信号净期望（扣**分段实际成本**：2023-08-28 前 0.25% / 之后 0.20%） | > 0，且毛期望 ≥ 0.3%（成本覆盖倍数 ≥ 1.5） |
| 统计显著性（r3 新增） | 单信号净期望**按交易日聚类 t ≥ 2**（或 block-bootstrap 95% CI 下界 > 0）；名义样本百万级不算数，有效样本以聚类后为准 |
| 分年净期望 | 2015+ 每个自然年 > −0.5%（允许个别年份微亏，不允许深亏） |
| 样本外（2019+） | 与全期结论同向 |
| 极端日稳健性（r2 新增） | 剔除 2015 股灾极端日后结论仍同向（单笔等权口径） |
| 挂靠层专查（r2 新增） | 「ATR 低波持仓振幅带」分层结论单列；若该层无净 alpha，M1 裁决时必须拍板挂靠二选一 |
| 候选密度 | 做T机会日均 ≥ 1 次且不集中个别票（**口径已拍板 2026-09-27**：「每股日均」**与**「每百票日均」**两指标并列输出**；并加「单票占比 ≤ 10%」；**零股规则**：单票不足 100 股直接跳过、不入统计） |
| 信号间相关性 | 入选信号两两相关 < 0.7 才考虑组合 |

**通过 → Phase 2；不通过 → 归档结题**（参照 P12/P18 模式，报告 + 证伪归因落 `results/`）。

### Phase 2：分钟级回测引擎（仅 Phase 1 有净 alpha 信号才启动，opencode/deveco）

## 五、风控与工程红线

- Phase 3 之前不碰任何生产账本、额度、现役策略代码。
- 做T模块若落地，独立 ledger，绝不纳管/卖出他人持仓。
- **实盘回转回退（r3 新增，与 Phase 1 强平口径同源）**：14:50 未平强制挂单平回；跌停/停牌平不掉 → 记**超配账本**、次日开盘优先卖出并计入风险暴露（正T 未平 = 隔夜超配，是「净仓位不变」承诺唯一可能被突破的口子）；反T 未接回不追高接回，底仓缺口次日由主策略正常流程补齐。
- **数据口径红线（r3 新增）**：moneyflow 为日频，任何日内触发信号禁止引用它，只允许作日度条件/分层变量；日内量能信号只能用 1min vol/amount 自聚合。
- 风控优先级红线不变：不为提高交易频率绕过风控底线。
- 本项目所有研究结论落 `results/`，证伪也要留档（对照资产）。
