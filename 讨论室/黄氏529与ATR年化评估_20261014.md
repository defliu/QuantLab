### A4. 预注册规则对照（T-20260816-001 T3）

- R1：若 2023-2026 全变体 CAGR ≤2% → 归档
- R2：若存在 >5% 且卡玛优于同期 ATR → 待拍板
- R3：中间段（2%~5%）→ DOING + 信号衰减监控，30 交易日复评

当前 2023-2026 CAGR 段为 7.00%（>5%），但**卡玛 0.37 远劣于同期 ATR 1.56**（R2 不成立）；而 2026YTD 到期均收 +1.44% 已**跌破 R1 的 2% 下沿**，fwd20 转负、信号流 -34%。→ **趋近归档条件，属「建议归档/待诚哥拍板」区间**。

### B4. 掩码修复后重跑刷新（2026-10-14 完成）

16.95% 出自 **2026-08-16 run，早于 2026-08-29 的掩码地基修复**（`strategy/atr_mask.py` 修两处硬 bug：`suspend_type!=''` 误把 'N' 判停牌、涨跌停用复权价比 up_limit），故属 **upper bound**。**2026-10-14 已按生产口径（季频 / 10万 / 2019-01-01~2026-06-30 / 真实价<50 / 等权 8 只 / 止损 -8% / next_open）用修复后引擎重跑两臂**（自建 runner：`atr_lowvol` + `AstockParquetReader` 为未掩码基线臂，`atr_lowvol_mask` + `MaskParquetReader` 为掩码臂；两策略逐行比对**唯一差异 = 掩码**，对比公平）：

| 指标 | 未掩码基线（同窗口重跑） | **掩码后（可交易真实口径）** | 差 |
|---|---|---|---|
| 总收益 | +200.40% | +148.93% | — |
| **CAGR（复利，真实）** | **16.50%** | **13.50%** | **-3.00pp** |
| 最大回撤 | -24.80% | **-28.71%** | 恶化 3.9pp |
| 夏普 | 0.874 | 0.702 | -0.172 |
| 胜率 / 笔数 | 73.88% / 656 | 70.71% / 676 | — |

→ **结论：掩码修复后真实可交易 CAGR 由登记的 16.95% 刷新为 13.50%（-3.45pp），回撤由 -24.80% 恶化至 -28.71%**。差异来源 = 框架执行层本已内建涨跌停/停牌挡单（`backtest/execution.py`），掩码臂的额外差异来自 **Selector 层去污染**（ATR 估计剔除停牌/涨跌停 frozen bar + 剔除调仓日不可成交标的）。旧登记值 16.95% → 同口径重跑基线 16.50%（差 -0.45pp，源于 D:/astock 数据更新 + 策略微改，n_trades 651→656）。**注意：生产 QMT 端策略实际掩码行为需与 `atr_lowvol_mask` 对齐核对**（登记口径按掩码臂 13.50%）。产物：`research_study/atr_mask_prod_rerun_result.json`。

### B5. 建议对外引用口径

> **ATR 低波（等权 8 只 + 真实价<50）：2019-2026 全样本 CAGR ≈ 13.50%（掩码修复后可交易口径；同窗口未掩码基线 16.50%），最大回撤 -28.71%（基线 -24.80%），夏普 0.702（基线 0.874）（线性年化 28.99% 为旧框架虚高口径，不采用）。**
