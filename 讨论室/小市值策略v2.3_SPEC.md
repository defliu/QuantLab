## 一、Objective（策略目标）

### 1.1 策略定位

A股小市值风格增强策略：以市值因子为 beta 底仓（流通市值最小 30% 分位），通过多因子选股获取 alpha，配合闭环风控扛住小市值特有的尾部风险（退市、流动性危机、风格切换）。

**基准**: 中证 2000 指数。策略目标是**相对基准的超额收益**，不是绝对收益 —— 原设计无基准，无法区分赚的是市值风格的钱还是选股的 alpha，本版修正。

### 1.2 量化验收线（样本外口径）

| 指标 | 验收线 | 说明 |
|------|--------|------|
| 年化超额收益（vs 中证2000） | ≥ 8% | ⚠️ 原设计未设基准，此为首版目标 |
| 信息比率 IR | ≥ 1.0 | 超额收益 / 跟踪误差 |
| 超额最大回撤 | ≤ 15% | 相对基准净值的回撤 |
| 月度超额胜率 | ≥ 55% | — |
| 月度单边换手率 | ≤ 80% | 缓冲区机制应显著降低换手 ❌ 需实测 |
| 成本损耗（年化） | ≤ 6%，且毛超额 ≥ 成本 + 5pp | 不满足则策略不成立（成本可行性闸门） |
| 压力窗口表现 | 2024-01-15 ~ 2024-02-29 窗口回撤 ≤ 20% | 微盘股流动性危机压力测试，详见 7.1 |
| 策略容量 | ≥ 2,000 万 | 详见第八节 |

### 1.3 对原设计的核心修正摘要

原设计存在四类严重问题：**因子合成代码 6 个因子中 3 个方向写反**（选股逻辑颠倒）、**风控规则不闭环**（回撤减半仓后无恢复规则、跌停无法执行止损）、**回测方法论缺陷**（无幸存者偏差处理、无前视偏差防控、样本期过短、无基准）、**小市值特有风险未覆盖**（退市风险、2024年初微盘危机）。全部修正明细见第十二节变更日志。

原设计将"一月波动率"作为 6 个排序因子之一，v2.0 改为股票池层的硬过滤：

### 3.4 股票池收缩兜底（🆕 原设计未定义）

技术/波动过滤在极端熊市会使池子急剧缩小，原设计未定义此时行为（实际构成隐性择时）。v2.0 显式化：

- 池内股票 ≥ 20 只：正常选股；
- 10 ~ 19 只：持仓数 = 池内全部股票，其余资金持现金（计入回测）；
- < 10 只：触发风格警报，总仓位上限降至 50%，并通知人工复核。

**触发频率验证（v2.1 新增）**：上述兜底不应在实盘中频繁触发。回测必须输出池子规模的历史分布（池内 < 20 只、< 10 只的月份数及占比）。若 < 20 只的月份占比 > 10%，应优先放宽过滤参数（ATR% 阈值放到 7%、或换手率区间放宽至 1%-10%）重新验证，而不是接受频繁降仓。Project_15_ATR低波动策略的已知问题中记录了同类风险（"双条件过滤可能在某些市场状态下选出 0 只"），佐证本项必要性。

### 4.2 方向约定与合成代码（P0 修正）

**原设计 6 因子中 3 个 rank 方向写反**（PE、动量、分析师预期，详见评估报告 3.1 节）。v2.0 统一约定：

> **综合得分越高越好；`rank(ascending=True)` 表示因子值越大、得分越高。** 每个因子在代码中必须注释方向。

```python
import numpy as np

def winsor_mad(x, n=3):
    """MAD 去极值（比 3σ 稳健）"""
    med = x.median()
    mad = (x - med).abs().median()
    lo, hi = med - n * 1.4826 * mad, med + n * 1.4826 * mad
    return x.clip(lo, hi)

def neutralize(x, industry_dummies, log_mv):
    """行业 + log(流通市值) 中性化：回归取残差"""
    X = np.column_stack([industry_dummies, log_mv, np.ones(len(x))])
    beta, *_ = np.linalg.lstsq(X, x.fillna(x.mean()).values, rcond=None)
    return x - pd.Series(X @ beta, index=x.index)

def composite(df):
    """v2.1 三因子等权合成（F4 冻结）。约定：得分越高越好。"""
    specs = [
        ('ep',           True),   # F1 价值：EP 越高越好
        ('mom_60_21',    True),   # F2 动量：区间收益越高越好
        ('turnover_20d', False),  # F3 量稳：换手越低越好（ascending=False → 小值得高分）
        # F4 分析师预期修正：v2.1 冻结（E:/astock 无数据源，见 2.1）；
        # 补数据后在此加回 ('analyst_rev', True) 并将覆盖率门控设为 0.40
    ]
    score, wsum = 0.0, 0
    for col, higher_better in specs:
        coverage = df[col].notna().mean()
        if coverage < 0.30:          # 覆盖率门控（F4 启用阈值为 0.40）
            continue
        x = winsor_mad(df[col])
        x = neutralize(x, df['ind_dummies'], np.log(df['circ_mv']))
        x = (x - x.mean()) / (x.std() + 1e-9)          # Z-score
        r = x.rank(ascending=higher_better, pct=True)
        r = r.fillna(0.5)            # 个股缺失 → 中性分，而非系统性劣势
        score, wsum = score + r, wsum + 1
    df['score'] = score / max(wsum, 1)   # 按可用因子数归一
    return df
```

与原设计伪代码的差异：方向显式化并逐一核对；缺失值从"一句 `handle missing_values` 伪代码"改为**中性分填充 + 覆盖率门控 + 按可用因子归一**；标准化与 rank 的管线顺序固定为"去极值 → 中性化 → Z-score → rank"，消除原设计两套方法叠加的歧义。

### 4.3 因子准入与权重

- **准入门槛**（对齐本库方法论）：每个因子先在小市值池内做单因子检验 —— 截面 spread > 0.15%、通过率 10%-95%、滚动 RankIC 均值 > 0.02 且 ICIR > 0.3，任一不达标即剔除，不得进入合成；
- **权重**：主方案等权（防过拟合，保留原设计该优点）；对照方案用滚动 24 个月 IC_IR 加权。仅当加权方案在**样本外**显著占优时才切换。

## 六、风控体系（闭环）

### 6.0 ⚠️ 与已有证据的冲突预警（v2.2 新增）

Project_10 的 P1-1 已对与本节高度相似的风控方案做过实测（`PROJECT_README.md` 2026-08-04 更新）：

- **分层降仓劣于断路器**：分层降仓重构后回撤反而恶化至 -32.7%，基线的 15% 一刀清仓断路器更有效；
- **ATR 止损增加成本**：开关保留但默认关闭。

这意味着本节的核心机制（ATR 追踪止损 + 回撤 15% 减半仓状态机）在小市值场景**很可能是负贡献**。裁决前，6.1-6.4 保留为"待验证方案"而非执行依据；实施前必须用 Project_10 的回测框架与 risk_state 基线做消融对照（断路器为对照组），详见讨论室 Q3。

### 6.1 个股层

| 规则 | 参数 | 执行方式 | 状态 |
|------|------|----------|------|
| ATR 追踪止损 | 止损位 = max(入场价 − 2×ATR(14)，滚动最高价 − 2×ATR(14))，每日更新 | **收盘价**跌破止损位 → 次日开盘卖出 | ✅ 保留原设计核心，ATR 计算沿用原文逻辑 |
| 跌停处理（🆕） | 止损日或次日跌停无法卖出 | 保留持仓挂跌停价排队，**打开后第一时间卖出**；回测按此模拟并记录额外滑点 | 🆕 原设计"次日开盘立即卖出"在连续跌停（2024 年 1-2 月微盘危机常见形态）下不可执行 |
| 个股硬上限（🆕） | 自入场价亏损 > 15%（无论 ATR 止损位在哪） | 无条件排队卖出，作为 ATR 失效时的兜底 | 🆕 |
| 止损后资金（🆕） | 止损卖出所得现金**持有至下个调仓日** | 备选方案"立即用候补股补位"仅作敏感性对照，不进主方案 | 🆕 原设计未定义 |
| ATR 突变条款 | 原设计"ATR 日变动 > 20% 立即重算止损位" | **删除** —— ATR 本身每日滚动更新，该条款冗余且引入任意性 | ❌ 删除 |

### 6.2 组合层：回撤控制状态机（🆕 闭环修正）

原设计"回撤 15% 减半仓"没有恢复规则，触发一次即永久半仓。v2.0 改为显式状态机：

```
状态: FULL(100%) → HALF(50%) → RECOVERING(75%) → FULL(100%)

FULL → HALF:
  组合净值自滚动高点回撤 ≥ 15%
  → 次日开盘总仓位降至 50%
  → 仅对未触发个股止损的持仓按比例减仓（保留原设计的禁止叠加减仓规则）

HALF → RECOVERING:
  回撤缩窄至 < 8%
  → 仓位恢复至 75%（买入按当月持仓名单等比例补足）

RECOVERING → FULL:
  回撤缩窄至 < 3% 或净值收复前高的 98%
  → 恢复 100% 仓位

减仓期间现金按货币基金年化 1.5% 计入回测（保守假设）。
```

### 6.3 极端市场条款（🆕）

- 中证 2000 单日跌幅 > 5%：当日暂停一切新增买入（止损卖出照常执行）；
- 持仓股中 > 10% 个股处于跌停无法卖出：暂停除止损外的一切操作，触发人工复核。

### 6.4 风控优先级

1. 个股硬上限（-15%）
2. ATR 止损
3. 极端市场暂停条款
4. 组合回撤状态机

同一股票不重复适用减仓规则（保留原设计"禁止叠加减仓"）。
