## 一、立项定位

**一句话**：为 P16 三臂（V1.x / G2 / ENS）补一层**慢尺度仓位门控**——防「温水煮青蛙式 regime 下移」（数周-数月的持续阴跌），与已有的单日快门控（E-4，2026-10-10 已落地）互补不冲突：快门控防「当天破位」，慢门控防「累计失血」。

**立项动机（必须如实表述）**：「**换回撤**」，**不是「提收益」**。
参考文章的「年化 11.7%→20%、回撤 33%→19%」**不可作收益预期**——审计 §六.4 已定性：同族规则我们自己有反例（见 §三 P10 警示），保险费不是增强。若回测显示年化显著提升，反而要警惕过拟合或口径错误。

## 二、机制定义（候选规则族）

### 2.1 主候选规则 R0（文章口径，最小改动）

```
指数基准：沪深300 收盘价（主）/ 中证1000 或中证2000（小盘对照，见 2.3）
回看窗口：63 个交易日（约 3 个自然月）
触发条件：收盘价较 63 日前收盘累计跌幅 ≤ −8%
触发动作：目标仓位降至 30%（只降新买预算与超配减仓，不强制清仓——与 E-4 T 档机制同构）
恢复条件（hysteresis 防抖）：累计跌幅收窄至 ≥ −4% → 恢复满仓
信号时点：T 日收盘算信号 → T+1 开盘执行（PIT 安全，无前视）
```

### 2.2 敏感性变体（网格，防单点参数过拟合）

| 维度 | 档位 |
|---|---|
| 回看窗口 | 42 / **63** / 126 交易日 |
| 触发阈值 | −6% / **−8%** / −10% |
| 降仓档位 | 0% / 30% / **50%** |
| 恢复阈值 | −4%（半阈） / 0% / 收复回看前高 |

结论稳健性要求：主候选过线时，其参数邻域（每维 ±1 档）结论不得翻转；单点过线、邻域翻转 = 过拟合信号，判伪。

### 2.3 关键设计点：指数选择可能比阈值更重要

三臂选股池是**小盘票**，但主候选指数是沪深300——大盘与小盘 regime 可能严重错位：2024 年初微盘股崩塌时沪深300 跌幅远小于小盘指数，用沪深300 做慢门控**漏防最需要防的场景**。
故回测必须**双指数对照**：沪深300 vs 中证1000/中证2000（或可得的最新小盘代理）。若小盘指数显著更优，这是「选对温度计」而非过拟合——两指数的触发日历须在报告中逐段列出供人工核对。

### 2.4 与单日快门控（E-4）的关系

两层独立触发、乘法叠加（如快门控 T=1 半仓 × 慢门控降 30% → 实际预算 15%）；不做互斥或覆盖逻辑，保持各自可独立归因。回测时**两层都开**（实盘口径）与**只开慢门控**（归因口径）各跑一遍。

## 三、硬警示（拍板前必读，来源：审计 §六.4 + AGENTS「优化方向实证」⑤）

1. **P10 MA200 同族反例**：大盘 MA200 门控把最大回撤 −29.7%→−15.8%，**代价年化 −4.4pp**——这类「仓位管理换回撤」的机制历史上在本仓库实证过一次，结论是保险费不便宜。C 层若过线，预期形态应与此同族：回撤显著改善、年化小亏。
2. **2024-09-24 V 反精确踏空风险**：累计回撤型降仓在急跌后 V 反时**恰好在最低点砍仓/空仓**，错过单日暴涨。2021-2026 回测窗含此场景，必须单段量化踏空代价（见 §5 判据 4）。
3. **文章数字不可作预期**（重申）：11.7%→20% 是文章自身口径，与我们的池、成本、执行方式无关。

## 四、与现有工作的隔离（红线）

- **不与 B1/B2 混跑**：C 层回测中，持有期（N5/N8/N10）、止损（−7% 及联合网格档位）、复入（B2-②）等受控变量**全部锁定为当前实盘值**，只加 C 层门控一个变量（单变量原则）。B1/B2 的任何拍板变更不并入 C 层回测，反之亦然。
- **不部署**：本立项只交付设计+回测方案+（后续）回测结果。任何实盘接入须回测过线后**另行拍板**，且接入点预计在 `rebalance_daily.py` / `rebalance_g2.py` / `rebalance_ens.py` 三处 Python 侧（与 E-4 同构，无需桥重建）——届时另行任务。
- **不占用本周窗口**：C 层回测排在 B1 联合网格出结果之后启动。

## 五、独立回测方案（预注册判据）

### 5.1 判据（过线 = 全部满足；任一不满足 = 判伪归档）

采用 **P21 证伪线预注册模式**（`specs/证伪线预注册锁定_20260928.md` + `config/falsification_criteria.yaml` 先例）：回测脚本启动前把下列判据写入只读配置，判定脚本只读配置输出 GO/NO-GO，杜绝「跑完再定标准」。

| # | 判据 | 过线标准 |
|---|---|---|
| 1 | 全期最大回撤改善 | ≥ 5pp（三臂分别计，至少两臂过线） |
| 2 | 全期年化代价 | ≤ 2pp（比 P10 的 −4.4pp 至少好一半） |
| 3 | 样本外一致性 | 留出段（见 5.2）方向一致（回撤改善为正且年化代价 ≤ 3pp） |
| 4 | V 反段踏空代价 | 2024-09-24 起 20 个交易日段，年化化踏空代价 ≤ 3pp |
| 5 | 参数稳健性 | 主候选邻域（±1 档）判据 1/2 不翻转 |
| 6 | 触发次数充分性 | 全期触发 ≥ 8 次、覆盖 ≥ 2 个独立下跌段（样本不足 = 结论不可信，直接判伪不判真） |

判伪即归档（P12/P18/P21 模式）：**重开须换口径重新预注册并经诚哥批准**。

### 5.2 样本与分段

- 全期：2019-01 ~ 2026-09（三臂共同可得窗口；再往前若数据可得加 2015-2018 前段作参考段，不进主判据）。
- 分段报告：2019-2021（牛）/ 2022-2024.09（熊）/ **2024.09-2024.10（V 反，单段踏空检查）** / 2025-2026（近年）。
- 留出段（样本外）：**2024-01 ~ 2026-09**（含 V 反与近两年，最难段留出）——预注册时锁定，跑完主段才解封。
- 成本：与三臂实盘口径一致（佣金+印花+滑点），换仓增量单独列示（慢门控自身引致的调仓成本）。

### 5.3 数据与 PIT

- 指数日线：先做**数据可得性 Day 0 检查**（D:/astock 是否含指数表；缺则从 Tushare 在线补或增量库取，写入数据源清单）。中证1000/2000 历史可得性一并检查——**指数数据缺失不改用代理拼凑，缺就降级为沪深300 单指数并如实标注**。
- 信号 PIT：收盘数据 T 日算、T+1 开盘执行，与 A 层教训一致（touch≈open，t=0.45，不做盘中触发口径）。
- **备用源交叉验证（AGENTS 硬规则）**：回测定稿后用 gpsj 备用源抽 1 个自然年复算（两源 CAGR/回撤差异 >1pp 需排查）；gpsj 不可用时报告显著位置标注「单源结论（仅 astock）」。

### 5.4 执行载体

- 复用三臂**纸面前向（paper forward）框架**做历史逐日仿真（三臂各自的候选/持有/风控链路已在该框架中，加门控变量最省）；不新写回测引擎。
- 产物：`research/c_slow_gate/` 下判据 yaml + 判定脚本 + 回测报告（编号沿用 P21 模式）。
