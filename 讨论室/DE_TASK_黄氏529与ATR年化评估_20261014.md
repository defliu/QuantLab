## 3. 必须做的独立复算（不引用文档结论，自己算）

1. **ATR CAGR 独立复算**：读取 `equity_curve.csv`（列 `date,total_asset`），用第一行与最后一行计算：
   - 总收益 = last/first - 1
   - 交易日数 n = 行数 - 1
   - 线性年化 = 总收益 × 252/n
   - 复利 CAGR = (1+总收益)^(252/n) - 1
   - 最大回撤（对 total_asset 序列）
   把复算结果与 `summary.json` 的 `annual_return` / `cagr` 字段对照，**明确报告是否一致**。可用 `python` 脚本（研究环境 Python 3.11）。
